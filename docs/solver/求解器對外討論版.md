# 貓九滑塊 求解器：方法與現狀（對外討論版）

> 面向「想討論算法、但不了解遊戲實作細節」的讀者。遊戲本身的數學模型見
> `../math/核心玩法形式化.md`（自包含、不依賴源碼）；本文只談
> 「我們怎麼自動求解」以及「做到了哪一步」，術語與該文一致。

## 0. 問題重述

狀態 = 固定大小 K 的**連通**格點集 S，落在某一種週期鋪砌的平面上
（方形 / 三角 / 米字三種鋪砌）。一步合法移動 = 選一條縫、選一側、把該側
**貼縫的連通分量**沿縫方向整體平移（遊戲中步長 step ≥ 1，逐步檢查無碰撞且
保持連通）。

目標狀態 = 所有格點拼成該鋪砌下的「標準大圖形」：方形為 m×n 矩形（可旋轉、
可平移）；三角為大正三角（實測只有 1 種朝向可達）；米字為 m×n 米字
（兩種晶格都算對）。求解器目標：給定任意合法狀態，輸出一條還原路徑；或證明
不可還原（目前尚未發現不可還原態）。

我們把「離目標多近」量化為**覆蓋率** σ = |S ∩ W| / |S|，W 為某個最佳放置的
目標形狀；σ = 1 且無內洞即已解。這把問題轉成「在狀態圖上把 σ 推向 1」的
優化／搜索問題。

## 1. 試過的幾條路線

1. **精確查表（小規模）**：對 4×4/s=2 這種狀態數可數的圖，反向 BFS 預計算
   所有規範狀態的最短路，求解即查表（亞秒、最優）。5×5 起狀態數爆炸，建表
   不可行。
2. **梯度聚攏（核心骨架）**：貪心局部搜尋——每步在所有合法移動裡選「讓 σ
   升最高」者，配 patience / 激進度等啟發式停機。這是免表線的主幹，方形與
   異形共用同一份迴圈。
3. **共軛填洞宏（人類解法的形式化）**：對「缺口 + 遠處凸起」用 A ∘ B ∘ A⁻¹——
   A 把凸起搬到缺口同行列並清出走廊，B 滑入缺口，A⁻¹ 撤銷。把 07 號死局從
   215s 降到 0.6s 全解。
4. **宏級 DFS 回溯**：消滅貪心順序依賴；加總時間預算實現「算不出來就停」。
5. **自動規劃入口（多段串流）**：有表先查表；無表按**當前空位數**決定先用梯度
   還是先用宏（空位少走梯度、空位多走宏），兩路都失敗則拼接部分成果或回傳
   「解到某步為止」的斷點。入口已重構為**多段播放**：查表 / 補缺宏 / 混合續算
   各段逐一上報可見狀態，實質提升即鎖定、打斷停於聚攏度最高態；配套把還原判定
   改為平移無關的剖面缺陷 Φ，並修掉續算坐標 bug（細節見《求解器現狀總結》）。

## 2. 結果（方形，免表線）

| 謎題 | 結果 | 備註 |
|---|---|---|
| 4×4 / s=2 | 0.0s | 查表，20 局 100% |
| 5×5 / s=2 | 全解 | 10 局 100%，免表 |
| 6×6 常見局 | 可解 | 角落缺口 + 遠距凸起為已知瓶頸 |
| 07 死局 | 0.74s / 35 步 | 舊 >150s |
| 04 死局 | 部分解（斷點） | 仍未完全根治 |

## 3. 異形（三角 / 米字）

同樣的「覆蓋率最大化」框架直接遷移：只換目標形狀 W 與合法移動的枚舉，搜尋
骨架不動。
- **三角**：目標為大正三角；實測大三角在斜座標下無 120° 旋轉對稱，可達放置
  只有 1 種朝向 × 平移。k=4 / s=2 基線約 8/10 復原。
- **米字**：目標為 m×n 米字，容許兩種晶格（錯開半格也算對）；性能已優化
  （每步 72.8 → 26.9ms，省 63%）。
兩者均已接入 GUI 自動求解。

## 4. 開放問題（歡迎討論）

- **通用解法**：目前是「啟發式 + 宏」的組合，不是保證終止的通用算法。作者判斷
  即便最強大模型也難短期攻克。
- **不可解形態之證明**：終極數學目標是證明「所有合法狀態都可還原」。04 號這類
  死局提醒我們：現有啟發式會卡住，但卡住 ≠ 不可解。
- **查表擴展（M5）**：三角小盤可試建表兜底；米字 4×4 = 64 片狀態數 ≈ 方形
  8×8，先緩。
- **段級覆蓋率閘門盲區**：少數惡型需更強的巨集（外層共軛推廣）。

## 結論

方形線已可生產（自動規劃 + 共軛宏讓多數死局秒解）；異形線把同一覆蓋率框架
跑通了 tri / mi。真正的硬骨頭是「保證終止的通用算法」與「證明無不可解態」——
這兩件本身就是公開的數學難題。
