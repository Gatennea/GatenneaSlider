# 求解器現狀總結

> 適合外部讀者快速了解 Gatennea Slider 求解器「試了什麼、成果如何」。
> 詳細機構與常量請看《求解器設計.md》；異形路線詳見《異形求解器計劃.md》。

## 一、目標與哲學

求解器目標是「自動復原任意合法局面」。設計哲學**只看形狀**：判定復原只問
單元是否拼成目標大圖形，不看朝向/轉置/晶格（米字轉置、三角倒置的判定口徑已
確認）。我們不做「通用神解」，定位是炫技 + 輔助作者找玩法 + 終極數學目標
（證明遊戲中沒有不可解的形態）。

## 二、矩形求解器——已落地可生產

探索過五條路線，現由自動規劃入口統一調度：

1. **查表 / BFS**：小盤（4×4 級）離線建表，亞秒級最優。
2. **梯度聚攏**（核心骨架）：貪心把單元往「目標窗」聚，聚攏度 = 與目標窗重疊率。
3. **补缺宏 / 填洞宏**：多空位宏級機構——**帶移讓位 + 粘上接走鏈**（幽靈塊追蹤
   洞漂移，只當追蹤器不當裁判），把 07 死局從 215s 降到 0.6s 全解。
4. **宏級 DFS 回溯**：消滅貪心順序依賴，加 60s 總預算實現「算不出來盡早停」。
5. **`auto_solve` 自動規劃（多段播放）**：有表先查；無表按**空位數**路由
   （≤2 混合先行、≥3 補缺宏先行）；兩路都試、失敗則拼接。2026-10-10 重構為
   **多段（multi-stage）串流**：查表 / 補缺宏 / 混合續算各段經 `emit_stage` 上報
   `{label, actions, reps, end, score, phi, solved}`，調用方逐段播放、實質提升即鎖定、
   打斷停於「聚攏度最高、並列取 Φ 最小」的歷史態（見下方「hybrid 多段播放」）。

基準：4×4 有表 0.0s；5.1 盤 0.7s/11 步；06 盤 0.6s/30 步（舊 150s 超時）；
07 盤 0.74s/35 步（舊 >150s）。

### hybrid 多段播放（2026-10-10 改造）

`auto_solve` 由「一次算完回傳整條路徑」重構為**多段串流**：

- **設計哲學**：① 計算期可見狀態；② 實質提升即鎖定該段、不反悔；③ 打斷時停於
  歷史「聚攏度最高、並列取 Φ 最小」的態。
- **段上報**：查表 / 補缺宏 / 混合續算各段經 `emit_stage` 上報
  `{label, actions, reps, end, score, phi, solved}`；無 `stage_cb` 時靜默保舊協議。
- **關鍵修正**：Φ 改委託平移無關的 `profile_defect`（已還原的偏移矩形 Φ=0，
  舊 `_phi_of` 寫死錨點會誤判為 24）；續算 checkpoint 坐標 bug（後綴從原點重放
  → 須整鏈重放）已修，由 `experiments/test_hybrid_stream.py` 的續算確定性測試鎖定。
- **現狀**：30 個 5×5/6×6 種子自然續算路徑 = 0（補缺宏 30s 內直接解或空 partial），
  續算 bug 只靠該測試覆蓋；測試全 PASS（分段 end 一致性 + 最優選擇規則 + 續算坐標）。

## 三、異形求解器（三角 / 米字）——從計劃走到實裝

《異形求解器計劃》拍板：照搬梯度聚攏（聚攏度評判標準直接移植）、目標框先行、
數字謎題不做。實作已跨過 M0–M4：

- **共享骨架 `ShapeGather`**：方形與異形共用同一份貪心循環，每形態只寫 5 函數
  適配器（聚攏度 / 動作枚舉 / 應用 / 快照 / 目標框）；方形調參結論一次改兩邊受益。
- **M0 目標框（翻案）**：原計劃寫「三角 3 個旋轉朝向」是錯的；實測大三角斜座標
  下無 120° 旋轉對稱，**可達放置只有 1 朝向 × 平移**，偏移須是 step 倍數
  （mod 過濾是合法性依據，非經驗過濾）。
- **M1 三角聚攏**：k=4 step=2 基線約 8/10 復原。
- **M3 米字聚攏**：雙晶格 A/B（錯開半格也算對）；性能每步 72.8 → 26.9ms
  （省 63%）；F2 調試面板 + GUI 求解放行。
- **M4 三角 GUI 放行**：自動求解 → 宏回放全鏈路。
- 測試鎖住：動作 5 元組不猜代表、components 與引擎 `opt` 同判據、
  `canonicalize` 不可省、score 與 `is_solved` 對齊、重放全過、方/三角無回歸。

## 四、數字謎題

已接入矩形求解器（求解器天然只看形狀，數字亂序也能復原矩形），收尾提示
「數字排列未調整請自行調整」。**數字排序公式生成器未做**（本質不同，作者暫不會）。
