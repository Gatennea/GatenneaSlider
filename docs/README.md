> 任何**曾提交过**的文档若被删除，都可用 git 找回（仓库历史中仍保留）：
> - 查历史：`git log -- <路径>`
> - 看旧内容：`git show <commit>:<路径>`
> - 临时恢复到工作区：`git checkout <commit> -- <路径>`（commit 取删除前的那次提交哈希）
