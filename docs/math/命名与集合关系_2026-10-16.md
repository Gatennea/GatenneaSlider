# 命名与集合关系（2026-10-16 定稿）

> 数学域命名唯一真源。2026-10-16 用户重新划定「可解」一词、并说明「着色集」
> 的原始定义。本文分两层：**§0 说人话**（累的时候只读这节）、**§1 严谨版**
> （论文与代码对拍用）。历史文档中的「可解集」一律指逆向可达集 B（旧口径），
> 引用时请换算。

## 0. 说人话

以 (4,4,2)（4×4 板、等级 2）为例，全部合法局面分四个圈子：

| 圈子 | 个数 | 什么意思 |
| --- | ---: | --- |
| 着色集 | 559,832 | 所有合法局面（四连通、数量对、且颜色分配与还原态一致）。每个滑块按坐标对等级取余数分颜色（游戏里的着色器，s=2 时红/绿/蓝/紫四色），还原态四色各 4 块；滑动永远不把滑块搬出它的颜色组，所以任何局面四色块数恒定 |
| 正向可达集 | 558,286 | 从还原态一步一步能走到的局面 |
| 逆向可达集 | 559,504 | 从该局面能走回还原态的局面 |
| 可解集 | 558,277 | 前两者交集：从还原态能走到它、它也能走回来。恰好就是状态图里最大的"互相都走得通"的团体 |

**两个被数据推翻的老猜想**（注意：早期文献把逆向可达集称作"可解集"）：

1. "能走到就能走回"（两个可达集一样大）——错。有的局面从还原态走得到却回不去
   （死局：(4,4,2) 9 个、(4,4,3) 6 个）；也有的局面回得去但从还原态走不到
   （(4,4,2) 1,227 个；正常打乱只会落在正向可达集里，这些态只有直接摆局面才出现）。
   两个可达集是**交叉**，不是谁包含谁。
2. "颜色块数对上了就能解"（着色集 = 逆向可达集）——错。着色集比逆向可达集大一圈
   （(4,4,2) 多 328 个、(4,4,3) 多 1,442 个），17 个已算尺寸一个不漏。

**现在的结论**：着色集 ⊇ 两个可达集的并。多出来的是"既走不到、也回不去"的局面
（(4,4,2) 319 个、(4,4,3) 1,436 个）——颜色对了也没用。

## 1. 严谨版

### 1.1 命名表

| 名称 | 符号 | 定义 |
| --- | --- | --- |
| 着色集（原始着色集合） | `A` | 色重向量与还原态相同的全部合法状态。**A 即着色集** |
| 正向可达集 | `cone` | 从还原态经合法移动可达 |
| 逆向可达集 | `B` | 能经合法移动回到还原态 |
| 可解集 | `cone ∩ B` | 既能从还原态达到、也能回去（2026-10-16 起的口径） |
| 死局 | `cone − B` | 正向可达、永远回不去 |
| 外来前驱 | `B − cone` | 回得去、从还原态走不到 |
| 两不沾 | `A − (cone ∪ B)` | 既不可达、也回不去 |
| 上帝之数 | `god` | B 上最难复原的状态到还原态的距离（回程口径） |

「可解」旧口径（2026-10-16 之前）= B，读历史结论时换算。

### 1.2 着色集（原始着色集合）

- 定义：对每块坐标 (x, y) 取 (x mod s, y mod s)，落入 s² 个同余类；各类的"1"数
  构成**色重向量**。两个状态色重向量相同 ⇔ 同一个着色集。
- 守恒：合法移动 = 某条缝某一侧的完整连通分量沿缝平移 s 的整数倍，每块的类别不变
  ⟹ 色重向量是全变换不变量。因此 cone ⊆ 着色集、B ⊆ 着色集——两种可达集都跑不
  出着色集（用户 2026-10-16 结论）。
- **A = 着色集**：复现引擎枚举的状态空间就是还原态的着色集。s=1 时类退化为一组，
  A 即全部四连通 K 格牌形——(3,3,1) 的 |A| = 1,285 正是自由九连块数、(2,3,1) 的
  |A| = 35 正是自由六连块数，可作枚举器校验。
- 色重向量实例（按 ((0,0),(0,1),(1,0),(1,1) 类序）：(4,4,2) = (4,4,4,4)；
  (4,4,3) = (4,2,2,2,1,1,2,1,1)（九类序 ((0,0),(0,1),(0,2),(1,0),…)）；
  (5,3,2) = (6,3,4,2)；5×5/s=2 = (9,6,6,4)（用户例，2026-10-16）。
- 游戏实现：`gui/cell_class.py` 定类、着色器上色（见 `docs/spec/術語規定.md` §3；
  s=2 四色即红/绿/蓝/紫）。"怎么打乱都是 9/6/6/4"即此守恒的直接后果。

### 1.3 猜想史（按新命名重述）

| 时期 | 猜想 | 结论 |
| --- | --- | --- |
| 早期 | cone = B（旧称"可达即可解"） | **推翻**：17 个已枚举尺寸中 10 个不成立——7 个相等；8 个 cone ⊊ B（外来前驱 1/29/505/8 及各自转置）；(4,4,2)、(4,4,3) 为交叉 |
| 早期 | 着色集 = B（旧称"可解集"） | **推翻**：全部 17 个尺寸 \\|A−B\\| > 0（(4,4,2) 差 328、(4,4,3) 差 1,442，最小尺寸也差 1） |
| 现在 | 着色集 ⊇ cone ∪ B | **成立**（守恒律直接推论），且为真超集，超出部分即两不沾 |
| 现在 | 可解 = cone ∩ B | **定义**。且它恰好是一个完整的强连通团体（主 SCC）：可解态 x、y 之间 x→goal→y、y→goal→x 互相可达；反之团内每个态都从还原态可达、也能回到还原态。引擎两尺寸逐数吻合（558,277 / 21,755） |

cone 与 B 是**交叉**而非包含——这一点历史文档屡被误述，论文陈述须写死。

### 1.4 量化对照（全量枚举）

| 量 | (4,4,2) | (4,4,3) |
| --- | ---: | ---: |
| \\|A\\| = \\|着色集\\| | 559,832 | 24,605 |
| \\|cone\\| | 558,286 | 21,761 |
| \\|B\\| | 559,504 | 23,163 |
| **\\|可解集\\| = \\|cone ∩ B\\|** | **558,277** | **21,755** |
| \\|cone ∪ B\\| | 559,513 | 23,169 |
| \\|死局\\| | 9 | 6 |
| \\|外来前驱\\| | 1,227 | 1,408 |
| \\|两不沾\\| | 319 | 1,436 |
| 上帝之数（回程口径） | 17 | 29 |

319 的来路（4,4,2）：559,832 − 558,286 − 559,504 + 558,277 = 319——着色集减去
两种可达集之并；因 A 本身即着色集，319 个全部着色匹配。17 尺寸全表见
`experiments/math_repro/sweep_results.csv`。附注：(4,4,3) 的还原态弱连通分量
23,171 = |cone ∪ B| + 2，即另有 2 个两不沾态与还原态弱连通（(4,4,2) 为 0）。

### 1.5 附带结论

- 色重向量还预测**排列群平凡上界** = 各类大小阶乘之积：(4,4,2) 4!⁴ = 331,776；
  (4,4,3) = 384；(3,3,1) = 9! = 362,880；(5,3,2) 6!·4!·3!·2! = 207,360；
  5×5/s=2（用户例）9!·6!·6!·4! ≈ 4.51×10¹²（未枚举，仅公式）。
- 群阶 = 上界（紧）的尺寸：(3,3,2)、(4,3,2)/(3,4,2)、(5,3,2)/(3,5,2)、(3,3,1)、
  (4,4,2)（纯随机 60 万步复算，见 `out_442_r6_pure.txt`）、(4,4,3)，及上界本为 1 的
  (2,2,2)。其余 8 个尺寸（2 行/2 列短板与 (4,3,3) 系）可达集仅剩 2~4 个态
  （步长相对板太大，几乎走不动），群阶 = 1，上界形同虚设。
- 死局（cone − B）与游戏侧黑名单 `solver/deadend_guard.py`（(4,4,2) 9 局）同批状态；
  《術語規定》§12.4 的游戏侧措辞是游戏语境表述，数学定义以本档为准。
