# 滑块谜题「切线整组滑动」独立复现问题重述

（用途：本文档自包含全部规则与待验证命题，供不接触任何现有实现的另一方独立编程复现。复现方只应依据本文档写代码，所有数值结论须由自己的程序产生。术语与《核心玩法形式化》保持一致。）

## 0. 问题框架

本问题等价地可表述为：**固定重量、单连通的 0/1 矩阵，在「切线分量平移」变换规则下的计数问题与有向图强连通分量问题**。

- **状态空间**：重量为 K（即 1 的个数固定）、四连通的有限 0/1 矩阵，模去平移与正方形对称（D4）后的等价类全体。
- **变换规则**：即第 1 节的合法移动。它在状态空间上诱导一张有向图，以下记为 G。
- **计数问题**：G 的顶点数、各类子集的大小（|A|、|cone|、|B| 等）。
- **强连通分量问题**：G 的强连通分解与凝聚 DAG 的结构。已知几个关键子结构：
  - goal 所在的极大强连通分量恰为 B ∩ cone（既可达 goal、又可被 goal 到达的顶点），在 (4,4,2) 上有 558,277 个顶点；
  - cone \ B（9 个死局）是凝聚 DAG 上的**汇点区**——整体前向封闭，其内部的强连通分解为 6 个无出边的平凡分量加一个 3 点非平凡分量（R5）；
  - B \ cone（(4,4,2) 上 1,227 个顶点）是能到达主分量、却永远不被主分量到达的外来前驱区；
  - (A \ cone) \ B（319 个顶点、76 个连通分量）与主分量完全隔离，是打乱永远生成、也永远无解的死分量区。
- **带标签版本**：同一变换规则作用在取值为 1..mn 的矩阵上，问复原矩形纤维（形状回到复原矩形的顶点）上的置换群结构——即 R2/R6。

## 1. 谜题规则（精确定义）

**状态**：平面上一个有限的格子集合，格子占据整数坐标 (r, c)（r 为行、c 为列，可为任意整数），且全体格子四连通（共享一条边即相邻）。

**谜题参数**：三元组 (m, n, s)，s 为正整数滑动步长。

**复原态（goal）**：集合 {(r, c) : 0 ≤ r < m, 0 ≤ c < n}，即 m 行 n 列无洞实心矩形。

**合法移动**（重复施加即构成游戏全部动态）：

1. 取一条**缝**（两行/两列之间的分割线）。水平缝用指标 L 表示（位于行 L 与行 L+1 之间），要求 min_r ≤ L ≤ max_r − 1；垂直缝同理用列指标 L，min_c ≤ L ≤ max_c − 1。min/max 取当前状态包围盒。
2. 取缝的**一侧**。水平缝上侧 = 坐标满足 r ≤ L 的占据格，下侧 = r > L；垂直缝左侧 = c ≤ L，右侧 = c > L。
3. 该侧的占据格在该侧内部按四连通分解为若干**侧内分量**（相邻对若被缝隔开则视为不连通；等价于"贴着缝的连通组"，即贴缝分量），取其中一个分量 G。
4. 将 G 整体平移：水平缝时 (0, +s) 或 (0, −s)；垂直缝时 (+s, 0) 或 (−s, 0)。
5. **合法性判定（关键，逐单位步）**：把该平移拆成 s 次单位步逐步施加。每施加一个单位步之后都必须同时满足：(a) 移动中的格子与静止格子无重叠；(b) 全体格子仍四连通。任何一步违反，则这整个移动非法（不是回退一步重试，而是该移动不存在）。
6. 合法则移动生效，得到新状态。注意：被选中的必须恰好是某条缝某一侧的完整连通分量，任意子集不可移动。由此**移动一般不可逆**（详见第 3 节第 4 条）。

**计数口径（重要）**：两个状态若能经平移或正方形的 8 个对称变换（旋转 0/90/180/270 度、各配一次翻转，即 D4 群）互相变换，视为同一状态。下文一切「状态数」都是在此等价关系下的等价类数。

**着色不变量**：把格子按 (r mod s, c mod s) 分成 s² 个同余类。任何合法移动把分量平移 ±s，不动其同余类，故各类格数的多重集是不变量。记 goal 的类计数多重集，A = 类计数多重集与 goal 相同的全部状态。

**三个关键集合**：

- 可达集 cone：从 goal 出发、经任意多次合法移动能到达的状态全体。
- 可解集 B：能经任意多次合法移动到达 goal 的状态全体。（移动不可逆，故 cone 与 B 一般不相等。）
- 死局：属于 cone 但不属于 B 的状态（打乱可达但永远无解）。A − B 中不属于 cone 的状态彼此构成移动图的若干连通分量，称为死分量。

**最少步数**：y ∈ B 的最少步数 = 从 y 到 goal 的最少移动次数。上帝之数 = max_{y∈B} 最少步数。

**带标签排列群（问题 R2 专用）**：在 goal 的每个格子上放一个互不相同的标签（共 m·n 个），移动规则不变、标签随格子一起移动。考虑所有移动序列，使得最终占据形状回到与 goal 相同的矩形（允许整体平移）。这些序列诱导的标签置换全体构成一个群，称为该谜题在复原矩形上的可达排列群。
