# 单步不可逆的唯一机制（粘连型唯一性）— 证明

> 状态、缝、侧、侧内分量、移动合法性（逐步验证）等记号一律沿用《核心玩法形式化.md》§1–§2，本文不重复定义。
> 本文把 R8 的经验事实提升为定理：两尺寸合计 891,663 条单步不可逆边 100% 属于"失去可分性"，
> 且"回移违规"类恒为 0 —— 前者是定理的推论，后者是引理的推论，两个零都不是巧合。
> 数据来源：本仓库 `experiments/math_repro/forward_closure.py`（4_4_2、4_4_3 全量边），独立复现 `engine.cpp` analyze 子命令（交叉印证）。

---

## 0. 结论先行

**引理 1（可选即合法）**：合法移动 u → v（分量 C，位移 s·d，落位 C' = C + s·d）之后，
若 C' 在 v 中**可选**——存在一条与 d 同轴的有效缝，使 C' 恰为该缝某一侧的一个侧内分量——
则把 C' 沿 −d 移回 s 步是 v 上的合法移动，且终态恰为 u。

**定理 1（唯一机制 / 粘连型唯一性）**：若不存在从 v 到 u 的合法移动（单步不可逆），
则 C' **失去可分性**——不是 v 中任何同轴有效缝单侧的完整侧内分量。
换言之，逆步非法只可能表现为"落位后选不中"这一种形式；
"仍能选中但回移违规"这一类机制在该规则下**逻辑上不可能存在**。

两条命题合起来读作：`{逆步非法} ⊆ {C' 不可选}`，且 `可选 ⟹ 合法`。
数据中 891,663 条不可逆边全部落在"不可选"一侧，回移违规 0 条、异常 0 条，与定理逐字对应。

## 1. 记号与前提

- u → v 是一次合法移动：分量 C（u 中某有效缝单侧的侧内分量），位移 s·d（s ≥ 1，d 为单位方向），
  v = (u \ C) ∪ C'，其中 C' = C + s·d。
- 轴相容（形式化 §2.4）：水平缝只配水平位移（a/d），垂直缝只配垂直位移（w/s）。
  故"与 d 同轴的缝"是良定义的：d 水平 ⇔ 用水平缝。
- 正向合法性（形式化 §2.5）给出四条事实：
  - **(F1)** 对每个 j ∈ {1, …, s}：(C + j·d) ∩ (u \ C) = ∅（逐步无碰撞）；
  - **(F2)** 对每个 j ∈ {1, …, s}：(u \ C) ∪ (C + j·d) 四连通（逐步不断连）；
  - **(F3)** u 四连通（状态不变量 P1；u 是合法状态）；
  - **(F4)** 有效缝两侧均非空 ⇒ u \ C ≠ ∅ 且 C ≠ ∅。
- 由 (F1) 取 j = s 得 **C' ∩ (u \ C) = ∅**；进而 **v \ C' = u \ C**（因为 v = (u \ C) ∪ C' 且两部分不交）。

---

## 2. 引理 1 的证明

假设 C' 可选，取见证：有效缝 L（与 d 同轴）与侧 σ，使 C' 恰为 (L, σ) 的侧内分量。
考虑 v 上的移动 a⁻ = (L, σ, C', −d, s)，逐条验证合法性：

**(a) 逐步无碰撞**。对每个 i ∈ {1, …, s}：

```
(C' − i·d) ∩ (v \ C') = (C + s·d − i·d) ∩ (u \ C) = (C + (s−i)·d) ∩ (u \ C)
```

- i = s 时：C ∩ (u \ C) = ∅；
- i < s 时：j = s − i ∈ {1, …, s−1}，由 (F1) 得 ∅。

**(b) 逐步四连通**。第 i 步后的整体为

```
(v \ C') ∪ (C' − i·d) = (u \ C) ∪ (C + (s−i)·d)
```

- i = s 时：等于 u，由 (F3) 连通；
- i < s 时：j = s − i ∈ {1, …, s−1} ⊆ {1, …, s}，由 (F2) 连通。

**(c) 方向与轴相容**。a⁻ 沿 −d 移动；L 与 d 同轴（可选性假设），故 −d 沿 L 的方向合法
（形式化 §2.4：每个方向 ±1 两个选项都可选，取反合法）。

**(d) 选中对象恰为 C'**。选择语义取"(L, σ) 的、含目标格的侧内分量"，而 C' 本身就是 (L, σ) 的
侧内分量，故选中的就是 C'（不涉及歧义）。又由 (F4)，v \ C' = u \ C ≠ ∅，
所以 C' ≠ v，不存在"全员选中"退化情形。

**(e) 终态恰为 u**。s 步后：

```
(v \ C') ∪ (C' − s·d) = (u \ C) ∪ C = u
```

(a)–(e) 覆盖形式化 §2.5 合法性的全部条目，故 a⁻ 合法，u 是 v 的一步邻居。∎

**证明未使用的假设（值得注意的两点）**：

1. **未使用 C ∩ C' = ∅**。分量沿自身方向滑动时可与自身原位重叠（如长条沿长轴滑 2 格），
   上述五步对自重叠移动同样成立——证明逐条只依赖 (F1)(F2)(F3) 与集合恒等变形。
2. **未要求见证缝 L 就是原缝 L₀**。逆步可以借另一条同轴缝选中 C'，不影响论证。

**推论 1（回移违规恒为 0）**：凡 C' 可选，逆步必合法且逐步检查全过。
因此"可选中但回移时碰撞/断连"的边数量恒为 0——这不是统计巧合，是 (a)(b) 两步的直接后果。
`forward_closure.py` 三分类中的"回移违规"与"异常"两桶必为空。

---

## 3. 定理 1 的证明（逆否）

若 v → u 无合法移动，而**假设** C' 可选，则由引理 1，(L, σ, C', −d, s) 就是从 v 到 u 的合法移动，
矛盾。故 C' 不可选：它不是 v 中任何同轴有效缝单侧的完整侧内分量。∎

"唯一机制"的确切含义：

- 逆步非法的一切情形都伴随同一个可观测后果——C' 失去可分性；
- 唯一能与之竞争的备选机制（"选得中但移不回"）被引理 1 排除；
- 因此不存在第三种不可逆机制。这正是数据里"其他机制 0 条"的理论根源。

## 4. 与全量数据的对照

**口径 A（本仓库 `forward_closure.py`，直接对应本定理）**：
对每条单步不可逆边，检验 `moved ∈ _all_side_components(y, 同轴缝)`，三分类：

| 分类 | 含义 | 4_4_2 | 4_4_3 | 定理对应 |
|---|---|---|---|---|
| 粘连型（不可选） | C' 不是任何同轴缝单侧完整分量 | 880,858（100%） | 10,805（100%） | 定理 1（必要性） |
| 回移违规 | 可选但回移碰撞/断连 | 0 | 0 | 引理 1（必为 0） |
| 异常 | 可选且回移合法却无逆边 | 0 | 0 | 定理 1 的逆否（不可能） |

两尺寸合计 891,663 条，逐边验证与两条命题逐字一致。

**口径 B（独立复现 `engine.cpp`，同族描述性细分）**：以"落位后与主体的贴缝接触数变化 +

封套（贴缝等量换边、无包含关系）133,617（15.2%）+ 其余两桶 0。
两桶都是"失去可分性"内部的几何形态描述，不与定理冲突，构成交叉印证

## 5. 边界与留给后续的问题

1. **本定理只取单向**：`逆步非法 ⟹ C' 不可选`。反向（不可选 ⟹ 逆步非法）未证也不总成立——
   自重叠移动（C ∩ C' ≠ ∅）中，逆步理论上可由 C' 的某个真子集（如 C' \ u 的部分）经另一条缝完成，
   此时 C' 不可选但边仍可逆。论文中陈述定理须保留单向性。
2. **粘连 / 封套二分的完备性**（接触数不减、gluedBig 桶为 0）目前仍是经验事实，未给出组合证明，
   可作为定理 1 之后的第二个细化命题。
3. **强不可逆**（跨 SCC、有限步也回不去，如死局入口边）不在本文范围；
   本文只处理单步口径。有限步可逆猜想已被死局推翻（见《遊戲衍生的數學問題.md》）。
4. 下游用途：定理 1 把"不可逆性"完全归约为"可分性"这一纯组合性质，
   死局结构刻画（为何全是 3 行扁条无洞）可在此基础上只讨论可分性的丧失模式。
