# 貓九滑塊（GatenneaSlider）核心玩法形式化

> 本文自包含：不依赖任何源代码或工程文件，任何 AI 读完后应能精确理解玩法、
> 复现状态空间、并理解既有求解思路。所有"实测事实"均有来源标注。

---

## 0. 一句话直觉

所有方块散在无限网格上、**始终连成一片**。每次操作是：选一条"缝"（两行/两列之间的线），
再选缝的一侧，把那一侧中**贴着缝、且连成一片**的那组方块，**沿缝的方向**整体滑一格（可多格）。
目标：把所有方块拼成一个 m×n 的实心矩形（旋转 90° 也算）。方块**没有编号、互相不可区分**。

---

## 1. 状态空间

- 网格：整数格点平面 ℤ²。坐标记 (r, c)，r=行、c=列。
- **状态** S：有限格点集，S ⊂ ℤ²，|S| = K（K = m·n 恒定）。
- **邻接**：两格相邻 ⇔ ‖(r₁,c₁)−(r₂,c₂)‖₁ = 1（4-邻接，上下左右）。
- **单连通**：S 在 4-邻接关系下是单一连通分量（从任一块可走到所有块）。

**性质 P1（可达性约束）**：初始状态是矩形（单连通），且合法移动保持单连通
（见 §2 的移动合法性），因此**一切可达状态都单连通**。

---

## 2. 合法移动（核心规则）

### 2.1 缝（gap）
- **水平缝** H_k：位于行 k 与行 k+1 之间的直线（k ∈ ℤ）。
- **垂直缝** V_k：位于列 k 与列 k+1 之间的直线。
- **有效缝**：缝必须穿过块集合内部：
  - H_k 有效 ⇔ min{r : (r,c)∈S} ≤ k < max{r : (r,c)∈S}；
  - V_k 有效 ⇔ min{c : (r,c)∈S} ≤ k < max{c : (r,c)∈S}。

### 2.2 侧（side）
缝把块集合切成两侧（用 ≤ 与 > 分界，缝线本身归入含等号一侧）：
- H_k：**上侧** above(S) = {s∈S : r ≤ k}；**下侧** below(S) = {s∈S : r > k}。
- V_k：**左侧** left(S) = {s∈S : c ≤ k}；**右侧** right(S) = {s∈S : c > k}。

### 2.3 侧内分量（选中的对象）
给定缝与侧，把该侧的块按 4-邻接分组，但**相邻对若被缝隔开（分别落在两侧）则视为不连通**。
得到的连通组称为**侧内分量**。

**性质 P2（贴缝引理）**：合法状态（单连通）中，任何非空侧内分量**必含贴缝块**
（H_k 上侧含行 = k 的块、下侧含行 = k+1 的块；V_k 同理）。
因此"贴着缝的连通组"与"侧内分量"等价，下称**贴缝分量**。

### 2.4 移动方向（关键，容易想错）
移动方向**只能沿缝的方向**（与直觉"穿过缝"相反）：
- H_k（水平缝）→ 只能左右滑：位移 ±e_c = (0, ±1)。
- V_k（垂直缝）→ 只能上下滑：位移 ±e_r = (±1, 0)。

每个方向 ±1 两个选项都可选（即缝两端都可滑）。

### 2.5 一次移动（操作）
一次操作 a 由四要素决定：
1. 有效缝（H_k 或 V_k）；
2. 侧（上/下 或 左/右）；
3. 该侧的一个贴缝分量 C；
4. 沿缝方向的位移方向 d（±e_c 或 ±e_r）与步数 s（游戏常用 s=2）。

将 C 整体平移：C → C + s·d。**合法性（逐步验证）**：对每一步 i = 1..s：
- 无碰撞：(C + i·d) ∩ (S \ C) = ∅；
- 保持单连通：((S \ C) ∪ (C + i·d)) 仍单连通（性质 P1）。

（即中间任何一格被堵或断开，整次移动非法，一步都不走。）

### 2.6 动作的数学表示与工程坑
- 数学上动作 = (缝, 侧, 分量 C, 方向, 步数)；**分量 C 必须显式给出**。
- 工程上用 4 元组 (gap_type, gap_line, side, move_dir) 表示动作——**它不包含分量信息**：
  同一 (缝, 侧) 下可能同时存在多个贴缝分量（它们通过另一侧的块间接连通）。
  若实现只按"该侧第一块"选分量，就会移动错对象。
  正确做法：用**分量代表格 rep_cell ∈ C**（C 中任一格的坐标）编码分量，动作记为
  (gap_type, gap_line, side, move_dir, rep_cell)。

## 3. 目标状态

S 是**实心矩形**（可旋转、可平移）：

```
∃ (r₀, c₀) ∈ ℤ²，使得
S = {r₀, …, r₀+m−1} × {c₀, …, c₀+n−1}   或
S = {r₀, …, r₀+n−1} × {c₀, …, c₀+m−1}
```

即 |S| = m·n 且 S 的外接矩形恰为 m×n 或 n×m 且内部无空洞。
（注：这与游戏 `is_solved` 的实现一致——m×n 与 n×m 都判定为完成。）

---

## 4. 状态图、对称性与距离

### 4.1 状态图
顶点 = 状态；无向边 = 存在一次合法移动互达（移动可逆：同一分量反方向滑回）。

### 4.2 规范等价（对称性）
两个状态若相差**平移**或**旋转/镜像**（平面 D4 群：4 种旋转 × 2 种镜像），视为等价：
- 平移：S ~ S + (Δr, Δc)；
- 旋转/镜像：S ~ ρ(S)，ρ ∈ D4。

**规范状态** = 等价类代表元：先平移到原点（减去最小行、最小列），
再取 8 个对称变体中**字典序最小**的坐标排序。

### 4.3 距离与直径
- 状态间距离 = 规范状态图上的最短路径长度（1 次移动 = 1 步）。
- 用反向 BFS 建表可得全状态精确距离。

**实测事实（作者提供 / 已建表）**：
| 谜题 | 规范状态数 | 距离范围 / 直径 | 备注 |
|---|---|---|---|
| 4×4, s=2 | 559,504 | 0–17（直径 17） | 完整表 |
| 4×4, s=3 | 23,163 | — | 完整小表 |
| 5×5, s=2 | 不可行 | — | 深度 2 球已达 7,337 状态，外推上亿 |

## 5. 解法词汇与思路（供讨论求解算法）

### 5.1 窗口、洞、缺口、凸起
给定一个候选目标窗口 W（m×n 或 n×m 的放置位置）：
- **洞**：W \ S（窗口内的空格）；
- **缺口**：贴着窗口边界的洞（洞在窗口边缘，内部洞较易处理）；
- **凸起**：S \ W（窗口外的块）；
- **聚拢度**：|S ∩ W| / |S|，越接近 1 越好；等于 1 且无洞即已解。

### 5.2 双层共轭宏（人类解法的核心结构）
对"缺口 + 远处凸起"的基本解法是共轭 **A ∘ B ∘ A⁻¹**：
1. **外层 A**：一系列合法移动，把凸起块 P 搬到与缺口同行/列对齐，并清出 P 到缺口之间的
   直通走廊（缺口保持为空）；
2. **内层 B**：P 沿走廊连续滑入缺口（B = "填洞"）；
3. **外层逆 A⁻¹**：按逆序撤销 A 的各步（P 已留在缺口内，其余块回到原位）。

推广：B 可以是**多格刚性凸起**整体填入等宽洞（教程第 5 关），称"刚体宏"。
这是解"角落缺口 + 远距凸起"的关键套路，搜索算法没有它时会陷入巨大启发平台。

### 5.3 实用求解流水线（免建表）
```
梯度聚拢（提高聚拢度）→ 填洞宏（填内部洞）→ 逐次单缺口定向搜索（每次消一个缺口）
```
- 逐次消解：每段搜索只要求"洞数减 1"，每段结束后重新锚定坐标系（从初始态重放全部已选动作）。
- 搜索启发：窗口洞数 + 凸起到最近洞的步长距离。

**实测事实（混合求解器）**：4×4/s=2 在 20 个随机打乱局上 100% 全解；
5×5/s=2 在 10 局上 100% 全解（全程免建表）；6×6 常见局可解，
但"角落缺口 + 远距凸起"残局是已知瓶颈（需刚体宏）。

## 6. 与工程实现的对应（便于对接代码）

| 数学概念 | 工程表示 |
|---|---|
| 缝 | `gap_type` ∈ {'h','v'}，`gap_line` = k |
| 侧 | `side` ∈ {'above','below'}（h）或 {'left','right'}（v） |
| 方向 | `move_dir` ∈ {'w','s','a','d'}：w=上、s=下、a=左、d=右（Δ(row,col) = (-1,0),(1,0),(0,-1),(0,1)） |
| 步数 | `step`（游戏常用 2；存档中单步可能合并多次基础移动） |
| 分量标识 | `rep_cell` = 分量中任一格的 (row, col) |
| 规范状态 | `canonicalize`：平移归一 + D4 八对称 + 字典序最小 + 位打包为整数 |

方向与缝的配对（不可交叉）：h → a/d；v → w/s。
