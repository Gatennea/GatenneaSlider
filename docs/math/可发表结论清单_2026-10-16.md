## 0. 说人话

我们做了一个新类型的滑块谜题（沿缝把一整块连通滑块平移 s 格），把它画成状态图后，
得到了一条**严格证明的定理**和一批**算出来的结果**：

- **定理（主菜）**：一步走不回去，原因只有一种——搬过去的块落位后和主体粘在一起、再也单独框不住。
  这个结论是证明出来的，对所有尺寸都成立，不只在某一两个尺寸上。
- **算出来的事**：两个尺寸（4×4/s=2、4×4/s=3）的全部局面都数清了；两个「直觉上应该相等」的
  集合其实不相等（被数据推翻）；在一系列尺寸上，滑块的编号可以任意两两对换。
- **开放问题（不是结论！）**：比如「用转换机从 s=1 抬升出 s=2 的对换公式」这条，原理清楚但**还没证出来**，
  构造也还没做；死局的吸引盆、死局充分性等都还没定。

**发表够不够？够。** 一条通用定理 + 干净的负值结果 + 一批普查数据，已经是一篇像样的
娱乐数学（recreational mathematics）论文体量。最该投的地方是 MOVES 会议论文集（AMS 出版）
或《Recreational Mathematics Magazine》；投之前先 arXiv 占优先权和 OEIS 登记序列。

## 1. 已确定结论（按可信度分级）

### A 级 · 严格定理（与尺寸无关，证明已成形）

**A1. 粘连型唯一性定理（单步不可逆的唯一机制）**
- 结论：一次合法移动 `u→v`（分量 C 沿缝平移 s 落位 C′），若 `v→u` 无合法逆步，
  则 C′ **失去可分性**——不是 v 中任何同轴有效缝单侧的完整侧内分量。
  逆否：只要 C′ 还可被某同轴缝单独框住，逆步必合法且回到 u（引理 1）。
  故「单步不可逆」**只可能**表现为粘连这一种机制；「选得中却移不回」在规则下逻辑不可能（推论 1，恒为 0）。
- 证据：**证明不依赖具体尺寸**（只用到合法性四条件 F1–F4，对一切 m,n,s 成立），是通用定理。
- 计算印证（逐边全量，非抽样）：
  - (4,4,2)：**880,858 / 880,858** 全粘连，回移违规 0、异常 0；
  - (4,4,3)：**12,926 / 12,926** 全粘连，回移违规 0、异常 0。
- ✅ **2026-10-16 已补齐，17/17 尺寸全部有全量佐证**：此前扫描表对 (4,4,2)、(5,3,2)、(3,5,2) 记 `None`，
  本次 `-fullsticky` 补跑：(5,3,2) 249,113/249,113、(3,5,2) 249,113/249,113、(4,4,2) 880,858/880,858；
  其余 14 个尺寸 `sticky == irr_B` 逐行成立。
  ⇒ **可放心写「全部 17 个尺寸 100% 粘连型，回移违规 0、异常 0」**，无悬空表述。
- 定理单向性须保留：`逆步非法 ⟹ 不可选` 已证；反向 `不可选 ⟹ 逆步非法` 未证（自重叠移动可有例外）。

### B 级 · 计算确定的普查与负值结果（全量枚举，确定性）

**B1. 两个可达集是交叉，不是包含（推翻两个老猜想）**
- `cone`（正向可达）= 从还原态走得到的；`B`（逆向可达）= 能走回还原态的。
- `cone = B` 不成立：17 个已枚举尺寸中 8 个有 `cone ⊊ B`（外来前驱），7 个相等，(4,4,2)/(4,4,3) 为交叉。
  →「能走到就能走回」被反例推翻（只需一个反例即足以推翻全称猜想）。
- `着色集 A = B` 不成立：17 个尺寸全部 `|A−B| > 0`（(4,4,2) 差 328、(4,4,3) 差 1,442，最小也差 1）。
  →「颜色块数对上就能解」被推翻。
- 成立的只有：`A ⊇ cone ∪ B`（守恒律直接推论），超出部分即「两不沾」。

**B2. 四个尺寸的全量状态普查（确定性枚举）**

| 量 | (4,4,2) | (4,4,3) |
| --- | ---: | ---: |
| \|A\|（着色集/全部合法局面） | 559,832 | 24,605 |
| \|cone\| | 558,286 | 21,761 |
| \|B\| | 559,504 | 23,163 |
| \|可解 = cone∩B\| | 558,277 | 21,755 |
| 上帝之数（回程口径） | 17 | 29 |
| 死局（cone−B） | 9 | 6 |
| 外来前驱（B−cone） | 1,227 | 1,408 |
| 两不沾（A−cone∪B） | 319 | 1,436 |
| 单步不可逆（B 内） | 880,858（20.63%） | 12,926（13.99%） |

注：上帝之数有**回程/正向两口径**，须注明；(4,4,2) 回程 17、正向 23。

**B3. 死局几何刻画（必要条件，数据支撑）**
- 「弱或」：存在某行或某列凑不出 s 连段 —— (4,4,2) 9/9、(4,4,3) 6/6 成立，稳健必要条件。
- 「真·强或」（全行或全列都凑不出）—— 0/15 恒假，「真而无用」由数据坐实。
- 「无洞」—— 15/15 成立（强几何旁证，非充分）。
- 短边 ≤3 只对 s=2 成立（s=3 死局短边 4~6），**不普适**。

**B4. 死局吸引盆推翻「不可解 ⟺ 流进死局」猜想（2026-10-16 新增，计算确定）**
- basin = `{x : x 能走到某个死局}`（反向 BFS 一次即得）。曾猜「不可解 ⟺ 会流进死局」，**实测为假**：
  - **(4,4,2)** basin = **559,513** = |B|(559,504) + 9 死局 ⇒ **每个可解态都能掉进死局**；不可解 328 中 **319 个（两不沾态、76 个孤立死分量）到不了任何死局**。
  - **(4,4,3)** basin = **23,170** = |B|(23,163) + 7；不可解 1,442 中 **1,435 个到不了死局**。
- ⇒ 「能走进死局」既不蕴含不可解、也不被不可解蕴含。**死局不是不可解性的根源**；不可解性主要来自**孤立死分量**（困在自己分量里永动）。此结果取代原 O2，并使「刻画孤立死分量」成为新的首要开放问题。

### C 级 · 计算验证的群论结果（随机游走+闭包，确定性「撞满上界」）

**C1. 可达排列群 = 颜色类内全对称群（⇒ 任意两同色滑块可单独对换）**
- 判据：色重向量给天花板 `∏(各类大小!)`；随机游走收集生成元、取乘法闭包，闭包 = 上界 ⟹
  可达群 = 上界 = 各类内对称群之直积 ⇒ 任意两同色滑块可净效果对换（对称群由对换生成）。
- 已撞满上界的尺寸（对换「做得到」）：
  (3,3,2)=96、(4,3,2)/(3,4,2)=2,304、(5,3,2)/(3,5,2)=207,360、
  (3,3,1)=362,880、(4,4,2)=**331,776**、(4,4,3)=384、(2,2,2)=1。
- 群阶 =1（一个都换不了）的反例：(6,2,2)/(2,6,2)=1,296 上界却只有恒等可达；短板与 (4,3,3) 系同理。

> `out_442_r6_pure.txt`（60 万步纯随机 + 多种子）。**论文只能引 331,776。**

**C2. 距离分布形态（计算）**
- 五张成品表（2_3_1~4_4_3）均为**单峰钟形、中心近似正态、左截断、右长尾**；偏度有正有负，无统一方向。

## 3. 发表可行性评估

**结论：已确定结论足以构成一篇娱乐数学论文。** 理由：

1. **有通用定理（A1）**——不是两尺寸数据，而是对所有 m,n,s 成立的组合定理，配全量验证。
   这是论文的脊梁，分量相当于「给这类谜题不可逆性唯一机制定性」。
2. **有干净的负值结果（B1）**——两个最自然的猜想被反例推翻，叙事清晰、易读、有戏剧性。
3. **有实质普查（B2/C1）**——上帝之数、状态数、群结构，是谜题数学的标准产出。
4. **方法论诚实**——已记录「抽样假阳性」「单种子困子群」「扫描表陷阱值」等坑，论文可写「我们怎么避免假结论」，反而加分。
