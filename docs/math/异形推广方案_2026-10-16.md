# 异形（三角 / 米字格）推广的数学形式化方案

> 受众：作者本人 / 第二篇论文骨架。2026-10-16。
> 真源：几何与规则以代码为准——`game_triangle.py`、`game_mi.py`、`gui/cell_class.py`、
> `gui/mi_view.py`；方形见 `docs/math/核心玩法形式化.md`。本文不重新发明几何，只把它们
> 收进**一个**统一抽象，并指出哪些结论可原样迁移、哪些真正需要新证明。

---

## 0. 说人话

我们之前只研究了方形板子。但游戏里本来就有另外两种板子：三角板（拼成一个实心正三角形）
和米字格板（每个方格被两条对角线切成 4 块直角等腰三角）。三者的**移动本质相同**——
沿一条「缝」把一侧的一块连通整体平移若干格、保持连通——差别只在**板面长什么样**、
**缝有哪几族**、**还原态是什么**。

好消息：论文里最有分量的几个结论**几乎不用改**就能搬过去：

- **「走不动」的判定**（走不回来只可能因为那块粘住了）——它的证明只用「移动＝沿缝平移一块、
  逆转＝原路退回」，跟板面形状无关，**三种板子通用**。
- **两个可达集交叉**、**着色只是必要条件**、**死局吸引盆的负结果**——这些是纯图论结论，
  对任何状态图都成立，换板面直接重算数字即可。

真正需要「新方法」的只有一件事：**怎么统一地写出三种板子的「守恒着色」**。
我们找到的关键钥匙是——**别用「坐标 mod s」，而用「合法移动生成的平移格子 Δ 的陪集」**。
方形、三角、米字格都恰好是这一句话的特例（而且现有代码 `cell_class.py` 已经是这么算的，
只是按形态分开写）。这就是「新的方法」，它把三种板子收进同一套公式。

---

## 1. 统一抽象：一个「板型」= (格空间 Λ×Ω, 方向生成元 D, 缝 Σ, 还原态 S₀, 权重 K)

把三种板子统一成下面这个对象（论文里就正式定义成这个）：

**定义（板型 B）** 由下列数据组成：

1. **格空间** `C = Λ × Ω`：
   - `Λ` = 格心的平移格子（仿射格子）；
   - `Ω` = 有限的朝向标签集（方形 `Ω={∅}`、三角 `Ω={▲,▼}`、米字 `Ω={N,E,S,W}`）。
   - 一个「局面」= `C` 的一个有限子集（且连通）。
2. **方向生成元** `D` = 一组「一步」平移向量（步长 `s` 时移动 `s·d`，`d∈D`）。
3. **缝** `Σ` = 把当前局面切成两半的「切割」，每个缝配一个**平行方向**（只允许沿缝平移）。
4. **还原态** `S₀`（一个具体的格集合），以及**权重** `K=|S₀|`。
5. **合法移动** = 选缝 `σ`、取其一侧的某个连通分量 `C`、沿 `σ` 的平行方向平移 `s·d`
   （`d∈D` 与 `σ` 平行），要求平移途中不与另一侧重叠、且整体仍连通（两端非空）。

**关键量：平移格子 Δ。** 定义 `Δ(B,s) = ⟨ s·d : d∈D ⟩ ⊆ Λ`（由所有合法一步平移生成的子格子）。

**守恒着色定理（统一版）**：合法移动只把每个格子平移 `s·d`（`d∈D`），故每个格子所在的
`Λ` 的陪集 `x + Δ` 与朝向 `ω∈Ω` 在移动中不变。于是

> **着色 = `Λ/Δ` 的陪集 × `Ω`**。合法移动保持着色不变。

这就是我们想要的统一「守恒量」。下面验证它精确复现三种板子（**关键检验**：方形必须回到
`(r mod s, c mod s)`）。

## 2. 三形态实例化

| | 方形 | 三角 | 米字格 |
|---|---|---|---|
| 格空间 `Λ` | `Z²`（(r,c)） | 斜坐标 `Z²`（(i,j)，基 `e1,e2`） | 半格 `{(p/2,q/2):p≡q mod 2}`（(r,c)） |
| 朝向 `Ω` | `{∅}` | `{▲,▼}`（up） | `{N,E,S,W}`（q） |
| 一步方向 `D` | `±e_x, ±e_y` | `±e1, ±e2, ±(e2−e1)`（6 个） | `±e_x, ±e_y, ±½(e_x±e_y)`（8 个） |
| 缝族 `Σ`（平行方向） | `h/v`（2 族） | `h(j=line)/p(i=line)/n(i+j=line)`（3 族） | `h/v/d1(\)/d2(/)`（4 族） |
| 平移格子 `Δ(B,s)` | `s·Z²` | `s·Z²`（斜坐标） | `s·⟨(1,0),(0,1),(½,½)⟩ = s·{(p/2,q/2):p≡q mod 2}` |
| 守恒着色 | `(r mod s, c mod s)` | `(i mod s, j mod s) × up` | `((r+c) mod s, (r−c) mod s) × q` |
| 还原态 `S₀` | `m×n` 实心矩形 | 边长 `k` 实心正三角形（`k²` 块） | `m×n` 实心矩形（每格 4 块俱全） |
| 权重 `K` | `m·n` | `k²` | `4·m·n` |

（表中的缝、方向、Δ、还原态、权重全部照抄 `game_triangle.py` / `game_mi.py` / `cell_class.py`。）

### 2.1 方形复现检验（抽象必须退回旧公式）

方形 `D = {±e_x, ±e_y}` 生成 `Z²`，故 `Δ = s·Z²`，`Λ/Δ = Z²/sZ² ≅ (Z/s)²`，陪集就是
`(r mod s, c mod s)`，`Ω={∅}`。✓ 与旧公式逐字一致——**说明统一抽象不是推翻重来，
而是把旧公式收进更一般的框架**。

### 2.2 三角：Δ 也是 `s·Z²`，多一个朝向不变量

`D = {±e1, ±e2, ±(e2−e1)}`，其中 `e1,e2` 已生成斜坐标 `Z²`，故 `Δ = s·Z²`，陪集
`(i mod s, j mod s)`；朝向 `up∈{▲,▼}` 平移不变，故着色 = 位置类 `× up`。与 `cell_class.py`
一致。**注意**：三角的还原态（正三角形）有 `120°/240°` 旋转等价，`S₀` 不是唯一的
「矩形式」目标——这是它相对方形的一个**结构性差异**，会影响 cone/B 的定义（见 §4.2）。

### 2.3 米字格：Δ 带半格、且奇偶决定类数（「双重晶格」的来源）

`D` 含 `(½,½)`，故 `Δ = s·⟨(1,0),(0,1),(½,½)⟩ = s·L₀`，其中 `L₀={(p/2,q/2):p≡q (mod 2)}`
（A 晶格 ∪ B 晶格）。陪集用 `((r+c) mod s, (r−c) mod s)` 表达——因为 `r±c` 对两种晶格
都恒为整数（正是这一点让「用 `r mod s`」失效，而 `r±c` 恒定）。朝向 `q` 平移不变，
故着色再乘 `q`。与 `cell_class.py` 一致。

**类数随 s 奇偶变化**（这是米字格最微妙处，也是「双重晶格」的代数解释）：
- `s` **偶**：`s/2` 为整数，斜向平移 `±(s/2,s/2)` 保持晶格；又 `(r+c)` 与 `(r−c)` 恒同奇偶，
  故只有「同奇偶」的余数对可达 ⇒ **实际类数约为 `s²/2`**（两个余数不能自由组合）。
- `s` **奇**：`s/2` 为半整数，斜向一步把整盘换到另一晶格（A↔B）；同一陪集横跨两个晶格 ⇒
  **`s²` 类**。
- 这解释了为何米字格在 `s` 奇偶下行为不同，也解释了代码里「按晶格过滤会误砍一半可达集合」。

## 3. 哪些结论可原样迁移（不需要新证明）

**命题 A（图论层，完全通用）**：`cone / B / 可解=cone∩B / 死局 / 外来前驱 / 两不沾 /
可达排列群 + 上界 ∏(类大小!)` 的**定义与分析方法**对任何状态图成立。把板型换成三角或
米字格，只需重新枚举得到新数字即可。**（本文所有「负结果」都属于这一层：交叉、着色不充分、
死局吸引盆推翻——它们不是方形的性质，而是状态图的性质。）**

**命题 B（主定理，形状无关）**：*不可逆定理*「一步不可逆 ⟺ 该块落位后失去可分性」
的证明只用四条合法性事实（(F1) 平移途中不碰撞、(F2) 途中保持连通、(F3) 起点连通、
(F4) 两端非空）加上「逆转＝沿平行缝原路回退」。这对**任何**满足「移动＝沿缝平移一侧
连通分量、且可沿平行缝选中它」的板型成立——三角（3 族缝）与米字格（4 族缝）都满足。
故 **定理在三种板子上逐字成立**，只需把「同轴缝」换成「平行于该步方向的缝」。

**命题 C（着色守恒）**：§1 的统一着色定理对三形态都成立，且给出各自的上界
`∏(类大小!)`（三角多乘 2、米字格多乘 4，因朝向不变量）。

## 4. 真正需要新工作的部分（第二篇论文的实质内容）

### 4.1 米字格的奇偶 / 双晶格（最硬的一块）
- 精确推导三种板型在 `s` 奇偶下的**实际类数**与每类**大小**（`∏(类大小!)` 上界要用真实类大小）。
- 回答：米字格的可达排列群是否也「撞满上界」？（方形三角已知撞满；米字格因双晶格
  与朝向 `q` 的额外约束，**未必**，这是真正的新问题。）
- 澄清「双重晶格」的完整结构（哪些类横跨 A/B、斜向缝的 rank 为何按朝向 +1）。

### 4.2 三角的还原态对称性
- 正三角形有 `120°` 旋转、`60°` 反射等价 ⇒ `S₀` 是一个**轨道**而非单点。`cone/B/可解`
  需相应地按「还原态轨道」定义（可达 = 能到达该轨道中任一姿态）。这会改变数字，
  需重新推导定义并枚举。
- 三角「无 120° 对称」（可达放置仅 1 朝向 × 全部平移）与旋转等价并存，需辨清。

### 4.3 三形态的枚举与普查
- 用同一套引擎抽象，把 `repro_fast` 从「矩形专用」泛化到「板型 B」，才能对三角/米字格
  跑 cone/B/死局/吸引盆/粘连核验/距离分布。**这是工程前提**。
- 三角 `k` 与米字格 `m×n` 的状态空间可能迅速变大（类比方形 `K>16` 的引擎上限），
  需评估可算尺寸。

### 4.4 排列群与对换公式（若要延伸到第二篇）
- 三形态各自「群是否撞满上界」需实测；撞满才有「任意两同色可对换」，才有对换公式问题。

## 5. 研究纲领（可执行路线）

1. **把 `repro_fast` 抽象成「板型 B」**：现有代码已把三形态的格空间/方向/缝/着色分得很清
   （`DIRECTIONS` / `GAP_DIRECTIONS` / `cell_class`），抽一个统一 `BoardType` 接口即可，
   枚举/粘连/吸引盆/BFS 逻辑复用。→ 解锁对三角/米字格跑全部现有实验。
2. **先算三角 `k` 小尺寸**（如 `k=2,3`）的 cone/B/死局/距离分布，验证抽象无误
   （可用「菱形对称态与方形同构」这一已知结论做交叉检验）。
3. **算米字格小尺寸**，重点解决 §4.1 的奇偶/类数/群是否撞满。
4. **主定理迁移**：对三角/米字格各跑一次 `-fullsticky`，把「不可逆⟺粘连」从「方形已证」
   升级为「三形态全证」——这是第二篇最漂亮的一个定理（同一证明、三个板型）。
5. 有余力再做异形的距离分布 OEIS 序列。
