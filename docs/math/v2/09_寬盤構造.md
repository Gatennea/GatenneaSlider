## 1. 幾何底座：寬盤的縫與首步全集

### 1.1 前提與記號

實心盤 `P = {0,…,n−1} × {0,…,m−1}`：行標 `r = 0..n−1`（短邊 `n`），列標 `c = 0..m−1`（長邊 `m`）；`e_r = (1,0)`、`e_c = (0,1)`。

本節**不假設 `n ≤ s`**——窄盤前提只在 `07 §3` 的 L3／L4 內用到。底下的兩塊磚是 `07 §3.1` L1〔已證〕（實心盤上任一有效縫的每一側恰有一個側內分量，且等於該側與盤的交，即整塊板條）與 D3（縫按行／列切分）。L1 只依賴實心性，故寬盤同樣成立；這正是「兩板投影都是完整區間」的根據。

### 1.2 L2′：水平縫判據〔已證〕

> **L2′**　實心 `m×n` 盤。對任一水平縫 `H_k`：上板或下板沿 `±e_c` 平移 `s` 格**合法 ⟺ `s ≤ m−1`**。判據與縫編號 `k`、側別、方向無關。

**證明**　取 `H_k`，被移動的側內分量 `C` 為上板（行 `0..k`）或下板（行 `k+1..n−1`），其餘板記 `Q`。按 D6 對 `i = 1..s` 逐步檢查。

**(a) 碰撞永不可能**

1. `C` 的行集 `R_C` 與 `Q` 的行集 `R_Q` 互斥：D3 按行切分，一側行標 `≤ k`、另一側 `> k`。
2. 第 `i` 步落格 `C_i = C + i·(0, ±1)`：**列方向平移不改變行標**，故 `C_i` 的行集仍是 `R_C`；`Q` 未動，行集仍是 `R_Q`。
3. 碰撞要求某格同時屬於 `C_i` 與 `Q`，其行標須同時落在 `R_C` 與 `R_Q`；`R_C ∩ R_Q = ∅`，故無此格。
4. 板是剛體平移，平移是雙射，分量內部不會自撞。

故 `|S'_i| = |S|` 對所有 `i` 成立，D6(a) 恆過。

**(b) 連通性 ⟺ 縫上兩板列投影每一步相交**

1. 兩板各自是實心矩形（L1），剛體平移不破壞板內 4-連通。
2. 兩板之間唯一可能的鄰接對是縫上的垂直對：同一列 `c`、行 `k` 與行 `k+1` 上下相鄰。
3. 未動板 `Q` 的縫行列區間恆為 `[0, m−1]`（L1：整塊板條的列投影完整）。
4. 動板 `C` 的縫行列區間：右移 `i` 為 `[i, m−1+i]`；左移 `i` 為 `[−i, m−1−i]`。
5. 相交條件：右移時 `[0, m−1] ∩ [i, m−1+i] ≠ ∅ ⟺ i ≤ m−1`；左移對稱。
6. 跨板鄰接對存在 ⟺ 兩區間相交；不相交則兩板間全無鄰接對，全盤斷成兩個 4-連通分量，D6(b) 失敗。

- **正向**：`s ≤ m−1` 時每個 `i ≤ s ≤ m−1`，區間恆相交；配合 (a)，移動合法。
- **反向**：`s ≥ m` 時取第 `i = m` 步（`m ≤ s`），右移後區間 `[m, 2m−1]` 與 `[0, m−1]` 不相交（左移對稱 `[−m, −1]`），跨板無鄰接，移動非法。

**與 `k`／側／方向無關**：`k` 只決定縫落在哪一行；兩板列區間都是完整 `[0, m−1]`。側別只決定動上板或下板、方向只翻轉區間符號，相交條件只依賴區間長度 `m`。∎

**依賴**：D3、D4、D5、D6、L1。

### 1.3 L3′：垂直縫判據〔已證〕

> **L3′**　實心 `m×n` 盤。對任一垂直縫 `V_k`：左板或右板沿 `±e_r` 平移 `s` 格**合法 ⟺ `s ≤ n−1`**。判據與 `k`、側、方向無關。

**證明**　行列互換，逐句式對照 1.2。

**(a)** 動板 `C` 的列集 `Col_C` 與未動板 `Q` 的 `Col_Q` 互斥（D3 按列切分）；行方向平移不改列標，故落格列集仍是 `Col_C`，與 `Col_Q` 無交集，碰撞不可能。

**(b)** 跨板鄰接只可能是縫上的水平對（同行 `r`、列 `k` 與 `k+1` 左右相鄰）。`Q` 的行投影為 `[0, n−1]`；`C` 下移 `i` 為 `[i, n−1+i]`、上移 `i` 為 `[−i, n−1−i]`。相交 ⟺ `i ≤ n−1`。

- **正向**：`s ≤ n−1` ⟹ 每步相交 ⟹ 合法。
- **反向**：`s ≥ n` 時取第 `i = n` 步，投影 `[n, 2n−1]` 與 `[0, n−1]` 不相交（上移對稱），斷連通，非法。∎

**依賴**：D3、D4、D5、D6、L1。

> 這兩條把 `07 §3.2` L2 的 `n ≤ s` 前提整個拆掉了，同時把 `07 §3.3` L3「垂直縫全禁」翻面：**窄盤 `V` 全禁不是垂直縫的天性，只是 `s ≥ n` 的算術後果**。寬盤 `min > s` ⟹ `s ≤ n−1` 且 `s ≤ m−1`，故 `H`、`V` 兩族首步全開。

### 1.6 判據旁證〔觀察〕

對 `m ∈ 2..5`、`n ∈ 2..4`、`s ∈ 1..4` 共 48 組實心盤跑同一生成器：`H` 全合法 ⟺ `s ≤ m−1`、`V` 全合法 ⟺ `s ≤ n−1`，48 組 0 例外；每一軸要嘛全合法、要嘛全非法，沒有中間狀態。反向情形的解析證明在 1.2、1.3 的反向段，48 組只是旁證（同 `07 §3.10` 第 1 條的口徑說明）。

### 1.7 梯田族在寬盤：`T_h ⊆ F`、`T_v ⊆ F`〔已證〕

**定義（`07` D12 去掉 `n ≤ s` 前提）**　`S ∈ T_h(m,n,s)` 若：(1) `S` 恰佔 `n` 行，第 `r` 行是長度恰為 `m` 的連續橫條，起點列 `x_r`；(2) `x_0 = 0`；(3) `δ_r := x_r − x_{r−1} ∈ sℤ` 且 `|δ_r| ≤ m−1`（`r = 1..n−1`）。`T_v` 是它的轉置：恰佔 `m` 列、每列一段長 `n` 豎條、相鄰列偏移 `∈ sℤ` 且 `|·| ≤ n−1`。

**`T_h ⊆ F` 的建構（照 `07 §3.5` L5，只走 `H` 縫）**　目標偏移 `(0, x_1, …, x_{n−1})`；按邊界 `r = 1..n−1` 依次處理，在 `H_{r−1}` 上取下側後綴行段 `P_r = {r..n−1}`，反覆平移 `±s` 直到第 `r` 行起點達標。逐步合法性：

1. **`P_r` 是側內分量**：梯田相鄰行投影相交（`|δ| ≤ m−1`），後綴鏈逐行相通（`07 §3.4` 預備步的分組論證只用到相鄰行投影相交，與 `n ≤ s` 無關）。
2. **軸向**：全程 `±e_c`，不碰垂直縫。
3. **碰撞**：前綴 `{0..r−1}` 與後綴 `{r..n−1}` 行集不相交，列平移不改行標（同 L2′(a)），D6(a) 恆過。
4. **中間態連通**：`δ_r* ∈ {−Ks,…,Ks}`、`K = ⌊(m−1)/s⌋` ⟹ `|δ_r*| ≤ Ks ≤ m−1`；單調路徑上每個中間值 `|j·s| ≤ |δ_r*| ≤ m−1`，縫上兩區間相交（L2′(b)）。
5. **步數對齊**：`δ_r* ∈ sℤ`，從 0 出發按 `±s` 走必恰好抵達。

**與窄盤前提的關係**：本建構全程不用 L3（窄盤垂直禁令），只用廣義 L2′ 的 `s ≤ m−1`；寬盤 `m > s` 給出 `m−1 ≥ s`。故 `T_h ⊆ F` 在寬盤上照樣成立。`T_v ⊆ F` 是整段轉置：只走 `V` 縫、`±e_r`，碰撞用 L3′(a)、連通用 L3′(b) 的行投影相交。

### 1.8 `T_h` 在寬盤上不封閉〔否證（封閉性）〕

窄盤 `07 §3.4` L4 的封閉結論，第 (i) 步整條依賴 L3：`n ≤ s` 時 `V` 縫全非法，合法移動只剩 `H`。寬盤上 `V` 首步就合法（表 1-1 的 8 條），而落點是豎梯田態、不在 `T_h`。故：

- `T_h ⊆ F` 成立（1.7），但 `T_h` **不是** `F` 的封閉子族；
- `07 §3.4` 的「梯田族對合法移動封閉」只在 `n ≤ s` 域內有效，搬到寬盤即失效。

這也正好說明寬盤與窄盤的差別不在「能不能動」，而在**兩個方向的縫同時可用**：窄盤只有一排橫向跑道，寬盤多出一整族縱向跑道，兩者交替就離開梯田族。

### 1.9 底座：`T_h ∪ T_v`，以及「混合階梯態」為何還不能算定理

**已證的底座**：`T_h ∪ T_v ⊆ F`（1.7），且這兩族在寬盤上互不包含、也不封閉（1.8）。窄盤的 `F = T`（`07 §3.6` T2）在寬盤只剩「`F ⊇ T_h ∪ T_v`」這種單向陳述。

**混合階梯態**：深度 ≥2 的樣本裡既不在 `T_h` 也不在 `T_v` 的態（1.10 的 `mixed` 欄），由 `H`、`V` 交替滑動產生。目前**沒有只看形狀的結構判據**，也只能給生成式定義（「由 `H`／`V` 交替滑若干次可得的態」）。

**一個要主動擋掉的寫法**：先前一份草稿把底座族寫成

```
W := T_h ∪ T_v ∪ M,   M := {S : S ∉ T_h, S ∉ T_v}
```

這等於 `W =` 全體 4-連通態，於是「`W ⊆ F`」變成「全空間 ⊆ `F`」——這是假命題（兩不沾態 `N` 就不在 `F`），而「`F ⊆ W`」變成廢話。這種用補集補出來的定義不能當底座，本稿不採用。混合階梯態要進底座，必須先給出真正的幾何刻畫；在給出之前它一律標〔猜想〕。

## 2. 一次對換的顯式配方

### 2.1 引理：對換只能發生在同一個著色類〔已證〕

> **L-9.1**　一次合法走法把分量 `C` 整體平移 `s·d`（`d ∈ {±e_r, ±e_c}`）。則 `C` 內每個標籤的殘餘類 `ρ = (行 mod s, 列 mod s)` 前後不變。

**證明**

1. 合法走法的位移恆為 `s·d`（D5；`07 §3.2` L2 也正是靠這個位移量說話）。
2. 同餘式：`r' = r + d_r·s ≡ r (mod s)`、`c' = c + d_c·s ≡ c (mod s)`，故 `ρ(r',c') = ρ(r,c)`。
3. 分量是剛體平移（D4），分量內標籤隨分量整體移動；未動分量的標籤位置不變。∎

**推論〔已證〕**　一個「僅兩格互換、其餘歸位、落點格集與完成態相同」的閉環，被換的兩個標籤各自留在原殘餘類 ⟹ 兩格必須同 `ρ` 值，即同一著色類。**跨類對換不可能由任何合法序列實現。**

**與上界的對應**：這條守恆正好解釋為什麼上界長成按類分塊的直積 `Π_c S(C_c)`——跨類不交錯，每個類只能在自己的 `S(C_c)` 裡動。上界原話在 `07 §5.1 (i)`〔已證，P1 推論〕。

> 順帶修正一處流傳的引用錯誤：這條上界**不在 `07 §4`**。`07 §4.2` 是窄盤必要性（G = 1）、`07 §4.3` 是充分性〔猜想〕；`G ⊆ Π_c S(C_c)` 在 `07 §5.1 (i)`。本稿所有引用都用 §5.1(i)。

### 2.2 配方要解決的最小情形

寬盤 `min(m,n) > s`，取同一著色類內、**軸向對齊且相距 `s` 格**的一對格（同行或同列）。`s=1` 即普通相鄰格；`s=2` 時同類格的行／列座標差是 `s` 的倍數，最小就是錯開 `(s,0)` 或 `(0,s)`。

序列的書寫口徑：每步標明 `H_k`／`V_k`、側別（上／下、左／右）、方向與位移 `±s`；全部沿縫。分量以「正規化相對格集圖案」記錄，回放時按圖案＋側別＋方向匹配，不綁定錄製時的標籤——這一條是必要的：拼接多個閉環後，前一輪已經換過標籤，按標籤認分量會對不上（實作時真的踩到這個坑）。

## 3. 二分律充分性的依賴鏈

### 3.1 要證的命題

`07 §4.3` 的充分性〔猜想〕是：實心 `m×n` 盤、`min > s` 時 `G = Π_c k_c!`（每個類撞滿對稱群）。把它拆成可驗的零件：

> **命題 S（條件式）**　若下列三條成立，則 `G ⊇ Π_c S(C_c)`；配合 3.2 的上界即 `G = Π_c S(C_c)`，充分性成定理。
>
> - **(i)** 每個著色類內可實現任兩格對換；
> - **(ii)** 每個著色類內可實現三循環；
> - **(iii)** 對換與三循環互不干擾（或存在「每次都在同一局部跑道重做」的可重定位版本）。

**為什麼夠**：對稱群 `S(C_c)` 由該類內的對換生成（`k_c ≥ 2` 時），三循環是另一組生成元；有了 (i) 就已生成 `S(C_c)`，(ii) 是備用／更短的路。(iii) 解決的是「把局部置換拼成全類置換」時，先做的置換不能被後續動作打亂。

### 3.2 上界〔已證〕

`G ⊆ Π_c S(C_c)`，見 `07 §5.1 (i)`（P1 推論）。本稿的 L-9.1（2.1）給出同一事實的機制版：標籤殘餘類守恆 ⟹ 任何閉環置換都把 `C_c` 映到自身 ⟹ 限制落在 `S(C_c)`。

 (i)  類內任兩格對換      〔部分〕  2.3–2.5 三尺寸各一對實跑

## 4. 判據（次線）：`F` 的補集

> 本節是「時間夠才做」的次線。結論先說：**沒撐出雙向判據**，只守住一條必要性的正確版本與一條〔猜想〕。撐不住的一律標出來，不拿普查口徑冒充判據。

### 4.1 「弱或」探測器的精確定義

- **投影**：把局面投影到全幅行與列（無牆口徑，`00 §5.5`；棋子可伸出原窗口，所以不能只看 `m×n`），逐條非空行／列算最長連續占格段。
- **弱或**：存在某一非空行或某一非空列，不含長度 ≥ `s` 的連段。
- **強或**：全部行都不含 `s` 連段，或全部列都不含。
- **判讀方向**：普查是在 `C−R`（回不去）態上統計「弱或成立」的比例，驗的是「不可解 ⟹ 弱或」這條**必要性**；它不是全集上的精確率。跑過 11 個尺寸（`01 §3.1`、`01 §3.2`）。
- **漏網口徑**：唯一反例 2×8 是 `C` 內的一個 **D4 類**（引擎狀態＝類代表，`00 §2`），既不是字面擺法層，也不是 K 層。
- **`s=1` 退化**：每條非空線自動含 ≥1 連段，弱或恆假；各 `s=1` 尺寸的唯一不可解態漏網即此故，例外形狀也是整塊矩形（`01 §3.2`）。

### 4.2 實心矩形為什麼漏得過去〔已證（定義層）〕

實心 `k×l` 矩形：每行投影是長 `l` 的連段、每列是長 `k` 的連段；`k,l ≥ s` 時弱或必然為假。探測器只問「有沒有一條線湊不出 `s` 格」，它**分不出 4×4 完成態與 2×8**——對填滿矩形的長寬比是結構性盲點。

〔觀察〕本稿覆核（`_work/_wide_C_probe.py`）：2×8（`s=2`）的色向量與 4×4 相同，落在 `C` 內；弱或為假、強或也為假；4 條字面滑動收成 2 個平移落點（互為鏡射），類層出度 1（`01 §3.1`）。

**定位**：探測器對不可解性是**必要不充分**（普查層〔已證〕）——非矩形的不可解態全部帶弱或（`02` #7b/#7e/#7h），但弱或成立不預測不可解。

### 4.3 能不能升格成 `C−F` 的判據

- **量級〔部分，本稿算術〕**：按 `01 §2` 兩欄相減，`(4,4,2)` 的 `C−F` 不到 `C` 的 0.3%，`(4,4,3)` 約一成一；對照窄盤 `07 §3.6` 的 `|F| = q^{n−1}`（極小），寬盤的 `F` 幾乎蓋滿 `C`。分解上 `C−F = (R−F) ∪ N`：困局 `T` 在 `F` 內，不進 `C−F`。
- **口徑警告〔已證〕**：現有弱或普查全落在 `C−R`；**`C−F` 的 `R−F` 半邊（外來前驅）沒有任何專門的幾何統計**。把 `C−R` 的探測結論搬到 `C−F`，目前沒有證據支撐。
- **候選一「某行／列湊不出 `s` 連段」（即弱或）**：〔部分〕已測寬盤上「非矩形且所有行列皆有 `s` 連段」未見不可解反例；但反向誤報壓倒性——本稿 3×3 `s=2` 全形狀閉包的 773 態中有 772 態帶弱或〔觀察，平移正規化口徑〕。一個幾乎恆真的條件不可能當判據。
- **候選二「孤立塊／缺口／洞」**：〔已證（負面）〕洞對可解性幾乎沒有預測力（`02` #7c #7j）；規則保證全盤單連通，本來就沒有第二分量可測。缺口／細頸對應的是標籤層分檔，不是形狀層可達性（`02` #26 #29）。
- **263 孤立死〔已證，全量〕**：`(4,4,2)` 的孤立死分屬 127 個 SCC、最大 8 態，出口邊 0、入口邊 2；主體是密封打轉區（`01 §3.4`）。一眼可判的幾何判據仍缺（接 `03` O-5），本稿沒補出來。
- **〔猜想〕** 寬盤 `C−F` 的主體不是局部形狀缺陷，而是「跑道不夠繞回所屬類」的全域現象，與跑道長 `R0` 的分帶同源（`02` #30 #35）。**證據缺口**：沒有 `C−F` 半邊的形狀普查；`R0` 與 `F` 可達性沒逐類對上。

### 4.4 實心矩形在寬盤上的可達性

`07 §3.6` T2 只管窄盤 `min ≤ s`（那時 `F` = 梯田族）；寬盤上 `k,l > s` 的實心子矩形能否從完成態到達，現有文檔無定理。

- 〔觀察〕本稿小閉包（丟標籤、平移正規化、CAP 250000）：3×3 `s=2` 閉包 773 態，實心矩形只有完成態本身；3×2 `s=1` 只有完成態及其轉置（D4 同類）。全量口徑下 `(4,4,2)` 的 `C` 內非目標實心矩形只有 2×8（短邊恰等於 `s`，不滿足 `k,l > s`），`(4,4,3)` 只有目標（`01 §3.1`）。
- `K ≥ 12`：**未做**（記憶體紅線，沒跑全量帶標籤 BFS）。

### 4.5 小結

寬盤判據這條線的現狀是：必要條件有了（弱或，且已知它在 11 個實心尺寸內漏的正是實心矩形），充分條件與「`C−F` 的幾何刻畫」都沒有。可交付的版本只有一句話——**「弱或」是必要的、對實心矩形結構性失效的探測器，不是判據**。其餘留〔猜想〕，不升級。

### 4.6 會後補：`R−F` 半邊的統計（2026-11-24，`01 §3.7`）

§4.3 的口徑警告指出「`R−F` 沒有專門統計」。這一塊本輪補上了，結論是**否定**的：

- 數字：`R−F` = 1,227（(4,4,2)）／1,408（(4,4,3)）／8（(6,2,2)）／1（(4,2,2)）／0（(3,3,2)）。大盤有上千個，比困局（9／6）多兩個數量級。
- 形狀：短邊九成落在 4–7、**沒有一個實心矩形**、96% 以上無洞、**出度全部 > 0**、**弱或 100%**。而普通可解態也有 99.6% 滿足弱或。
- 因此 §4.3 的候選一（弱或）、候選二（洞／缺口）在 `R−F` 上都是恆真——不是判據，是常態。形狀層這條路到此為止，`C−F` 的刻畫只能換到顏色／連通性層（已記成 `03` O-23）。
- 同時修正本節 §4.2 的適用範圍：**「弱或失效的唯一場合＝實心矩形」只在 11 個實心尺寸內成立**；本輪在 (6,2,2) 找到 42 個、在 (4,2,2) 找到 1 個非矩形的「無弱或卻不可解」態（兩尺寸不在 11 尺寸表內，待複現）。(4,4,2) 的唯一反例仍是 2×8（state 89014，出度 1），與原結論一致。
- 副產品：「兩不沾」不是「卡死」——(4,4,2) 的 319 個兩不沾裡 273 個出度 > 0。
