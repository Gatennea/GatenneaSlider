# 「移形換位」的真實身份與能力邊界

> 2026-11-25。查證 `E:\program_project\other\wkbddtest\GatenneaSlider` 中名為「移形換位」的代碼段，並做三個探針。
> 結論：它是**幾何復形**的雙向 BFS，**不處理排列**。這一點決定了二級「對換」不能靠它證明。

## 2 它是什麼

**不是手寫宏，是搜尋器。** 註釋寫得明確：

> 實現 = step 級組移動作的全量雙向 BFS：正向從當前局面、反向從全部還原態（面積界內實心 m×n 矩形）出發，小側優先擴展，中間相遇。
> 動作枚舉與引擎同語義：選縫一側的連通分量平移 step 格……**只發 `k=step` 動作**。
> BFS 最短性 → 動作數不劣於用戶手解。

所以要點三條：

1. **只發整 `step` 格位移**（`step=2` 即只走 2 格）；
2. **反向目標是「全部還原態」集合**，不是單一完成態；
3. **BFS 最短路 → 輸出的是最短序列，不是可複用的模板**。

---

## 3 判定口徑：`is_solved` 平移不變

`game.py:1039`：

```
外接框 height == m 且 width == n（或轉置），且框內每一格都被佔滿
```

**沒有錨定到某個固定原點。** 所以「還原」是一族**平移副本**，不是唯一形狀。這條口徑直接影響下面兩個探針的解釋——`_swap_fill` 的「解出了」= 走到某個平移的實心矩形。

## 4 三個探針（`(4,4,2)`，`max_nodes` 2 萬～6 萬）

| 局面 | 結果 | 解釋 |
|---|---|---|
| `(0,0)` 塊移到 `(0,-1)`（1 格缺口） | 未命中（2 萬節點，21.9 s；6 萬節點，67.3 s） | **形狀不連通**：`(0,-1)` 的鄰格 `(0,0)`、`(1,-1)` 都空，成孤塊 → 任何移動都非法。**與 mod 無關** |
| `(0,0)` 塊移到 `(0,-2)`（2 格缺口） | 未命中（節點 1，0.0 s） | 同上，`(0,-2)` 孤立 |
| 左上 `2×2` 整組移到 `(2,4)-(3,5)` | **2 步** | 位移 `(+2,+4)`，是 2 的倍數 → 合法；`('v',1,'left','w',(2,0))` + `('h',1,'above','d',(0,0))` |
| `(0,0),(0,1)` 兩塊整移到 `(0,-2),(0,-1)` | **1 步** | 一對伸出的格直接右移 2 格歸位 |

**修正我先前的一個誤判**：我原以為「1 格缺口」未命中是 mod 不變量在起作用。**不是**。那兩個局面本身違反 4-連通——塊被孤立在盤外，遊戲根本不會產生這種形狀。真正的 mod 自洽性是另一回事：`_swap_fill` 只發 `step` 格動作，所以它**天然**不會改變 `(r mod s, c mod s)`，不需要額外檢查。

## 5 能力邊界（關鍵）

`_swap_fill` 的狀態 = `frozenset(coords)`，**只有座標，沒有標籤**。

推論：

1. 它判斷「解」只看形狀，**看不到「哪塊在哪」**；
2. 所以「滿盤但兩塊對換」對它而言就是 `is_solved() == True`，直接返回 `[]`；
3. **它給不出對換序列，一步都給不出。**

因此二級「同 mod 對換」的顯式路徑**不可能**從 `_swap_fill` 取得——那需要帶標籤的搜索，而這批數據在 `sequences/swap_442_all24_cases.json`（24/24 全覆蓋，9–11 步）。

| 層 | 對象 | 工具 | 現狀 |

| **排列層**（對換） | 塊的**標籤分配** | 帶標籤 bidi 搜索（`sequences/`） | 有，一級 15/28/45 對、二級 8/14/24/25 對全覆蓋 |

**使用者所說的「構造單缺口 4×4 再調補缺求解器拿序列」**，拿到的是**形狀層**的復形序列；「對換」那一層已經由另一套數據獨立解決。

兩層都齊了，缺的只剩「尺寸無關的參數化」這一步——而那不是 BFS 能給的。

## 7 可複用的調用方式（夜裡/以後直接抄）

```python
import sys
sys.path.insert(0, r"E:\program_project\other\wkbddtest\GatenneaSlider")
from solver.ml.fill_macro import _swap_fill

coords = frozenset({...})          # 塊佔的格子，必須 16 個、整體 4-連通
acts = _swap_fill(coords, 4, 4, 2, max_nodes=40000, verbose=True)
# acts: [(gap, line, side, dir, rep), ...]；None = 預算內未找到
```

**三個坑**：
- `coords` 必須整體 4-連通，否則節點 1 就停；
- `len(coords)` 必須等於 `m*n`，否則直接返回 `None`；
- `dir` 是 `w/s/a/d` = **上/下/左/右**（`'d'` 是右，不是左）。
