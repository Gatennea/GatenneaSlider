# 03 開放問題

> **用途**：只放「還沒有答案」的問題。已在 `02` 有結論的一律不進來；有一半證據但不夠下結論的也不算開放，那是**待核**，留在 `01` 的狀態欄。
> **判據**：既沒有全量枚舉、也沒有證明 → 才算開放。
> **維護規則**：問題解答後**不要刪行**，把它移到 §4「已結案」並寫明結論去了 `02` 的哪一條。這樣才不會出現「明明做過又重做一次」。

編號 `O-n` 終身不變，`02` 與實驗紀錄用編號回指。

## 5. 寫作紀律

1. **猜想不得與結論同表**。猜測只能出現在本檔，且標「猜想（未驗）」。
2. **每條必須回答「玩家可感知嗎」**。答否的歸第 2 層，不要混進社區文檔。
3. **成本只准三檔**：一次引擎（小時內算完）／要寫證明／要外部數據。寫「中等」「較難」等於沒寫。
4. **禁止把待核寫成開放**。待核＝已有部分證據，位置在 `01` 狀態欄，不在本檔。
