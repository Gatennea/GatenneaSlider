## 1. 規則卡：我們拿什麼去比

> 這張卡是「尺」。文獻比對時只問：對面的模型在這七格裡有幾格與我們不同。

| 維度 | 本模型取值 | 這一維為什麼會改變結論 |
|---|---|---|
| **R1 棋子** | 多聯骨牌（polyomino）多塊，形狀可混，重量 K 有限 | 若對面是單位格或 1×2 車，狀態空間的粒度不同，gadget 可行性也不同 |
| **R2 邊界** | **無牆**：狀態＝格點集合，可整條搬出原包圍盒（`00 §5.5`） | 有牆 ⟹ 狀態空間有限、可達集有界；無牆 ⟹ 可數無窮，判定問題要先界定輸入編碼 |
| **R3 移動生成** | 沿**縫**：縫把當下盤面切成兩半，取縫一側的**貼縫連通分量**整坨平移；H 縫左右、V 縫上下（`07 §1` D2–D5） | 一般滑塊是「單塊沿自身長邊滑」，沒有縫這個二級結構；縫是**全域切分**，不是局部碰撞 |
| **R4 連續性** | 位移 ±1 逐步檢查，每步不碰撞、全程整盤 4-連通；**中間態不留**，失敗即整次移動不存在（`07 §1` D6） | 「可中途停」會把一次操作拆成多步，狀態圖膨脹；「不留中間態」使操作原子化，可達集反而收窄 |
| **R5 步長量子化** | 單次位移恆為 s 的整數倍（預設 s=2） | 這是顏色不變量（`07 §2`）的來源，也是 T2 裡 q 的來源；一般滑塊是 ±1 格 |
| **R6 勝負** | 回到實心 `m×n` 矩形，**位置與 D4 朝向任意**，不是回到原位（`00 §5.6`） | 「回原位」會逼實作追絕對座標並讓 R 變小；「回形狀」才是本模型的目標語義 |
| **R7 不變量** | 每格顏色 `(行 mod s, 列 mod s)`；一步位移是 s 的倍數 ⟹ 色向量不變（**必要條件，非充分**，`07 §2`） | 有 R7 的模型才有「著色集」這個中間層；缺 R7 的模型不需要顏色論證 |

**一句話**：本模型＝**無牆 ＋ 縫驅動 ＋ s 量子化 ＋ 原子化平移 ＋ 以形狀恢復為目標**的多聯骨牌謎題。

### 2.2 最近的三支，逐條說清爽在哪

**Torus Puzzle（#9）：整條帶推移的唯一切實文獻，但它把「帶」釘在環面上。** 這是候選方向「只能沿給定方向移動整條帶」唯一命中者：一次動作確實搬動一整行或一整列，這與我們的「整坨平移」語義最重疊。但三條硬差異：(a) 條帶是**固定行列**，不是由當下盤面誘導出來的縫；(b) 環面週期邊界讓「繞回」取代了無牆平面——**週期邊界既不是牆也不是無牆，是第三種情形**；(c) 棋子是標記 token，沒有「整盤四連通」這種幾何約束，也沒有 s 量子化（drag 變體一次可移任意格數）。因此它能「搬整條」，但不能「在無牆平面上搬、且只能搬 s 格」。

**Sliding Squares（#10）：唯一在「連通」這一維與我們同向的模型。** 全程維護邊連通，這點與 R4 最合；但移動單元是單塊單位 square、限於包圍盒、步長 1。差別在後果：它守恆的是「連通性」這個 predicate，我們守恆的是「色向量」這個 counting invariant（`07 §2`）——前者只切掉一部分狀態，後者把可達集釘在一個等差格點上。

**GSTP（#4）：唯一允許「多塊同時動」的模型，但那是並行、不是縫。** 它允許單一 escort 下多塊並行滑動，外觀上像我們「整坨搬」；但盤面固定、有空格／escort、碰撞是幾何約束，目標是給定配置而非「回實心矩形」。它的「並行」是為了模擬倉儲機器人，沒有縫這個二級結構，因此也不能解釋我們的顏色不變量與 T2。

### 2.3 其餘各支的一句話定位

- **Rush Hour／Klotski／Hearn–Demaine 滑塊（#1–#3）**：都是「有框、單塊、可停」的滑塊族。有框 ⟹ 可達集有界；單塊 ⟹ 沒有「貼縫連通分量」這個決策層；可停 ⟹ 一次操作可拆成多步，狀態圖更大。三條都與我們相反，因此只能算部分同構。
- **15-puzzle／Wilson（#5）**：不變量是**置換奇偶**，把態空間切成兩個排列陪集；我們的不變量是色向量，切的是 `s×s` 格的計數。同為「不變量刻畫」，但不是同一套對象。
- **Peg solitaire（#6）**：棋子數遞減的跳吃，與「守恆平移」在數學上是兩個不同的守恆律。
- **Push-Pull／Sokoban（#7–#8）**：動作者是 agent，一次一格，牆是題面元素；缺縫、缺量子化、缺「回形狀」。
- **Inglenook（#11）**：軌道類代表，但「帶」是物理軌道，平面幾何不存在。
- **Tilt（#12）**：唯一同為 polyomino 棋子且方向正交的模型，但「選誰動」由全局外力決定，玩家沒有選擇權——這是我們把它列為僅主題相鄰、而非部分同構的關鍵。
- **Warehouseman（#13）**：連續運動規劃的歷史基線，離散化之後才可能與我們對話。

## 3. 三特徵交集：未找到（問題 2）

> 三特徵＝① 移動限定在縫；② 單次位移為固定步長 s 的整數倍；③ 無邊界（可移出原包圍盒）。

| **本模型** | ✔ 縫由當下盤面誘導，H 縫左右／V 縫上下 | ✔ 恆為 s 的整數倍 | ✔ 狀態只是格點集合 |
| Rush Hour | ✘ 方向由車軸鎖死，無縫 | ✘ 任意格 | ✘ 6×6 框 |

| Sliding Squares | ✘ 單 square | ✘ 單位格 | ✘ 包圍盒 |

| 其餘（peg／Sokoban／Push-Pull／Inglenook／Warehouseman） | ✘ | ✘ | ✘ |

**結論（正面回答問題 2）：未找到任何同時具備三特徵的已知模型。** 這是本檔最硬的一條負面結論，也是投稿定位裡「規則新穎度：高」的唯一支撐——它支撐的是「未見前人做過」，不是「已有人做過但我們更好」。

### 3.1 我們到底獨特在哪（四句）

1. **縫是誘導出來的，不是畫死的。** Torus 的行列、line-push 的掃描方向都是題面固定；我們的縫隨盤面形狀改變（`07 §1` D2），所以「同一個規則在不同盤面上生出不同的候選操作」這件事本身是新的結構。
2. **s 量子化把可達集釘在等差格點上。** 文獻裡的不變量幾乎都是奇偶性（15-puzzle）、排列群（Wilson／Brunck–Kwan）或群型（line-push）；「步長是 s ⟹ 色向量守恆 ⟹ 可達集只落在某些格點」這條鏈，在檢索範圍內沒有對應物。
3. **無牆與量子化合起來，造出一個文獻沒有的落差。** 一般尺寸下狀態空間可數無窮（無牆），窄帶 `n ≤ s` 時卻被 T2 收成 `q^(n−1)` 的多項式小族（`07 §3.6`）。「同一個模型，寬一點就變無窮、窄一點就變多項式」這個相變，是既有模型裡找不到的對照點。
4. **棋子是多聯骨牌，且要求全程整盤 4-連通。** Sliding Squares 只對單位 square 維護邊連通；我們對異形骨牌的整盤拓撲負責，這使「一次操作」的合法性檢查多了一層全局條件。

### 4.1 判斷：T2 **未找到**等價文獻結論

檢索覆蓋六類來源（puzzle 可達性、token sliding reconfiguration、polyomino 枚舉、transfer-matrix 砌磚、height function、行列平移 puzzle），共 15 組檢索詞。所有命中都落在兩個框架之一：

- **「標記單位塊＋空格＋單塊／單 token 移動」的排列模型**（Wilson、Karpman–Roldán、Brunck–Kwan、line-push、token sliding、Torus）；
- **「磚塊覆蓋區域」的砌磚模型**（polyomino 枚舉、transfer matrix、height function）。

T2 屬於第三種、兩邊都不是：**無標記、幾何排布族、由「搬整坨」與 s 量子化共同逼出來的乘積式計數**。

三條「差在哪」值得記下來，因為它們正好說明 T2 為何不能由既有定理推出：

1. **與 B（Karpman–Roldán）的差**：它同樣是窄盤，但它的窄盤結論是「順序不能變」，可達集是 `(m₂−1)!` 個**排列**；我們的窄盤結論是「每行變成一條長 m 的橫條，行間只能整體錯開 `sℤ` 且 `|δ| ≤ m−1`」——這是**幾何**而非排列，且限制「錯開多少」而非「誰排在哪」。我們的結論反而更嚴：它把偏移量離散化成 `q` 個格點，等於把「每行能滑到哪」也一併釘死。
2. **與 C（line-push）的差**：它是唯一對可達集做**完整**刻畫的相鄰模型，但分類用的是群論（trivial／cycle／Alt(5)／Alt(n)），輸出是「哪些置換可實現」；T2 輸出是「哪些排布可達、有幾個」，計數是乘積 `q^(n−1)`，不是群階。
3. **與 F（transfer matrix）的差**：`q^(n−1)` 的乘積形式很容易被誤認成 transfer matrix 的特例。不是。transfer matrix 處理的是**行與行之間有耦合**（磚必須拼滿整個區域、邊界要對齊）；T2 的相鄰行只被「位移差 ∈ sℤ 且 `|δ| ≤ m−1`」約束，**n−1 個 δ 互相獨立**，所以乘積直接成立。若硬把每行當成一個狀態、把 δ 當成轉移，會得到一個 `q×q`、只依差值的 Toeplitz 型矩陣：**每個狀態恰有 `q` 條出邊，出邊數不隨位置改變**，所以長度 `n−1` 的路徑數直接是 `q^(n−1)`，不需要任何位置權重。文獻的 transfer matrix 之所以通常只能給有理生成函數，正是因為那些模型的轉移數**依位置而變**（邊要對齊、磚要拼滿）；我們的約束恰好沒有這種位置依賴——這既讓計數可算，也正是它不構成既有計數定理特例的原因。

**一句話**：與 T2 形式最像的文獻（transfer matrix）假設更強、與 T2 結論最像的現象（窄盤可達集有限）對象不同；**沒有文獻把「位移差 ∈ sℤ 且 `|δ| ≤ m−1`」這個約束寫成封閉乘積式**。

### 4.2 這條負面結論的效力邊界

只說「在檢索範圍內未找到」。三類東西本檔不能排除：(a) 未刊手稿與小眾實體謎題；(b) 非英文（日／韓／中）的 puzzle 研究；(c) 以「reconfiguration」為名、但規則等價的論文（檢索詞未必覆蓋）。若日後要對外宣稱新穎，這三類應各補一輪再定稿。

### 5.2 若要做 PSPACE 歸約，缺的是什麼（雙面評估，未證）

成熟的 PSPACE 歸約路徑幾乎都走 NCL：QBF → AND/OR constraint graph → 在謎題裡嵌入可切換的 vertex gadget、接線、信號分裂，並靠**固定不動的牆塊**維持平面完整性。對照本模型，兩面的疑慮同時存在。

**(a) 表達力可能太弱。** 移動被鎖在縫上、單次位移恆為 s 的整數倍，狀態變換被著色集（行 mod s、列 mod s 不變，`07 §2`）與 4-連通硬性夾住。已有的完整刻畫顯示：短邊 `n = min ≤ s` 時正向可達集就是梯田族，`|F| = q^(n−1)`（`07 §3.6`）。在窄帶口徑下，可達集只是一個低維參數族——**能動的自由度少到裝不下 NCL 需要的「每個 vertex 一個可鎖定的有限內部狀態」**。更關鍵的是：本模型沒有 agent，也沒有現成的固定牆塊來充當 NCL 構造中的 cell-wall；縫是全域切分，任何「局部 gadget 隔離」都得先證明「縫序列能把兩個 gadget 隔開」。

**(b) 表達力可能反而過強、判定資格先不成立。** 無牆 ⟹ 狀態空間可數無窮。若輸入編碼不給定有限包圍盒、容許的擴張範圍或位移上界，狀態空間不隨輸入規模多項式封閉，**連 PSPACE 的成員資格都無法先驗成立**；目標矩形位置與朝向任意、中間態不留，又讓「存在一個多項式尺寸的包圍盒足以容納某條求解路徑」本身變成待證的有限化引理。第 5.1 節那 8 條 bounded-box 歸約，一條都不能直接移植。

**合起來看**：本模型目前既無已知的 PSPACE 難度歸約，也無正面的多項式算法結論；上面兩面只是**結構風險評估**，不是定理。若硬要選一側下注，(a) 的可證性明顯高於 (b)——因為窄帶的 T2 已經把「可達集小」寫成可檢查的式子，而 (b) 只是編碼層面的形式障礙。

### 5.3 若要繼續做，最該先補的三件事

1. **界定有限化口徑**：正式寫出輸入編碼（初始格點集合、目標矩形參數、步長 s），並證明（或證否）「存在多項式尺寸包圍盒覆蓋所有必要中間態」。沒有這一步，hardness 歸約沒有合法的判定問題載體。
2. **把 T2 往一般寬度推一步**：現有結果只在 `n ≤ s`。先問「一般 n 下可達集的增長級」；若能證明短邊受限變體多項式可解，這本身就是比硬湊 hardness 更值錢的正面結論。
3. **最小 gadget 原型（只做原型，不做宣稱）**：先用縫序列編碼 NCL 的 AND／OR 邊信號，做一個可鎖定的 latch 原型，檢查縫上能否實現信號隔離與雙向傳遞；若原型階段就卡死，應轉向「證明多項式可解」，而不是繼續鋪完整歸約。

## 6. 投稿定位（問題 5）

兩個維度各給一句判斷，再合成結論。

- **規則新穎度：高（本檔 §3 給出依據）。** 檢索未找到任何模型同時具備「移動限定在預設縫＋單次位移固定步長 s 的整數倍＋無邊界」；三特徵交集是我們的位置。
- **已證結果強度：中偏弱。** 手上有的是 `07 §2`（顏色只是必要條件，含反例）、`07 §3.6`（T2，窄帶完整刻畫＋乾淨計數式）、`07 §4`（二分律**必要性**已證、充分性仍是猜想）、`07 §5`（三檔律只到包含關係）。**全部都停在「窄帶／必要條件／單側」層級，缺一般尺寸的完整刻畫，也缺任何複雜度結論。**

**判斷（一句）**：這套東西目前的合理落點是**「娛樂數學專欄／謎題期刊的短文（short note）」這一類，或先做成 OEIS 序列**；**不適合**現在就按「複雜度／算法論文」投。

理由三條：

1. **娛樂數學／謎題期刊短文的門檻正是「新規則＋一條乾淨的小定理」**。我們有「三特徵交集未找到前人」的規則，加上 T2 這種一句話可複述、可手算驗證的計數定理——這正好是該類載體要的東西；篇幅與嚴格度也匹配。
2. **OEIS 序列是低成本、可累積的一步**：T2 的 `q^(n−1)` 有封閉式，本身不夠「謎」；真正有序列價值的是**按形狀分類的計數**（`01 §5.4`、`01 §5.5` 那批逐類三檔的數字）與「K 固定時困局／兩不沾的個數」——這類數字目前只能靠枚舉得到、沒有公式，符合 OEIS 收錄偏好；而且一旦收錄，就替這套規則在文獻裡留下一個可引用的座標。
3. **不適合複雜度論文**：第 5 節已經說明，我們連判定問題的有限化編碼都還沒立，硬湊 hardness 只會被審稿人一句「輸入未界定」打回；反過來若真能證多項式可解，那也該等一般寬度的刻畫做出來再談。
