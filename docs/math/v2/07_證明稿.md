## 1. 形式定義 D1–D12 與記號

> 本章定義供 §2 以後直接引用。坐標記 `(r, c)`，r＝行、c＝列；`e_r = (1,0)`、`e_c = (0,1)`。

**D1 格點與狀態**　格點＝ℤ²；狀態 `S ⊂ ℤ²`，`|S| = K < ∞`，且在 4-鄰接下連通。

**D2 縫**　水平縫 `H_k` 位於行 k 與行 k+1 之間；垂直縫 `V_k` 位於列 k 與列 k+1 之間。縫有效 ⟺ 它穿過狀態內部：
- `H_k` 有效 ⟺ `min{r : (r,c)∈S} ≤ k < max{r : (r,c)∈S}`；
- `V_k` 有效 ⟺ `min{c : (r,c)∈S} ≤ k < max{c : (r,c)∈S}`。

**D3 側**　對 `H_k`：上側 `{p∈S : r ≤ k}`，下側 `{p∈S : r > k}`。對 `V_k`：左側 `{p∈S : c ≤ k}`，右側 `{p∈S : c > k}`。

**D4 側內分量**　把該側的格子按 4-鄰接分組；**相鄰對若被縫隔開（分落兩側）則不算相鄰**。分組得到的連通組即側內分量。（對應 `核心玩法形式化.md` §2.3、`moves.py:25-41`。）

**D5 一次移動**　選 `(縫, 側, 分量 C, 方向 d, 步數 s)`。方向必須**沿縫**：`H` 縫 → `d = ±e_c`；`V` 縫 → `d = ±e_r`（`核心玩法形式化.md` §2.4；`moves.py:44-64`）。落位
`S' = (S ∖ C) ∪ (C + s·d)`。

**D6 合法性**　對 `i = 1..s` 逐步檢查：(a) 無碰撞：`|S'ᵢ| = |S|`；(b) 全盤 4-連通。任一 i 失敗，整次移動不存在（不是回退一步重試）。中間態不留存（`06` §2.2）。

**D7 色向量**　`v(S) ∈ ℕ^{s×s}`，`v_{ab}(S) = #{格 (r,c) ∈ S : r ≡ a (mod s), c ≡ b (mod s)}`。

**D8 集合記號**　照 `00` §1：着色集 `C`、正向可達集 `F`、逆向可達集 `R`、可解集 `S`、困局 `T`、兩不沾 `N`。

**D9 無牆**　狀態只是格點集；不得把「在不在 `m×n` 框內」當合法性條件（`00` §5.5、`06` §2.1）。

**D10 勝負**　回到實心 `m×n`，位置與 D4 朝向任意（`00` §5.6）。不得把「回到原位」寫成約束。

**D11 帶標籤層**　每格一個標籤，標籤跟著格子跑；標籤計算只用**平移正規化**，不做 D4（`00` §2 例外）。還原態穩定子 `G`＝走一圈回到同形狀同位置集時實現的標籤置換全體。

**D12 梯田態（P2 的核心對象）**　設實心盤 `m×n`，`n = min(m,n) ≤ s`。稱 `S` 為**梯田態**，若：
1. `S` 恰好佔 n 行，第 r 行（`r = 0..n−1`）是長度恰為 m 的連續橫條，起點列 `x_r`；
2. 平移規範 `x_0 = 0`；
3. 相鄰行偏移 `δ_r := x_r − x_{r−1} ∈ sℤ` 且 `|δ_r| ≤ m−1`（`r = 1..n−1`）。

記 `T(m,n,s)` 為全體梯田態；`K := ⌊(m−1)/s⌋`，`q := 2K + 1`。

## 2. P1 顏色只是必要條件

### 2.1 命題〔已證〕

> **P1（單向）**　若 `v(S) ≠ v(S')`，則 `S` 與 `S'` 彼此不可達；特別地，`S'` 不能從 `S` 經合法移動回到。
>
> 反向**不成立**：色向量相同不代表可達。色向量是必要條件，不是充分條件。

### 2.2 正向證明（不同色 ⟹ 不可達）

**步驟 1（單步位移是 s 的整數倍）**　依 D5，一次移動把分量 `C` 平移 `s·d`；被移動格 `(r,c)` 落到 `(r + s·d_r, c + s·d_c)`，未被移動的格不動。

**步驟 2（殘餘類不變）**　對被移動格，`(r + s·d_r) mod s = r mod s`、`(c + s·d_c) mod s = c mod s`；對未移動格更不待言。故每格的 `(r mod s, c mod s)` 類在單步後不變。

**步驟 3（色向量不變）**　依 D7，`v_{ab}` 是各殘餘類的格數；每格留在原類，故 `v(S') = v(S)`。

**步驟 4（沿路徑歸納）**　一條合法路徑由有限次單步組成；逐次套用步驟 3，色向量沿路徑恆定。因此存在 `S → … → S'` 路徑的必要條件是 `v(S) = v(S')`。逆否命題即：`v(S) ≠ v(S')` ⟹ 無論正向逆向都無路徑。∎

**依賴**：D5、D6、D7；不引用任何未證幾何事實。

### 2.3 反向不成立：C 內存在不可達態

**現成證據**　`02` #3〔全量〕：着色集嚴格包含 `F ∪ R`，17 個尺寸全部 `|C−R| > 0`；即同色向量的局面裡有走得到回不去的，也有從完成態根本走不到的。

**小尺寸具體化（本次驗算）**　腳本 `_work/_proofA_p1_color.py`，只做正向閉包；枚舉 K 格平移正規化連通形狀後按色向量（容許整體相位平移）濾出 C，再與閉包 F 對照。輸出行：

```
== (3,2,1) K=6 ==
  合法邊數(閉包內重複說法計入)=2000  色向量改變的邊=0
  |C|(具體態,平移正規化)=216  |F|(正向閉包)=214  |C−F|=2
  C−F 例: ######
  C−F 例: #/#/#/#/#/#

== (3,3,2) K=9 ==
  合法邊數(閉包內重複說法計入)=5592  色向量改變的邊=0
  |C|(具體態,平移正規化)=797  |F|(正向閉包)=773  |C−F|=24
```

解讀：

- `(3,2,1)`，s=1：着色退化成單一類，C 即全部 6 格連通形狀（固定座標口徑 216 個）；F＝214，C−F＝2，即 `1×6` 直條的橫、豎兩個朝向。它們與完成態同色，但不可達。
- `(3,3,2)`：C＝797、F＝773，C−F＝24；同色向量仍有 24 個具體態不在正向閉包內。
- 兩個尺寸上「色向量改變的邊」均為 0，與 §2.2 的不變量一致。
- 口徑提醒：這裡的 `|C|`、`|F|` 是平移正規化的具體態數（C 容許色相位的整體平移），不是引擎 D4 類數（§0.3）。

### 2.4 小結

P1 的否決方向是單向的：`U−C` 永不可解（`00` §2 的顏色否決 Lemma），但 `C` 內部遠比 `F ∪ R` 大。可解性問題只能在 C 內發生，不能反過來說 C 內皆可解。

## 3. P2 短邊上限：從「cone ≤ 4」到梯田定理

> 本章固定場景：實心 `m×n` 盤，`n = min(m,n) ≤ s`；行＝短邊 n、列＝長邊 m。原 `05` 命題「min ≤ s ⟹ cone ≤ 4」標〔否證〕（§3.8）；本章給出真正的定理 T2。

### 3.1 L1 板引理〔已證〕

> **L1**　實心盤上任一有效縫的每一側，恰有一個側內分量，且它等於該側與盤的交（整塊板條）。

**證明**

設實心盤 `B = {0,…,n−1} × {0,…,m−1}`。

1. **水平縫 `H_k`**（`0 ≤ k < n−1`，D2 有效條件）：上側 `U = {0,…,k} × {0,…,m−1}`，下側 `L = {k+1,…,n−1} × {0,…,m−1}`。
   - 在 U 內：同一行的格沿列方向成水平鏈；相鄰兩行在同一列有 4-鄰接對，且這兩行都屬 U，不跨縫。故 U 內任意兩格可經 U 內路徑相通，U 是一個 4-連通實心 `(k+1)×m` 矩形。
   - 跨縫鄰接對（行 k 與行 k+1）依 D4 不算相鄰；它們本來也分屬兩側，不影響 U 內分組。
   - 故 U 的側內分量恰為 U 本身；下側 L 同理，恰為 L 本身。
2. **垂直縫 `V_k`**：左側、右側各為實心豎條，論證同上（行列互換）。
3. 兩側各自非空（有效縫定義 D2），故每一側恰一個分量。∎

**依賴**：D2、D3、D4；實心性（每行每列填滿）是唯一幾何前提。

### 3.2 L2 沿縫判據〔已證〕

> **L2**　實心 `m×n`、`n ≤ s`。對 `H_k`：上板／下板沿 `±e_c` 平移 s 格**合法 ⟺ `s ≤ m−1`**；與縫編號 k、側、方向無關。

**證明**　取 `H_k`，被移動分量 C 為上板（行 `0..k`）或下板（行 `k+1..n−1`），其餘板記 Q（避免與逆向可達集 R 混淆）。按 D6 逐步檢查 i = 1..s。

**(a) 碰撞永不可能**　C 的行集合與 Q 的行集合不相交（D3 按行切分）。碰撞要求落格同時屬於 `C + i·e_c` 與 Q：前者行標來自 C 的行集，後者行標來自 Q 的行集；列方向平移不改變行標，故無交集。板自身是剛體平移，格與格不會互撞。故 `|S'ᵢ| = |S|` 對所有 i 成立（D6(a) 恆過）。

**(b) 連通性 ⟺ 兩板列投影每一步相交**　板內部由 L1 保持連通；兩板所在的列範圍互不相交，全盤是否連通，只看兩板在縫上是否還有鄰接對。`H` 縫上的跨板鄰接是「同一列、上下相鄰」的垂直對：縫上兩板橫條在第 i 步的列區間——
- 未動板 Q 的縫行：`[0, m−1]`；
- 動板 C 的縫行，右移 i：`[i, m−1+i]`；左移 i：`[−i, m−1−i]`。

兩區間相交 ⟺ `i ≤ m−1`。跨板存在鄰接對 ⟺ 區間相交；不相交則兩板斷成兩個 4-連通分量（D6(b) 失敗）。

- **正向**：若 `s ≤ m−1`，則對每個 `i ≤ s` 都有 `i ≤ m−1`，區間恆相交，連通性逐步成立；碰撞 (a) 恆過，故移動合法。
- **反向**：若 `s ≥ m`，取第 `i = m` 步（`m ≤ s`）：右移後區間 `[m, 2m−1]` 與 `[0, m−1]` 不相交（左移對稱 `[−m, −1]`），跨板無鄰接對，全盤斷連通，移動非法。

**與 k、側、方向無關**：k 只決定縫落在哪一行；兩板的列區間都是完整的 `[0, m−1]`（實心性，L1）。側決定動上板還是下板，方向決定左移還是右移，二者只翻轉區間符號，相交條件只依賴區間長度 m。故判據 `s ≤ m−1` 不隨 k、側、方向改變。∎

**依賴**：D3、D4、D5、D6、L1。

### 3.3 L3 垂直縫全禁〔已證〕

> **L3**　`n ≤ s` 時，任何 `V` 縫移動非法。

**證明**　取 `V_k`，被移動分量 C 為左板或右板，另一板記 Q。C 與 Q 的列範圍互不相交，唯一可能的接觸是跨縫的「同一行、左右相鄰」水平對，要求兩側在同一行 r 都有格。

- 未動板 Q 的行投影：`[0, n−1]`；
- 動板 C 下移 i：行投影 `[i, n−1+i]`（上移 i：`[−i, n−1−i]`）。

兩行投影相交 ⟺ `i ≤ n−1`。跨板鄰接存在 ⟺ 行投影相交；合法要求每個 `i = 1..s` 都相交，即 `s ≤ n−1`。

現設 `n ≤ s`，則 `s ≥ n > n−1`。取第 `i = n` 步（`n ≤ s`）：動板行投影 `[n, 2n−1]` 與 `[0, n−1]` 不相交（上移對稱），跨板無鄰接對，全盤斷連通（D6(b) 失敗）。故任何 `V` 縫移動非法。∎

**凍結例證（本次驗算重跑）**　`(4,2,2)`：s = 2 = n，垂直縫滑滿 2 格後，剩餘行 `{0,1}`、滑後行 `{2,3}`（或 `{−2,−1}`），交集為空。腳本 `_work/_proofA_4x2_ways.py` 輸出：

```
V_0 左 (1, 0): 剩餘行=[0, 1] 滑後行=[2, 3] 交集=set()
V_0 左 (-1, 0): 剩餘行=[0, 1] 滑後行=[-2, -1] 交集=set()
```

**依賴**：D3、D4、D5、D6。

### 3.4 L4 梯田不變性〔已證〕

> **L4**　完成態屬於 T；從 T 內任一態出發的任何合法移動，落點仍在 T。

**預備：梯田態的側內分量＝連續行段（按 D4 定義走一遍）**

設 `S ∈ T`，各行橫條 `Seg_j = {j} × [x_j, x_j+m−1]`。對 `H_k`，上側 U＝行 `0..k`，下側 L＝行 `k+1..n−1`。

1. **同側內的鄰接**：行 j 與行 j+1 同在 U（或同在 L）時，同列的垂直鄰接對存在 ⟺ 兩段列區間相交：`[x_j, x_j+m−1] ∩ [x_{j+1}, x_{j+1}+m−1] ≠ ∅` ⟺ `|x_{j+1} − x_j| ≤ m−1`。這正是 D12(iii) 的條件。
2. **跨縫對不算**：行 k 與行 k+1 的鄰接對被縫隔開，依 D4 排除；它們不計入 U 或 L 內的連通關係。
3. **分組結果**：在 U 內，鏈 `Seg_0 – Seg_1 – … – Seg_k` 逐行相交相通，U 只有一個分量，即前綴行段 `{0,…,k}`；在 L 內，鏈 `Seg_{k+1} – … – Seg_{n−1}` 相通，L 只有一個分量，即後綴行段 `{k+1,…,n−1}`。這是 L1 從實心盤到梯田態的推廣：實心矩形的「填滿」被 D12(iii) 的「相鄰行投影相交」取代。

**本體證明**

**(i) 移動軸向**　由 L3，`n ≤ s` 時 `V` 縫移動全部非法；故 T 態上的合法移動只能是 `H` 縫的水平平移。

**(ii) 被選分量是行段板**　由預備步，`H_k` 兩側分量分別是前綴行段 `{0..k}` 與後綴行段 `{k+1..n−1}`；合法移動選中的 C 必為其中一塊。

**(iii) 平移對偏移的改動**　設前綴被平移 `±s`（後綴對稱）：前綴各行起點 `x_0..x_k` 同加 `±s`，後綴不動。
- 前綴內部偏移 `δ_1..δ_k`：兩端同加一常數，差值不變；
- 只有縫邊界項 `δ_{k+1} = x_{k+1} − x_k` 改變為 `δ_{k+1} ∓ s`；後綴被平移時改變的是同一邊界項，符號相反。
- 新 `δ'`：舊 `δ ∈ sℤ`（D12(iii)），加減 `s ∈ sℤ`，故 `δ' ∈ sℤ`。

**(iv) 連通性逼迫邊界偏移上限**　落點最終態必須全盤 4-連通（D6(b)）。兩板只可能在縫上相接（列範圍互不相交），跨縫鄰接存在 ⟺ 縫上兩段列區間相交 ⟺ `|δ'| ≤ m−1`（同 L2(b) 的區間相交條件）。故合法落點的新邊界偏移自動滿足 `|δ'| ≤ m−1`。

**(v) 其餘條件保持**　剛體平移不改變每行橫條的長度與連續性，也不改變行數；行集合不變，故不會合併或分裂橫條。平移規範 `x_0 = 0` 可事後用整體平移歸一，整體平移不改變任何 `δ`。

**(vi) 完成態在 T 內**　完成態 `x_r = 0` 對所有 r；`δ_r = 0 ∈ sℤ`，`|0| ≤ m−1`，符合 D12。

綜合 (i)–(v)：T 在合法移動下封閉；(vi) 完成態 ∈ T。∎

**依賴**：D4、D5、D6、D12、L2(b)、L3。

### 3.5 L5 梯田可造〔已證〕

> **L5**　T 內任一態可由完成態經合法移動到達。

**顯式構造**　目標態偏移 `(x_0=0, x_1,…,x_{n−1})`；完成態起點全 0。按邊界 `r = 1, 2, …, n−1` 依次處理：在 `H_{r−1}` 上選後綴行段 `B_r = {r,…,n−1}`（該縫的下側分量，依 L4 預備步），反覆平移 `±s`，直到第 r 行起點達到目標 `x_r`。

**逐步合法性驗證**

1. **後綴是側內分量**　依 L4 預備步，`B_r` 是 `H_{r−1}` 下側的唯一側內分量（後綴鏈由 `|δ| ≤ m−1` 相接），選取合法（D5）。
2. **軸向**　水平平移，不觸犯 L3 的垂直禁令。
3. **碰撞**　前綴 `{0..r−1}` 與後綴 `{r..n−1}` 行集合不相交，同 L2(a)：列平移不改行標，無碰撞（D6(a) 恆過）。
4. **中間態連通**　設當前邊界偏移 `δ_r^cur`，朝目標 `δ_r^*` 單調走一步：`δ_r' = δ_r^cur ∓ s`。目標 `δ_r^* ∈ {−Ks,…,0,…,Ks}`，`K = ⌊(m−1)/s⌋`，故 `|δ_r^*| ≤ Ks ≤ m−1`；單調路徑上每個中間值 `|j·s| ≤ |δ_r^*| ≤ m−1`，縫上兩段區間相交（L2(b) 條件），跨板有鄰接對。後綴內部偏移隨剛體平移不改，前綴不動，故中間態全盤連通（D6(b) 逐步成立）。
5. **步數對齊**　`δ_r^*` 是 s 的整數倍（D12(iii)），從 0 出發按 `±s` 走可恰好抵達，不會落在非整倍位置。

**後綴互不干擾**　處理邊界 r 時，被移動的是 `B_r`；平移 `B_r` 使 `x_j`（`j ≥ r`）同加常數，故只改 `δ_r`、不改 `δ_j`（`j ≠ r`）。處理邊界 `r+1` 時只動 `B_{r+1} ⊂ B_r`，第 r 行與前綴 `{0..r−1}` 保持不動，已鎖定的 `x_r` 不變。歸納下來，邊界 `1..r` 在後續步驟中不再被改動。

**收尾**　`r = 1..n−1` 處理完畢，所有 `x_r` 達目標值，落點即目標梯田態。∎

**依賴**：D5、D6、D12、L2(a)、L2(b)、L3、L4。

### 3.6 定理 T2〔已證〕

> **T2**　`n = min(m,n) ≤ s` ⟹ `F（具體態，平移正規化）= T(m,n,s)`，故
> `|F| = q^{n−1}`，`q = 2⌊(m−1)/s⌋ + 1`。

**證明**

1. **`F ⊆ T`**　完成態 ∈ T（L4(vi)）；T 在合法移動下封閉（L4）；F 是完成態的正向閉包，故 `F ⊆ T`。
2. **`T ⊆ F`**　任一梯田態可由完成態合法到達（L5），故 `T ⊆ F`。
3. **計數**　每個邊界 `r = 1..n−1` 獨立取偏移 `δ_r ∈ {−Ks, …, 0, …, Ks}`，共 `2K+1 = q` 個取值；n−1 個邊界互相獨立，故 `|T| = q^{n−1}`。由 1、2，`|F| = q^{n−1}`。∎

**推論**

- **(a) 凍結情形**　`m ≤ s`（短邊兩向皆 ≤ s）：`K = 0`，`q = 1`，`|F| = 1`，閉包內只有完成態。
- **(b) 兩行盤**　`n = 2`：`|F| = q = 2⌊(m−1)/s⌋ + 1`。
- **(c) 對原「≤4」命題的判定**　具體態口徑下 `|F| = q^{n−1}`；所謂「≤4」應與 `q^{n−1} ≤ 4` 對照（D4 類口徑另計，類數是具體態再對稱坍縮後的結果）。**非凍結窄盤**（`q ≥ 3`）在 `n ≥ 3` 時 `q^{n−1} ≥ 9`，已越過 4；原命題〔否證〕，反例見 §3.8。

### 3.7 4×2 對照節

實心 `4×2`、s=2 完成態的首步字面走法（腳本 `_work/_proofA_4x2_ways.py`）：

```
== (4,2,2) m-1=3 n=2 ==
  H 候選 4 條，合法 4；V 候選 12 條，合法 0
  H_0 上 |C|=4 位移(0, 1) 合法 ..####/####..
  H_0 上 |C|=4 位移(0,-1) 合法 ####../..####
  H_0 下 |C|=4 位移(0, 1) 合法 ####../..####

    形狀 ..####/####..  由 2 條字面走法
    形狀 ####../..####  由 2 條字面走法
```

- 合法四條全部來自唯一內部水平縫 `H_0`：上側左／右、下側左／右。
- 垂直縫 `V_0、V_1、V_2` 左右側各兩方向共 12 條全部非法；理由統一為 L3：s = 2 = n，滑滿後行投影不相交。
- 四條字面走法只落成 **2 個具體形狀**（互為鏡像：`####../..####` 與 `..####/####..`），連同完成態本身，D4 類數（引擎 cone 口徑）＝2。

**為什麼不是「上下左右各一」**：垂直方向一條都不合法（L3）；水平方向雖有 4 條字面走法，但上側右滑與下側左滑落點互為平移、上側左滑與下側右滑亦然，收成 2 個具體形狀。所謂「左右兩列 × 兩個向外方向」的說法把 `V` 縫的側別與 `H` 縫的移動方向混在一起，實際不存在那組走法（§3.8）。

### 3.8 與 `05 §2` 的差異：原命題錯在哪、為什麼「≤4」曾經碰巧成立

**原 `05 §2` 第 2 步原文要點**：滿盤每一側連通，分量就是把整條邊剝下來；剝下來往**盤內**搬 s 格必然碰撞或斷連通，兩個都非法；**唯一合法是往盤外搬**。

**逐句錯誤定位**

1. **把「沿縫」讀成「穿縫」**　規則的移動方向是沿縫：`H` 縫左右滑（`±e_c`）、`V` 縫上下滑（`±e_r`）（D5；`核心玩法形式化.md` §2.4；`moves.py:44-64`）。規則裡不存在「跨過縫往盤內／盤外」的徑向移動。「往盤內搬 s 格必然碰撞」這個判斷預設了一個穿縫方向的位移，而該方向根本不是合法動作。
2. **碰撞理由說錯**　依 L2(a)，水平平移時兩板行集合不相交，列方向平移不改行標，**碰撞在兩個方向都不會發生**；合法性的瓶頸是縫上列投影是否相交的連通條件（L2(b)），不是「往內會撞牆」。無牆模型（D9）下也沒有盤外可去、盤內不可入的邊界。
3. **「唯一合法是往盤外」不成立**　4×2 的合法移動是上／下板沿 `H_0` 左右滑；兩個方向都沿縫，無所謂內外。梯田態下只要邊界偏移滿足 `|δ| ≤ m−1`，`+s` 與 `−s` 同樣合法（L2、L4）。
4. **原 `05 §2` 第 3 步「左右兩列 × 兩個向外方向」標錯對象**　4×2 的四條合法走法是「上側／下側 × 左／右」（`H` 縫兩側沿水平方向）；「左右兩列」是 `V` 縫的兩側，而 `V` 縫 12 條走法全非法（§3.7）。把 `V` 側套上「向外方向」的描述，是縫向與側別交叉錯配。

**為什麼「≤4」在那 13 個尺寸上仍成立〔否證：小尺寸現象，不是定理〕**

- 原命題統計的對象是引擎 cone（D4 類數）；那 13 個已算尺寸的共同特徵是 `n ≤ 3`、`m ≤ 8`。
- 按 T2，具體態數為 `q^{n−1}`：`n = 2` 時 `|F| = q`；`n = 3` 時 `|F| = q²`。在 m ≤ 8、s 取 2 或 3 的窄盤上，q 本身很小，具體態個數有限；再經 D4 商掉旋轉與鏡像，類數落到 ≤4 是**小尺寸＋對稱坍縮的巧合**，不是結構上的上界。
- 超出這個範圍後不等式失效：`(5,4,4)` 具體 27／D4 類 10、`(8,5,5)` 具體 81／D4 類 25、`(7,3,3)` 25／9、`(9,2,2)` 9／5，D4 類數都越過 4（本次驗算，§3.9）。
- 故 P2 的正確陳述是 T2（梯田族計數）；「min ≤ s ⟹ cone ≤ 4」標〔否證〕。它在窄盤上真正成立的替代結論是 L1–L5 的結構刻畫，而不是一條 ≤4 的數字上界。

### 4.2 必要性〔已證〕：min ≤ s ⟹ 還原態穩定子平凡

**命題（P3-necessity）**：設完成態為實心 m×n 盤，`n = min(m,n) ≤ s`。在帶標籤層（D11）上，走一圈回到同形狀同位置集時實現的標籤置換全體 G 只有恆等置換：`G = {id}`。

**證明（逐步，每步標依賴）**：

1. **軸向鎖死**（依 §3 L3；幾何沿縫口徑見 D5、§3.8）。`n ≤ s` 時任何垂直縫 V 移動非法；合法移動只能走水平縫 H，方向 ±e_c。因此每一步被移動的分量只改變列座標，**行座標不變**。
2. **標籤不換行**（D11：標籤跟著格子跑）。由步驟 1，整條走路上沒有標籤跨到別的行；每個標籤始終留在它原來的行（整盤平移造成的同行整體偏移除外，平移已由 D9／D10 商掉）。
3. **可達態皆梯田**（依 §3 定理 T2；定義見 D12）。F 內每個態恰佔 n 行，第 r 行是一條長度恰為 m 的連續橫條，起點列 x_r；平移規範 x_0 = 0，相鄰行偏移 δ_r ∈ sℤ 且 |δ_r| ≤ m−1。
4. **行內次序不變**（依 §3 L1 推廣到梯田、L4）。每一條橫條被移動時，作為該縫一側的連續行段整體平移；平移不改變條內格子的左右次序，側內分量也不會在一行之內分裂。故從完成態到任一可達態，**每行內標籤的左右次序保持不變**。
5. **回到同一格集**。設走完一圈的落態 S* 格集與完成態 S₀ 相同（D11 的「同形狀同位置集」；位置任意見 D10，無牆口徑見 D9）。S₀ 第 r 行佔列 0…m−1；S* 格集相同，故 S* 第 r 行起點 x_r(S*) = 0 = x_r(S₀)，每行仍是列 0…m−1。
6. **標籤歸位**。由步驟 2，標籤 ℓ 仍在它原來的第 r 行；由步驟 4，該行內次序未變；由步驟 5，該行佔的格子與完成態第 r 行相同。三者併起來，ℓ 落在完成態時它所在的那格。所有標籤歸位，誘導置換即恆等。∎

**口徑說明**：S* 可能是 S₀ 的整盤平移副本；D10 已把整體平移商成同一類，D11 的穩定子只認「平移正規化後同形狀同位置集」。本證明不把「回到絕對原位」當約束（`00` §5.6 貓九指正：要求原位不改變 R，只是逼實作追絕對座標）。

**為什麼這條比「cone 小所以換不動」更強**：

- 舊鏈條（`05` P3 必要性）靠「可達集小到離譜，湊不出一圈」。這條理由站不住，有兩層問題：
  - 「min ≤ s ⟹ cone ≤ 4」本身已被〔否證〕（§3.8；cone 為舊稱，D4 類口徑，不是 F）：窄盤的 D4 類數可以到 10、25，不是 ≤4；且該類數是 D4 類口徑、F 是具體態數，兩者不可混（§3.6）。
  - 可達集大小是形狀層的量；穩定子是標籤層的量，前者小不邏輯地蘊含後者平凡。
- 上面的剛性論證與 |F| 多大**無關**：它只依賴步驟 1 的軸向鎖死與步驟 3–4 的橫條剛性，不計算可達態數。
- 驗算（正向閉包，CAP 250000，只跑規格准許的窄尺寸；腳本 `experiments/math_repro/_work/_proofB_stabilizer.py`）：

  | (m,n,s) | 可達棋形 | 可達帶標籤態 | 行不換行違反態數 | 保色回原形置換數 |
  |---|---:|---:|---:|---:|
  | (4,2,2) | 3 | 3 | 0 | 1（恆等） |
  | (5,4,4) | 27 | 27 | 0 | 1（恆等） |
  | (7,3,3) | 25 | 25 | 0 | 1（恆等） |
  | (9,2,2) | 9 | 9 | 0 | 1（恆等） |

  其中 (5,4,4)、(7,3,3) 的可達棋形已分別是 27、25（D4 類數見 §3.6 的 10、9），遠不是「cone ≤ 4」，穩定子仍然平凡——直接對上「必要性不靠可達集小」這條結論。

### 4.3 充分性〔猜想〕：min > s 時能否湊滿上界

**命題（猜想，未證）**：實心 m×n 盤、`min(m,n) > s` 時，`G = Π_c k_c!`（每個著色類達滿對稱群，即撞滿上界）。

**現狀**：只有 14 個實心尺寸全中的經驗匹配（`02` #22）〔觀察〕；沒有構造性證明，也沒有顯式算法。充分性接 `03` O-4，尚未做出。

**策略與種子（只記錄線索，不宣稱構造完成）**：

1. **7 步三循環**：(3,3,2) 的純三循環 7 步，支撐集＝4 格大類任取 3 格；8 個三循環＝4 個缺角 × 2 個繞行方向（`01` §5.1；`02` #15 #19）。
2. **2×2 缺角 L**：最便宜的三循環支撐是 2×2 缺一角的 L 形；s=1 要 6 步、s=2 要 7 步（`01` §5.1；`02` #21）。
3. **一圈辦兩件事**：最短元素型別 (4,2,1,1,1)＝大類四格輪換＋一個對換，6 步；拆開做分別要 7 步與 15–17 步。構造應該走「一整圈」，不是分件拼（`02` #16；#17 顯示最短路徑收斂成同一條圈）。
4. **已知的坑**：D4 共軛不能用來批發三循環——共軛後步驟合法、也回本形狀，但落點不在可達集，著色相位被打亂（`02` #20）。要造其餘循環只能各自幾何地造。

「繞著空的角轉，七步」目前還只是一句人話，尚未寫成與尺寸無關的顯式配方；這是 O-4 要補的東西。

### 4.4 門檻為什麼是 s

- **必要性方向**已由 4.2 給出機制：`min ≤ s` 時垂直縫全禁、軸向被鎖死，窄盤的剛性鏈條封死了標籤交換的可能。
- **充分性方向**還缺構造：`min > s` 為何打開足夠的跑道、能在每個類內造出對換與輪換，沒有證明。
- 「為何閾值剛好是 s，而不是 s+1、2s」目前無答案；14 尺寸全中是經驗律，不是定理（`03` O-15）。注意：O-15 的①「先證 ≤4」已被 T2 取代——必要性的正確版本見 4.2，不再需要 ≤4 這條數字上界。

## 5. P4 逐類三檔律：障礙分析

### 5.1 〔已證〕部分

設著色類 C_c 為殘餘類 `(r mod s, c mod s)` 相同的格子集合，大小 k_c；g_c 為穩定子在該類上的投影因子。

**(i) G ⊆ Π_c S(C_c)**〔已證，P1 推論〕。
由 P1（§2），一次移動位移恆為 s 的整數倍，每格的殘餘類不變；標籤跟格跑（D11），故標籤永不離開自己的著色類。任何 π ∈ G 把 C_c 映到自身，其限制 π|_{C_c} ∈ S(C_c)。於是 `G ⊆ Π_c S(C_c)`。這條只用到類不變性，不含類間是否獨立的結論。

**(ii) k_c ≤ 2 的因子自動落在三檔內**〔已證，但屬群論廢話〕。
- k_c = 1：因子平凡，只可能是 1。
- k_c = 2：S₂ 只有 {1} 與 S₂ 兩個子群，對應檔位 1 與 k = k! = 2。

必須老實說：這是群論本身的後果，**不是本定理的幾何內容**——任何 S₂ 的子群本來就只有這兩個，三檔律在 k ≤ 2 不承載任何幾何斷言。真正需要幾何證明的是 k ≥ 3 的情形。

**(iii) 窄實心盤域內 P4 真空成立**〔已證，接 4.2〕。
`min ≤ s` 時 G = 1（4.2），所有因子取 1，三檔律在這個域裡自動滿足，沒有實質內容。

### 5.2 〔部分〕還缺的兩條引理

現有結論只給了 G 乘積包含關係。要把三檔律推成定理，下面兩條都還沒證。

**引理 (a)：類間不干擾**

- **陳述（待證）**：對閉環實現的置換，其在各著色類上的投影可獨立實現；即 `G ≅ Π_c g_c`（直積分解），且在某一類上做的置換不改變其他類的可達性。
- **用途**：目前的包含式 `G ⊆ Π S(C_c)` 允許 G 是乘積的對角子群（各類投影互相綁定）。要得到「逐類各自決定檔位」的等號分解，必須有這條。
- **卡點**：一條觸及某類的圈可能順帶拖動別類；尚未證明各類的圈可以無副作用地組合。經驗上 `02` #27 的均勻性（每個可達棋形剛好帶 |G| 種標籤）像是自由作用，但那是枚舉觀察，不是證明；且 ≤8 格起還有平移副本干擾口徑（`02` #31）。

**引理 (b)：單類可行性判據**

- **陳述（待證）**：給定形狀與一個 k 格著色類，刻畫幾何條件，使 g_c 落在 {1, C_k, S_k} 哪一檔（k=3 時另列 A₃ 例外，見 5.3）。
- **用途**：這條決定每個類死／只輪換／滿對稱，是三檔律的核心；沒有它，「逐類獨立」只是分解形式，判據仍空缺。
- **卡點**：找不到只看形狀的判據。已知相關量跑道長 R0 只是統計分帶（`02` #30 #35）；活著的類不必含同色 2×2（`01` §5.4；`03` O-17）。現有資料能對上 R0 分帶，對不上逐類的充分必要條件。

### 5.3 k=3 例外：A₃ 不是群論必然

- S₃ 有三個二階子群（三個對換），另有 A₃ = C₃（三循環）與 S₃ 本身。所以「3 格類只到 A₃——做得到輪換、做不出對換」**不是群論必然**：群論上對換是允許的。它是幾何事實：那個盤面在該類內湊不出對換。
- 這正是 `02` #29 記錄的唯一例外檔位：3 格類只取 k = 3（輪換），到不了 k! = 6。對應開放問題 `03` O-19（3 格類何時只剩輪換）。
- **三檔律的真正內容在 k ≥ 3**：S₄ 有 V₄ 等大量中間子群；`{1, C_k, S_k}` 這條律若成立，等於在幾何上排除了這些中間子群。k=2 時 k = k!，檔位退化成 {1, 2}，不承載內容；k=1 恆平凡。
- 補充：A₃ 本身就是 C₃（循環群），落在「k 檔」；例外只在「為什麼到不了 S₃」，不在「為什麼有輪換」。

### 5.4 觀察證據〔觀察，不得升級成定理〕

- `02` #29：≤7 格、s=2，156 個帶標籤形狀，逐類三檔律 **156/156** 全中；同批有 26 個中間值，說明二分律在一般形狀上不成立。
- `02` #32：≤8 格、s=2，646 個帶標籤形狀，**646/646** 全中。
- `02` #34：s=3，**87/87** 全中；活著的類只有全不動與一個 3 格類只到輪換兩種。

以上三組都是全集枚舉的經驗律，證明等於 5.2 兩條引理補上之前，不得寫成定理。

### 6.1 定義

```lean

abbrev Cell : Type := ℤ × ℤ

structure State where
  cells : Finset Cell
  connected : Is4Connected cells

-- 縫（D2）：水平縫 H_k / 垂直縫 V_k
inductive Seam where
  | H (k : ℤ)
  | V (k : ℤ)

structure Move where
  seam      : Seam

  legal     : ∀ i ∈ 1..steps, CollisionFree component i dir steps
```

### 6.3 寫不進框架的部分（明說原因）

1. **P3 充分性、P4 兩條引理**：所需的幾何構造與判據尚未做出，命題還不能寫成可證形式；骨架不補 `sorry` 以外的偽證明。
2. **標籤層要先獨立建模**：現有形狀層引擎只存格點集；`Stabilizer` 定義依賴「標籤跟格跑」的 `LabeledState`，必須先把這一層建出來，群才能談。
3. **保色過濾必須進穩定子定義**：若「回原形」只比格集，整盤平移一格的副本會偽裝成非平凡置換（`02` #31）；`ColorPreserving` 一項不能省。
4. **兩個狀態層不能混**：形狀層是平移＋D4 商圖；標籤層是具體座標、只平移正規化（旋轉／鏡射不是合法動作）。骨架只建具體座標層；形狀層的類數字不能直接搬進標籤層。
5. **T2 的幾何連通論證**依賴 L1–L5 的板引理與分量分析，骨架只引用其結論，不在此層重複形式化。
