# 一級可換性：階段總結與缺口清單

> 2026-11-25。本文只收「已經確定的」與「明確未定的」，不寫過程日誌。
> 分級：**定理**（可手證）／**機檢**（K≤14 實測）／**猜想**／**缺口**。

---

## 0 命題

一級（`s=1`、單色、滑塊 = 1×1）下：對任意 K，是否**任意兩塊都能互換**？

等價形式：從滿盤出發，所有 K! 個排列是否都可行（即**滿盤置換群 = K!**）。

**白話**：K 個一模一樣的方塊，在一級規則下，能不能把任意兩塊的位置對調、其餘不動。

**參數域**：本文所有結論默認 `min(m,n) > s`（`s=1` 時即 `min(m,n) ≥ 2`）。`1×K` 直條單獨成立、不與其它形狀連通，是這個命題的邊界，不是反例。

---

## 1 定理（可手證，不依賴機檢）

**T1 任何路徑都可原路反向，且標籤完全復原。**

單向邊「不可逆」只指**一步直接反向不合法**（粘連型），不指整條路徑。一步一步原樣倒著走，合法性與標籤都逐格對應。

**T2 若形狀圖弱連通，則任意形狀上的標籤群 = 滿盤群。**

路徑：`s → 滿盤 → g → 原路返回`，`s` 上得到 `X g X⁻¹`。`S_K` 對共軛封閉，故每個形狀同樣是 `S_K`。

**T3 命題 ⟺「L2：形狀弱連通」＋「滿盤 S_K」。**

**白話**：只要能證明「所有形狀連成一張圖」而且「滿盤能排出所有排列」，命題就通。已經不是兩件事揉在一起，是兩件獨立的事。

## 3 猜想與缺口

### G1（缺口，最核心）R2 的「其餘 ≤ K」沒有證明

**猜想 R2**：任意 K 格 4-連通形狀，到最近 `m×n` 矩形（`m·n=K`）的距離 ≤ K+1（直條除外）。

**已作廢（2026-11-25）**：K=16 的 4×4 實測 R2 = **18 = K+2**，最遠點唯一（15 直 + 末端側枝）。正確形態是「非正方形 R2 = K−1，正方形超出（3×3 為 K+1、4×4 為 K+2）」。見 `14_K16全圖結果_R2等於18.md`。

L 那一側已有 M5（= K−1，餘量明顯），**「其餘形狀 ≤ K」完全沒有理論**。

### G2（缺口）L 族 ≤ K−1 只是一條經驗規律

六尺寸都對，但 K=9 的例外說明它不是普遍定理。

### G3（⚠ 待重驗）K=16 不可機檢

全標籤空間確實不可枚舉（`16! = 2.09×10¹³`）。先前聲稱用「穩定子口徑」補上了，但該腳本有口徑漏洞（歸一化把整體平移誤判成回還原態），**結論已撤回，等絕對位置版重跑**。

### G4（⚠ 待重驗）`(4,4,1)` 群階 = 16!

K=6/8/9/10/12/14/15 七個尺寸是實測 K!（全量標籤 BFS，不是穩定子口徑，不受漏洞影響）；K=16 退回未核。

## 5 結構障礙（這一條解釋了為什麼上面全失敗）

**形狀必須保持 4-連通 ⟹ 單個格不能單獨移動 ⟹ 任何路徑都是「整塊分量搬運」。**

**白話**：不能把一格拎起來塞進洞裡——一拎就把整塊切斷，非法。所以「逐格把差異改小」這類貪心，**從一開始就不在合法操作裡**。

所有勢函數路線失敗的真正原因在這，不在函數選得不好。

## 6 下一步需要什麼

只有兩種可能：

1. **整塊搬運的通用構造**：對任意 `(m,n)` 與任意形狀，給出「整塊滑 → 錯位 → 收回」的顯式步驟表，並證明步數 ≤ K+1；
2. **不需構造的連通性論證**：例如證明形狀圖的割點集只有少數「最瘦族」成員（已實測 K=9 三個、K=10／K=12 各一個，見 `13_形狀圖的橋與割點.md`）、或每條單向邊都有一條「不改變標籤序」的逆回路。

**註**：原稿這裡寫的是「證明形狀圖沒有割點」——**已被實測否掉**（有 1–3 個割點）。正確目標是「割點集恰好是最瘦族，且該族可被走過」。

第二條更接近 M5 的「扭樓梯」直覺，但目前沒有形式化。
