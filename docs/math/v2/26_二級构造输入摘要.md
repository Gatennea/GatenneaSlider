## 0 两个划分，先分清（这是最容易混的地方）

4×4 上同时存在两套 4 块分组，**它们不同**：

| 划分 | 定义 | 4 个组的坐标 |
|---|---|---|
| **粗格** | 连续 2×2，`(⌊r/2⌋, ⌊c/2⌋)` | 左上 `(0,0)(0,1)(1,0)(1,1)`｜右上 `(0,2)(0,3)(1,2)(1,3)`｜左下 `(2,0)(2,1)(3,0)(3,1)`｜右下 `(2,2)(2,3)(3,2)(3,3)` |
| **mod 类** | 交错，`(r%2, c%2)` | `(0,0)`→`(0,0)(0,2)(2,0)(2,2)`｜`(0,1)`→`(0,1)(0,3)(2,1)(2,3)`｜`(1,0)`→`(1,0)(1,2)(3,0)(3,2)`｜`(1,1)`→`(1,1)(1,3)(3,1)(3,3)` |

**任一粗格与任一 mod 类恰好相交于 1 块。** 换句话说：4 个粗格的「左上角」全属 mod 类 `(0,0)`，右上角全属 `(0,1)`……

**稳定子 `S₄⁴` 保的是 mod 类，不是粗格。** 所以凡说「类内操作」，动的都是**分散在四个粗格里的 4 块**。

## 1 硬约束（只有一条，别再加戏）

1. **每块不出自己的 mod 类**：`s=2` 每步平移 2 格，`(r%2, c%2)` 是结构性不变量（不是统计）。所以四个 mod 类互不交换成员，`G ⊆ S₄⁴`。
2. **除这一条外没有别的约束**。⚠ 本节此前写过「四类符号乘积 = +1」「单对换不可能」「最小修复 7 步」，**三条全部作废**，见下：
   - D=7 群阶 165,888 = `S₄⁴ ∩ A₁₆`，但那只是**深度 7 内**的局部值；
   - D=8 出现 24 个奇回路，群阶直接跳到 **331,776 = 24⁴ = 全體 `S₄⁴`**；
   - 所以「四类符号乘积 +1」不是不变量，纯两块交换（`2,1×14`）在 **D=9** 出现，共 20 条。

**白话**：二级真正锁死的只有「块不许跨类搬家」，类内 4 块想怎么换就怎么换，24⁴ 全都做得到。之前那些「永远不可能」的断言，是被深度 7 的天花板骗出来的。

### 纯两块交换的 9 步序列（已验证）

从还原态出发，块 1（`(0,1)`）与块 3（`(0,3)`）互换，同属 mod 类 `(0,1)`：

```
1. box(0, 0, 0, 3)  -> ( 0,-1)
2. box(0,-2, 3, 0)  -> (-1, 0)
3. box(-2,-2,-2,0)  -> ( 0,+1)
4. box(1, 2, 3, 3)  -> (-1, 0)
5. box(-2, 2, 1, 3)  -> (+1, 0)
6. box(-2, 0,-1, 1)  -> ( 0,+1)
7. box(-2, 3,-2, 3)  -> (+1, 0)
8. box(-2, 2,-1, 2)  -> ( 0,-1)
9. box(-2, 0, 1, 0)  -> (+1, 0)
```

**框落在负坐标不是越界**：按 `00` 的口径，状态是格点集合、画布没有墙、整体平移早已商掉，块本来就可以整条搬出原盘。独立复核脚本 `_work/_verify_pure_swap9.py` 跑通，最终归一化仍是 4×4 满盘、置换 `[0,3,2,1,…]`。

**9 步是最短**：D=8 的 289 个回路里没有任何 `(2,1×14)`，D=9 才有。

## 2 已机检的积木

### 2.1 mod 类内 3-循环：6 步（四类都有样本）

模板（mod 类 `(1,1)`，即动 `(1,1)(1,3)(3,1)(3,3)` 三块）：

```
1. 框(0,0,3,2) → (−1,0)
2. 框(−2,0,0,3) → (0,−1)
3. 框(−2,−2,1,3) → (0,1)
4. 框(−2,0,1,2) → (1,0)
5. 框(1,4,1,5) → (1,0)
6. 框(3,2,3,5) → (0,−1)
```

净效果：三相循环，其余 12 块原位不动。

### 2.2 由 3-循环生成整个 `A₄`

`A₄` = 恒等 + 8 个 3-循环 + 3 个双对换。双对换 = 两个 3-循环的乘积 ⟹ **类内任意偶置换 ≤ 12 步**（两段模板拼）。

但注意：D=6 每类只抓到 2 个 3-循环（一个三元组的正反），其余 6 个是否也 6 步，未验。「有样本」足够生成，效率待定。

### 2.3 两个类各一个 3-循环（合法且更省）

D=6 里有 `{(0,0):(3,1), (0,1):(3,1)}` 型——两类的两个 3-循环，另外两类完全不动。3-循环是偶，偶×偶仍是偶 ⟹ 合法。

## 3 一级与二级的关键差异

| 项 | 一级 `(4,4,1)` | 二级 `(4,4,2)` |
|---|---|---|
| 有 mod 类约束 | 无（s=1 只有一类） | 有（4 类，各 4 块，互不交换） |
| 奇偶守恆 | 无 | **无**（D=8 起被推翻，见 §1） |
| 回原样可达 | 16! 全可达（絕對位置版已機檢） | **24⁴ = 331,776**（D≥8 实测） |
| 单对换 | **可，7 步**（D=6 里零个 `(2,1×14)`，7 步构造已存档） | **可，9 步**（D=9 实测 20 条，已被存档复现） |
| 局域操作 | 无天然划分 | 每个 mod 类可独立做整个 `S₄`（含奇） |

**白话**：一级是「一副 16 块的散牌」；二级是「四个盒子各锁 4 块」——盒子之间不能换人，盒子内部 4 块随便怎么摆都行。**二级没有奇偶帐，只有分类帐。**

## 4 手工验证一条序列的方法

1. 序列每条是 `(comp 包围盒, unit)`，`unit` 是 4 方向之一，位移量固定 = `s = 2`。
2. `comp` 必须是 4-连通，且 `|comp| = m·n = 16`（`s=2` 下一次移动携带整块的形状，不是单块）——实际由 `moves.legal_moves` 判合法性。
3. 框坐标落在负数不算错，见 §1 的说明。
4. 算净效果：跟踪 16 个标签的最终位置，得 `label → pos` 映射，**只需检查每块的 `(r%2, c%2)` 与初始一致**。⚠ 原先这里还要求「四类符号乘积 = +1」，该约束已被 D=8 推翻，不要再拿它当校验条件。
