# 形狀圖的橋與割點：瓶頸完全幾何化

> 2026-11-25。機檢 `networkx.bridges` / `articulation_points`。用途：給 L2（弱連通）定難點位置。

---

## 0 一句話

形狀圖**不是** 2-邊連通的——K=9 有 3 條橋、K=10 與 K=12 各 1 條，且全部落在「直鏈 + 一根側枝」的最瘦族形狀上。

**「形狀圖無橋」設想作廢。**

## 3 結論

**R-a 橋完全落在「最瘦族」。** 三種尺寸的所有橋，兩端都是「一根直鏈 + 一根側枝」，差別只在側枝掛在鏈的哪一格。這與 `087178e` 的「最遠點唯一是細長 L」是同一個族——**最難到矩形的形狀，剛好也是形狀圖的割點**。

**白話**：形狀圖的骨架是一大片 2-邊連通的「胖」區域，外面掛著幾根「細長側鏈」，而這幾根側鏈的頸部就是那 1–3 條橋。

**R-b 側枝收回只有一條通道。** 側枝要沿直鏈挪到頭，中途必須逐格經過那些割點位。所以「壓扁」（`087178e`）之所以卡、之所以是 K 步級，是因為它走的是一條串聯通道，不是並聯網。

**R-c L2 的難點被定位了。** 證明「形狀圖弱連通」不需要處理全部 63,600 個形狀——只需要：

1. 證明「胖」部分（割點以內）連通；
2. 證明「側枝能沿直鏈一路挪到頭」，即那 1–3 條橋可以被「走過」。

第 2 條就是 L 族 = K−1 步那件事的另一種說法。

## 4 推翻的舊設想

`05_命題與證明計畫.md` / `06` 裡曾有「L2 只需要無橋，比連通弱一檔」的說法。

**這個想法錯了**：實測有橋（K=9 三條、K=10/12 各一條），不是無橋。正確表述是：

> 形狀圖**幾乎** 2-邊連通——2-邊連通分量只有 2 個（K=10/12）或 4 個（K=9），被 1–3 條「側鏈頸部」的橋切開。

這個表述比「無橋」弱不了多少，但它是**真的**，而且直接指出證明要補哪一塊。
