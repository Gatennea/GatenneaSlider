# 研究进度总结（2026-10-14）

## 0. 问题形式化（用户给定口径）

**标题**：对于"所有'1'元素构成 4-联通分量"的重量固定的 01 矩阵在特定变换规则下的状态计数问题与状态图性质研究。

**状态**：支撑集四连通、重量 K 固定的二元矩阵。

**变换（一次移动）**：任取一条贯穿其包围盒的行（或列）分界线，将矩阵按该线切成两个非空子矩阵，把其中一个子矩阵的某个四连通分支整体沿线平移 s 个单位；平移逐单位步执行，全程与另一子矩阵不交且并集保持四连通，否则该变换不存在。

**还原态**：重量 K 定义为合数 n·m；当矩阵尺寸为 n×m（或 m×n，即矩形）时，它是还原（目标）态。

**状态机**：在该变换下，所有重量 K 的四连通 01 矩阵构成一个有向状态机；问题即研究该状态机的形状展开（计数与图性质）。

**本文档使用的符号映射**（与复现引擎一致）：

| 形式化概念 | 引擎量 | 含义 |
|---|---|---|
| 全部合法状态（重量 K、四连通、包围盒内） | `|A|` | 状态机顶点总数 |
| 还原态的正向锥 `cone` | `|cone|` | 从还原态正向可达的状态集 |
| 接受态（可解集 B） | `|B|` | 能回到还原态的状态集（回程可达） |
| 上帝之数 | `god` | B 上离还原态的最远距离（回程口径） |
| 死局 / 逃逸态 | `dead` | 在 `cone` 中但不在 `B` 中（正向可达、永远回不去） |
| 单步不可逆边 | R8 | 两端都在 B 内、且逆步非法的有向边 |
| 排列群 | R6 `|G|` | 标签在"净效果"意义下可达的置换群 |

> 注：用户口径"初始/还原/接受态"把矩形（n×m）同时称作三者；本文档将矩形固定为**还原态**，B 为**接受态**，A 为全部状态空间。

## 2. 第一项定理：粘连型唯一性（全量验证）

文档：`docs/math/粘连型唯一性证明.md`。

- **引理 1（可选即合法）**：落位分量 C′ 仍可选 ⟹ 逆步合法且终态=原态（五步逐条验证，不依赖 C∩C′=∅、不依赖原缝）。
- **定理 1（粘连型唯一性）**：逆步非法 ⟹ C′ 失去可分性（逆否一行证）。
- **推论**：回移违规 / 异常两类恒为 0；故"单步不可逆 ⇔ 粘连型"对两尺寸成立。

**全量验证（决定性）**：修复引擎 R8b 两处 bug 后，两尺寸单步不可逆边**逐边**核验均 100% 粘连型：
- (4,4,2) **880,858 / 880,858**，回移违规 0、异常 0
- (4,4,3) **12,926 / 12,926**，回移违规 0、异常 0

**验证中修复的引擎 bug（重要）**：
1. 落位像误用 `res & ~comp`（`comp`=移动前分量，已不在 `res`），使 image 退化整张棋盘 → 虚假"全粘连"。此前"300 抽样全粘连"即此 bug 假阳性。
2. 粘连判定未限"同轴缝"（水平滑动只能由水平缝选回），虚增非粘连型。

**扩展证据**：参数扫描（§4）覆盖的 13 个尺寸中，凡可算粘连者（B 内不可逆边数 ≤ 6 万）**全量均 100% 粘连型**（如 (3,3,2) 27/27、(4,3,2) 5779/5779、(5,3,2) 249113/249113、(3,3,1) 1433/1433）。定理从"两尺寸抽样"升级为"多尺寸全量"支撑。
