# 打包與發版

> 2026-11-06 從 `agents.md` §4 / §19 拆出（內容未改，另補一條開機動畫資源的打包約定）。
> 相關：`Gatenneaslider.spec`、`build_exe.bat`、`build_release.py`、`gui/updater.py`。

## 1. 打包鐵律

- 每幀調用的可選功能**必須能力檢測**（主循環一個大 try 包住事件 + 全部繪製 + flip）；
  任何異常只讓整幀不繪製（白屏但進程活着、windowed 無輸出）。
- 新增運行時資源**必須同步 spec 的 `datas`**，不可排除 `pygame.cursors` / `pygame.sprite` / `pygame.mask`。
- 日誌路徑順序：exe 同級 `config/` → `%APPDATA%/GatenneaSlider/` → temp。
- **開機動畫 / 啟動圖**：幀序列走 `datas`（`assets/picture/boot/frame_*.png`），啟動圖走
  `EXE(splash='assets/picture/splash.bmp')`（PyInstaller 在 exe 啟動段自行顯示，GUI 起來後
  `pyi_splash.close()`）。兩者都屬可選功能——加載失敗只跳過，不許崩。
- 新增 `datas` 後**必須實測一次打包產物**：源碼能跑 ≠ 打包能跑（`_MEIPASS` 路徑、缺檔、白屏都在這一步暴露）。

## 2. 版本號與發版（2026-10-17 改）

- **版本號 = 打包日期 `vYYYYMMDD`**（`build_release.py` 不再用 Git 提交數）。不給 `--version` 時自動取今天。
- **改因**：舊規則「Git 提交數 + 日期」的提交數會被 **squash 合併壓小**，提交數不再單調，曾發生
  `v154 < v197` 倒退——發出去會讓裝 v197 的用戶被更新器判為「已最新」、**永不彈升級**。
  日期天然單調、與 git 歷史無關。
- **更新器兼容**：`gui/updater.py` 只比較版本號 v 後第一個 `-` 前的整數（`v20261017` → 20261017），
  恒大於舊的 `v197` 等提交數版本，**過渡無礙，比較邏輯不用改**。
- **手填版本號約束**（`build_release.py` 校驗）：須 `vYYYYMMDD` 或 `vYYYYMMDD-xxx`，且日期**不早於今天**
  （防倒退）；舊制 `vN-YYYYMMDD` 放行。
- **同日發兩版**：直接取下一天日期，或 `--version vYYYYMMDDHHMM`（帶時分才能真正比舊的大；
  `v20261017-2` 這類後綴比較時只看前導整數 20261017，同日不會判新）。
- **發版走 GitHub 網頁手動**：tag 填版本號，上傳 **`GatenneaSlider-Windows.zip` + `version.json`**
  兩附件；zip 文件名必須固定（下載鏈接 / 更新器都依賴它，改名即失效）。

## 3. 開機動畫素材（2026-11-07 換代）

`assets/picture/boot/frame_*.png` 與 `assets/picture/splash.bmp` 都由
`tools/gen_boot_assets.py` 離屏生成，改動畫改這個腳本再重跑，不要手改某一幀。
幀名必須保持 `frame_000.png … frame_NNN.png`（`GUI.py::_load_boot_frames` 按
`glob` 排序載入），解析度 854×480 RGBA，執行期墊 (30,30,30) 底色再 cover 縮放。
腳本不依賴 `video/`：素材配色（背景 30 / 藍塊 60,150,200 / 縫 80 / 描邊 100）
直接寫在腳本裡，`video/materials/cover_shuf.png` 之類只作視覺參照，
clone 倉庫後沒有 `video/` 也能重生成。

## 4. 背景樂格式與安裝包體積（2026-11-07 定）

**問題**：`assets/audio/music/` 原本放 6 分 23 秒的 44.1kHz / 16bit 立體聲 WAV
（64.5MB），比整個遊戲程式還大。PCM 用 zip deflate 實測只壓到 61.2MB，
也就是**一旦重新打包，31MB 的安裝包會直接漲到 90MB 以上**，而且往後每加一首
就再漲一截。

**約定**：`assets/audio/music/` 只放壓縮格式 `.ogg` / `.mp3`，正式曲目命名
`bgm.ogg`（`gui/audio.py::_find_in` 優先認 `bgm.*`）。選 OGG 不選 MP3 是因為
`mixer.music` 循環播放時 Vorbis 無縫，MP3 有編碼器延遲會在接縫處喀一聲。
128k 品質：64.5MB → **5.31MB**，時長、立體聲、採樣率都不變。

新曲子放進來之前先轉（本機 `ffmpeg` 的 WinGet shim 是 0 位元組壞檔，要用
`D:/python/python.exe -c "import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())"`
取出真實執行檔，或直接裝一個正常的 ffmpeg）：

```
ffmpeg -i 母带.wav -c:a libvorbis -qscale:a 4 assets/audio/music/bgm.ogg
```

`.wav` 母帶留在本機即可，**不進版本庫、也不進安裝包**：`.gitignore` 有
`assets/audio/music/*.wav`；`Gatenneaslider.spec::_collect_assets()` 會主動跳過
`music/*.wav`；`build_release.py::warn_raw_music_assets()` 打包前會提醒還留著幾個。
⚠️ 只擋 `music/`：`assets/audio/sound/slide*.wav` 是 70~165ms 的短事件音，
必須照常入庫、照常進包。

往後曲子變多時按 6 分鐘 ≈ 5MB 估算；真要控體積就降 `-qscale:a 3`（約 96k），
或改成首包只帶一首、其餘按需下載，不要靠 zip 壓縮救。
