## 1. 匯報與術語（對用戶 / 對協作方）

- 匯報順序：**運算時間 > 解的長度**（先說耗時，再說步數）。
- 術語：**聚攏度**（不說 ov）；**空位** = 缺口 + 孔洞統稱；**Couple** = 粘上接走配對。
- 坐標必須附「從 1 數第幾行第幾列」。
- 用戶定方向不管實現；匯報失敗要區分「實現沒學到」vs「方向沒價值」。
- **解釋交付結果**：盡量用協作方能自然理解的說法，**避免自造詞 / 過於專業的形式**；
  **不提底層實現細節**（內部函數名、算法代號、度量符號等留給代碼與文檔，不進交付說明）。

## 2. 遊戲語義（避免說錯話）

- **等級 ＝ 步長(step) 同一概念**，勿把「等級 / step / 尺寸」當三件獨立事。
- **縫是刀不是被推對象**：點選塊為錨，切出連通片沿平行縫平移；UI 先標「帶走哪些塊」再標
  「能往哪走」。宣傳片裡縫不是賣點。
- **異形 = 進階挑戰 + 開放數學難題**，不當「已完成功能」展示；可點「連作者也還在摸索解法」。
- 等級 2 的 6×6 ≈ 三階魔方。
- **三種模式：練習 / 創造 / 競速**（創造模式 ≈「允許拆開重裝、自動檢測能否還原」的魔方，利於做教程）。
- **四種形狀（密鋪形態）：方形 / 三角 / 米字 / 數字**，數字由玩家建議加入（非作者原創構想）。
  異形求解器當前實裝三角 / 米字（形態支援表見 `docs/agent/readme_to_agent.md` §12）。
- mi 聚攏度 0 復原是**預期**不是缺口（方形同預算也是 0 復原），勿寫成「架構缺口」。

## 3. 官網 / 宣傳（GatenneaSliderWeb，獨立倉庫）

- 官網**教程不寫解法術語**（用玩家語言，不暴露求解器內部概念）。
- 官網截圖**用真實遊戲截圖**，**不用 SVG / emoji 做圖示**。
- `app.js` 是打包產物 → 改 `src/*.ts` 再 build，勿直接改 `app.js`。
- 多語言文案：先確認副本數（繁 / 簡各幾份）再動；用戶直改簡體文案時，繁簡可能整段改寫，
  先 grep 避免改錯位置。
- 首屏 `<nav>` 寫 `class="nav"`。

## 4. 官網圖解頁鐵律

- 畫風：深色 `#0d0d0f` + 藍 `#4696c8` + 綠 `#87cf92`；遊戲真實色板（滑塊淡藍 `#3c96c8`、
  選中綠 `#00c864`、縫線紅 `#ff0000`）。導航繁簡雙入口「狀態圖圖解」，「支持貓九」恒在最後。
- **死局口徑（官網專用，勿改）**：用戶拍板官網「死局」= cone\B（從還原態走得到卻回不去），
  **不是** sink（一步都動不了）。全頁統一口徑，勿「糾正」成 sink；sink 在官網只叫「一步都動不了」。
  **具體數字只在 `docs/math/權威數據.md` 維護，官網文檔不抄第二份。**
  嚴謹論文口徑相反，見 `docs/math/写作与口径.md`。
- **配圖二選一**：能用真實遊戲截圖的（局面 / 卡死 / 滑動箭頭 UI）一律用真截圖（源
  `GatenneaSlider/video/materials/` 與 `experiments/out/`）；抽象結構（集合切分 / 狀態圖）才重畫 SVG，
  且必須乾淨專業。圖片統一放倉庫 `Web/images/`（勿新建 `img/`）。
- ⚠️ **禁止用 SVG `<marker>` 畫雙向箭頭**：marker-start / end 共用 orient="auto" 會讓起點箭頭指向內部
  （畫不出 ⇄）。正確做法 = Python 直接算三角形頂點畫 `<polygon>`（尖端距圓心 R+1，底邊中點距圓心
  R+1+AH_LEN；AH_LEN=16 / AH_WID=13），方向由幾何決定；改完跑幾何校驗（尖端比底邊中點更靠近所指節點，
  錯誤數須為 0）。
- **集合關係圖 ＝ 真實比例環形圖**（別用兩圓疊加，交集占比看不直觀）：四塊互斥分區按真實角度切環 +
  右側圖例（色塊 + 名稱 + 數量 + 百分比）+ 底部「把細縫放大」堆疊條讓極小區塊可辨；**絕不放大扇區角度**。
- ⚠️ **SVG 文字必須跑自動重疊校驗**：按 east_asian_width 估算每個 `<text>` 包圍盒
  （CJK=1.0×font-size、ASCII=0.55×；y 盒 = baseline−0.8×size 到 +0.24×size），逐對判相交 + 判越界
  viewBox，須為 0。
- 圖解頁零符號：`A / B / cone / sink / god / SCC / 出度 / 上帝之數` 一律不出現（改說「全部局面 /
  去程可達 / 回程可達 / 可還原 / 真死局 / 一頭都不沾 / 最難還原步數」）。**例外：用戶明確要求講
  「著色集合」**（= 所有合法狀態的全集，一切數字的分母）時這個詞必須出現並解釋清楚
  （守恆約束等價於按坐標染色、滑動時每種顏色塊數不變）。
- **官網只放輕量數據**：`GatenneaSliderWeb/data/` ＝ 22 謎題總表 `ALL_SUMMARY.csv` + 距離分布
  `distance_distribution.csv` + `per_puzzle/<m>x<n>x<s>/summary.txt` + `README.md`（共約 34KB）。
  **論文草稿 / 證明 / 研究現狀不搬官網**（未發表 + 含舊死局錯誤 + 投稿風險）；
  **679MB 原始二進制不搬**（`boards.bin` 399MB 超 GitHub 100MB 硬限制），官網註明「可用開源引擎重算」。
