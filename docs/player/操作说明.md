# 二维操作说明

## 怎么玩

一块蓝色方块就是一个滑块，所有滑块始终连成一块整体。把打乱的滑块组还原成实心形状就算过关。

1. 点一条「缝隙」（滑块间的分隔线），它变成红色
2. 点缝隙一侧的任意滑块，整组变绿
3. 按 W/A/S/D（或 F1 虚拟键盘）整体滑动，一次走「等级」格
4. 还原成实心形状即过关

第一次玩，菜单栏「教程」有交互式新手关卡，跟着做一遍最快。

## 核心规则

1. 滑块组任何时候必须连成一体，不能断开、不能重叠。移不动不是坏了，是规则在保护连通性
2. 滑块按「组」划分，同组才能换位置（2 级矩形分 4 组）。右下角打开「着色」按组涂色，打开「连锁」悬停时高亮同组能去的地方
3. 难度由形态和等级决定：矩形最简单，三角形更难，米字格最难。奇数级往往比相邻的偶数级难
4. 选缝有两条硬规矩：缝不能穿过任何滑块，缝两侧都要有滑块。最外沿的缝、米字格错开半格时的部分横竖缝选不中，换一条就行

## 三种谜题

1. 矩形：基础形态，适合入门
2. 三角形 / 米字格：异形形态，难度递增；没有随机生成，造题请用「手动构造」
3. 数字谜题：滑块带编号，按编号还原，难度更高

## 模式

右下角切换。练习：自由探索。竞速：打乱后按空格开始计时，复原自动停表，计时中再按空格记 DNF。创造：自己造题，方形可随机生成或手动构造，三角和米字只能手动构造。

## 常见问题

   - 移不动：滑块会被拉断或重叠，规则直接拒绝
   - 缝点不中：见上面第 4 条
   - 求解只走几步：见「通用」页「为什么求解常常只走几步就停」
   - 打乱很慢：尺寸很大时正常，等一会儿
   - 键盘没反应：输入法切到英文；或按 F1 用屏幕上的虚拟键盘
   - 关掉游戏会丢进度吗：不会，会自动缓存上次状态；也可以用 Ctrl+S 手动存

## 右下角与面板

   - 缩放、速度：拖动滑块
   - 动画、着色、连锁：三个开关，随时可拨
   - F1 虚拟键盘：三角是六向布局，米字是八向，米字主要靠它走
   - F2 调试面板：看当前聚拢度等数字；棋盘上的记号和框在「设置 → 视觉」里单独控制
   - F3 成绩面板：按谜题分组看成绩和平均
