# 三维操作说明

三维谜题和二维是两套操作：二维先点缝再点块，三维不画缝隙，改用右键选「切面」、左键选滑块。第一次进三维局会弹一个四步小引导，可跳过；想再看可以到「谜题 → 三维谜题」菜单里重看。

## 打开三维谜题

- 菜单「谜题 → 三维谜题 ▸」选一档开局（2×2×2 起步最容易）
- 或「谜题 → 自定义」，形态选「三维」，填行数 / 列数 / 层数 / 等级
- 三维建局处都标了「三维操作与二维不同 · 查看操作」，点它直达本页

## 视角与相机

- **左键按住空白处拖动** = 旋转视角，任何角度都能直接选切面、选滑块，不需要转正
- **Ctrl + 滚轮** = 缩放画面
- **没选中滑块时点虚拟键盘六个方向键** = 平移整个盘面（选中后同样的键变成推动）
- **数字键 1–6** = 切到六个固定朝向（每个都带一点倾斜，方便看出立体）；**0** = 回到默认斜视
- 手动平移后画面不再自动跟随滑块组中心；右下角操作卡里的「回到中央」把平移归零并恢复跟随
- 右侧栏有「缩放 / 速度 / 拆分 / 切面」四条竖滑条，边拖边看

## 怎么选切面（右键）

1. **右键点方块的一个面** = 选中这个面所在的切面，选中的切面整片红色预览
2. 切面一共三个方向：横排之间、竖列之间、层与层之间——点不同方向的面就换族
3. **右键点空白处** = 取消选中
4. 没选中切面时左键点滑块会提示「先右键选一条缝」——这是固定顺序，先选面再选块

## 怎么选滑块、怎么推动（左键 / 箭头 / 六键）

1. 选好切面后，**左键点切面一侧的任意滑块**，那一侧连着的整组变绿
2. 选中后点击处附近会出现**方向箭头**，点箭头就往对应方向推一格
3. 虚拟键盘（F1）三维版是**六个方向键**（三对，对应三个轴），点一下推一格
4. 滑不动是因为会拉断或重叠——和二维一样是规则在保护，不是卡住

## 撤销与重做

- **Ctrl+Z** 撤销，**Ctrl+X** 重做，和二维完全一样
- 走乱了先撤销，再想下一步

## 常用按键小结

- 左键拖空白 = 旋转｜Ctrl+滚轮 = 缩放｜数字 1–6 = 换朝向，0 = 斜视
- 右键点面 = 选切面｜右键空白 = 取消｜左键点块 = 选整组
- Ctrl+Z / Ctrl+X = 撤销 / 重做｜Ctrl+K = 命令面板｜F1 = 虚拟键盘

## 创造模式：放块与挖块

- 「模式开关 → 创造」后选「三维搭建」（造打乱局面）或「还原状态 → 三维搭建」（造复原目标）
- **左键点一个可见面**：当前是「挖除」就拿掉这块，切到「放置」就往面外放一块
- 工具条或数字键 **1** 切「放置」、**2** 切「挖除」；**R** 恢复进入时的样子，**C** 清空
- 拖动空白仍然是旋转视角；**Esc** 取消退出，**回车**（或点「完成」）保存
- 造复原目标必须先给样式起名字；保存时会检查连通性和有没有可走的步，只过必要条件、不保证可解

## 切面和二维的缝隙有什么不一样

- 二维把每条缝都画在盘上，直接点就行；**三维不画缝**，靠右键点「面」来告诉游戏你要切哪里
- 选中的切面是**整片红色**（被方块挡住的部分不会画出来），缝两侧的墙面也会染红，一眼能看出刀切在哪一层
- 二维选缝有「缝两侧都要有滑块」等规矩，三维同理：点到没有内部切面的面会提示换一个面点
- 二维是「点缝 → 点块 → 方向键推」，三维是「右键面 → 左键块 → 箭头 / 六键推」，顺序一样，入口换了

## 求解器与宏

- 三维求解器尚未接入：按 Ctrl+A 会明确提示不支持，不会拿二维算法硬算
- 宏、竞速计时、存读档、撤销重做在三维照常可用
