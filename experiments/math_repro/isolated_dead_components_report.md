## 0. 说人话

我们把这个滑块谜题两个尺寸（4×4 棋盘、步长 2 和 3）的**全部**局面画成了一张有向地图：每个局面是一个点，每步合法移动是一条箭头。然后专门盯上了其中一块「进了就别想出去」的区域——里面的局面**既走不回通关状态，也走不到真正的死局**，只能在一些**首尾相扣的小圈子**里无限打转：圈子里的几个局面，你走到我、我走到他、他再走回你，永远出不来。两个尺寸的发现几乎一模一样，规模不同而已：

1. **这块被困区域是真实存在的，而且不小**：4_4_2 有 **263** 个局面被困（占全部 56 万局面的 0.047%），4_4_3 有 **1094** 个（占 2.46 万的 4.4%）。所有不可解局面里，约四分之三到五分之四（80.2% / 75.9%）都属于这种「打转型」，而不是「走进死胡同型」。
2. **小圈子都很小**：4_4_2 的 263 个状态分成 **127 个**小圈子（最大的才 8 个状态；圈子之间有少量单行道相通，见 §3.2）；4_4_3 的 1094 个状态分成 **352 个**小圈子（最大的 36 个）。
3. **整个被困区域只进不出**：从区域内任何一个局面出发，走任何一步都还在区域里（向外的箭头 **0** 条）。但不是完全密封——各有 **2** 条箭头从**正常可解的局面**指进来，其中一条甚至是从通关态乱走就能到达的局面发出的。也就是说：**好好玩不可能被困，但「一步走错」确实可能永世不得超生**。
4. **圈子内部大多是「一根链条首尾相扣」**：4_4_2 有 34 个圈子是干干净净的单环（每个状态只有一条对内出路），62 个是单点；带额外岔路（弦）的圈子 31 个。4_4_3 类似（193 单环 / 132 带弦 / 27 单点）。还有几个单点状态靠「走了一步等于没走」（自环）原地永动。
5. **被困状态被卡得特别死**：它们的平均出路数只有 2.45（4_4_2）/ 1.70（4_4_3），而全图平均是 7.63 / 3.83——正常局面的选择多得多。
6. **跟对称性基本没关系**：绝大多数被困形状毫无对称性（85.9% / 97.7% 旋转翻转自对称群为平凡群）；更关键的是，每个局面本身就是一个「旋转翻转等价类」，所以圈子里的状态不可能互为旋转翻转像；「颜色置换」在这个数据口径下同样退化成恒等，没有可捡的规律。
7. **对比另一类不可解**：328（1442）个不可解局面里，65（348）个其实会流进真死局——它们大多是半冻结状态（52/327 个干脆就是真死局本人）；剩下 263（1094）个才是打转的。**死局不是不可解性的主源，永动小圈子才是。**

严谨数字见下文。

## 2. 孤立死区边界：只进不出的「陷阱区」

把 263（1,094）个孤立死状态从 `edges.bin` 导出为诱导子图（只保留两端都在集合内的边）：

| 量 | (4,4,2) | (4,4,3) |
|---|---:|---:|
| 孤立死状态 | 263 | 1,094 |
| 子图边 | 645 | 1,860 |
| 孤立死 → 外界 的边 | **0** | **0** |
| 外界 → 孤立死 的边（入口） | 2 | 2 |

结构性事实（可由集合定义直接推出，也已逐边验证）：孤立死状态的**每一个**后继都还是孤立死状态——因为若后继可解则它也可解、若后继能到死局则它也能到死局。所以整个孤立死区**没有一条向外的箭头**：进去就再也出不来。

两条入口边（唯一的口子，均来自可解侧 B∩吸引盆）：

| case | 入口边 | 源状态在 cone（打乱可达）内？ |
|---|---|---|
| 4_4_2 | 363829 → 356752；417154 → 356752 | 363829 否；**417154 是** |
| 4_4_3 | 12613 → 2620；18406 → 15813 | **两者都是** |

也就是说，从还原态出发做合法的自动打乱，确实可能一步踏进永动陷阱（4_4_2 一条、4_4_3 两条这样的入口）。

## 3. 小圈子（强连通分量）清单

SCC 分解方法：numpy 读 `edges.bin` 建 CSR 邻接表 → 迭代版 Tarjan（显式栈）；同数据另跑迭代版 Kosaraju 独立复核；两者跑分前先在 300 张随机有向小图上与**暴力传递闭包**三方比对（划分完全一致）才允许正式跑。两个尺寸上 Tarjan 与 Kosaraju 的划分均一致。

### 3.1 分量个数与大小分布

| 量 | (4,4,2) | (4,4,3) |
|---|---:|---:|
| SCC 个数 | 127 | 352 |
| 平均大小 | 2.07 | 3.11 |
| 最大分量 | 8 | 36 |
| 大小直方图（大小×个数） | 1×62, 2×36, 3×6, 4×13, 5×3, 6×6, 8×1 | 1×27, 2×194, 3×51, 4×28, 5×18, 6×16, 7×4, 8×4, 9×1, 10×1, 11×3, 18×1, 19×1, 20×1, 23×1, 36×1 |

两个尺寸的分布都严重右偏：绝大多数是 1~4 个状态的小圈子。(4,4,3) 有 5 个「大圈子」（18/19/20/23/36 态），(4,4,2) 几乎没有。

### 3.2 分量之间是否相连？

| 量 | (4,4,2) | (4,4,3) |
|---|---:|---:|
| 跨分量的边（分量 A → 分量 B） | 276 | 74 |
| 凝聚图（每分量缩为一点） | 127 点 / 276 边 | 352 点 / 74 边 |
| 汇分量（无出区边，永动陷阱底） | 31 个（大小 1×2, 2×18, 3×2, 4×6, 6×3） | 315 个（大小 1×3, 2×185, 3×47, 4×28, 5×18, 6×16, 7×4, 8×4, 9×1, 10×1, 11×3, 18×1, 19×1, 20×1, …） |
| 源分量（无入区边） | 76 个（大小 1×51, 2×20, 3×2, 4×2, 5×1） | 327 个（大小 1×27, 2×189, 3×41, 4×25, 5×16, 6×12, 7×3, 8×4, 9×1, 10×1, 11×3, 18×1, …） |

**结论：孤立死区不是若干互不相连的「孤岛」，但也远不是一团匀质的迷宫——两个尺寸展示了两种不同的拓扑性格：**

- **(4,4,2)**：276 条跨圈子单行道分摊到 127 个圈子上（平均每圈 2.17 条），小圈子之间相当互联；只有 31/127 = 24.4% 的圈子本身是「坑底」，其余圈子踩几步还会掉进别的圈子。
- **(4,4,3)**：只有 74 条跨圈子边分摊到 352 个圈子上（平均每圈 0.21 条），**89.5% 的圈子本身就是坑底**——整个区域更接近「一堆互不相干的小孤岛，外加几条狭窄的单向走廊」。

（注：`docs/math/可发表结论清单` B4 中「76 个孤立死分量」是**旧口径**（A∖(B∪cone) = 319 个状态）下的说法；本报告按现行真死局口径重算，263 个状态对应 127 个 SCC，其中凝聚图源分量恰为 76 个。）

### 3.3 分量内部结构：单环 / 自环单点 / 带弦

分类标准：分量内边数 E 与节点数 V 比较。强连通下 E=|V| 当且仅当每个节点对内出度恰为 1，即一根覆盖全分量的简单有向环（无弦）；E>|V| 称为「带弦」（岔路）；E−|V| 记弦数。

| 结构类型 | (4,4,2) | (4,4,3) |
|---|---:|---:|
| 单点分量 | 62（其中**自环永动单点** 2） | 27（其中**自环永动单点** 3） |
| 纯单环（无弦） | 34 | 193 |
| 带弦分量 | 31 | 132 |
| 带弦分量的弦数分布（E−|V|） | 1×3, 2×7, 3×5, 4×5, 5×1, 7×3, 12×6, 16×1 | 1×39, 2×11, 3×18, 4×19, 5×10, 6×1, 7×4, 8×11, 9×2, 10×3, 11×3, 12×2, 13×1, 14×1, 15×1, 16×1, 27×1, 30×1, 32×1, 35×1, 66×1 |

- 「纯单环」占比：(4,4,2) 34/127 = 26.8%，(4,4,3) 193/352 = 54.8%——(4,4,3) 里过半、(4,4,2) 里约四分之一的小圈子就是一根首尾相扣的链条。
- 「自环永动单点」：单点分量带一条 u→u 的边，走一步回到自身（规范形不变），是最小的永动陷阱。
- (4,4,3) 的大圈子弦很多（最大 36 态圈子有 102 条内边 = 36 + 66 条弦），圈子内部像一张稠密小网。
- 分量内平均出度（按节点计）：(4,4,2) 1.403（最大 4），(4,4,3) 1.633（最大 5）。有 60（24）个节点对内出度为 0——全是单点分量，它们的出路全部指向别的圈子，是凝聚图里的「过客」。

## 4. 孤立死状态的度数 / 距离分布

| 量 | (4,4,2) | (4,4,3) |
|---|---:|---:|
| 总出度：平均 / 范围 | 2.452 / 1~6 | 1.700 / 1~5 |
| 出度分布 | 1×76, 2×82, 3×28, 4×70, 5×1, 6×6 | 1×541, 2×381, 3×133, 4×37, 5×2 |
| 总入度：平均 / 范围 | 2.460 / 0~12 | 1.702 / 0~6 |
| 入度分布 | 0×49, 1×74, 2×45, 3×32, 4×21, 5×9, 6×9, 7×7, 8×6, 9×6, 10×3, 11×1, 12×1 | 0×24, 1×530, 2×347, 3×141, 4×46, 5×5, 6×1 |
| dist（回程距离） | 全为 −1（无定义） | 全为 −1（无定义） |
| 入度为 0（谁都到不了它） | 49 个 | 24 个 |
| 对照：全图平均出度 | 7.628 | 3.831 |

- 孤立死状态**没有**出度为 0 的（出度 0 即真死局、必在吸引盆，定义上被排除）；最少也有 1 条出路，但出路全在孤立死区内或通向区内别的圈子。
- dist 字段是「回程距离，不在 B 内为 −1」，孤立死状态全部不可解，故 dist 一律无定义——这不是缺失，是定义使然。
- 孤立死状态的平均出路数远低于全图平均（2.452 vs 7.628；1.700 vs 3.831）：被困状态普遍「动不了几步」，这与小圈子体积小、边稀疏互为因果。

## 5. 对称性分析（boards.bin 规范形）

数据事实：`boards.bin` 中全部 559,832（24,605）个规范形**两两互不相同**——每个顶点本身就是「平移归零 + D4 八变换取最小」后的唯一代表，即**一个 D4 等价类**。由此得到两个严谨结论：

1. **分量内状态不可能互为 D4 对称像**：若两个状态互为旋转/翻转像，它们会收敛到同一规范形、成为同一顶点。顶点互异 ⟹ 分量内任意两状态 D4 不等价。该问题在此口径下**恒否**，无需逐个分量检查。
2. **分量内状态也不可能互为「颜色置换像」**（颜色 = mod s 位置类）：颜色置换由平移（或平移复合 D4）诱导，而规范形对平移不变——脚本对每个孤立死状态做了直接验证：把格子集平移 (1,0)、(0,1)、(1,1) 后重新归一，规范形逐字节不变（两个尺寸全部通过）。故平移诱导的颜色置换把每个顶点映到自身，同样不产生新顶点。
   - 若把「颜色置换」理解为**不保几何的抽象重标号**，则该作用不施加于形状顶点集，问题在此数据口径下**无定义**（如实标注：未决/不适用，不做猜测）。

可以客观量化的是**被困形状自身的 D4 自对称性**（稳定子群阶 = 8 / 轨道大小）：

| 形状 D4 轨道大小 | 含义（自对称群阶） | (4,4,2) | (4,4,3) |
|---|---|---:|---:|
| 8 | 无自对称（群阶 1） | 226 | 1,069 |
| 4 | 有一阶自对称（群阶 2） | 35 | 21 |
| 2 | 群阶 4（如矩形类） | 2 | 4 |

**绝大多数被困形状毫无对称性**：(4,4,2) 226/263 = 85.9%、(4,4,3) 1069/1094 = 97.7% 的自对称群阶为 1。被困与形状对称性基本无关。

mod 类着色向量核对（全部孤立死状态均合法，即目标矩形某个相位平移下的类计数）：

- (4,4,2)：263 个状态全部是唯一的 {4,4,4,4} 向量（正方形目标让相位平移不改变计数向量）；
- (4,4,3)：9 种相位对齐向量各占一部分（237/224/200/163/134/78/29/25/4 个），全部落在目标矩形的合法相位集合内。向量种数 = 9 = s²，与理论预期一致。

## 6. sink（真死局）与「不可解但能到死局」对比

| 量 | (4,4,2) | (4,4,3) |
|---|---:|---:|
| sink 数量 | 52 | 327 |
| sink 的 dist | 全 −1（均不在 B） | 全 −1 |
| sink 的入度：平均 / 范围 | 0.29 / 0~2 | 0.06 / 0~3 |
| sink 入度分布 | 0×38, 1×13, 2×1 | 0×310, 1×15, 2×1, 3×1 |
| sink 是否都在吸引盆内 | 52/52（自身即死局） | 327/327 |

| 不可解局面的两类归宿 | (4,4,2) | (4,4,3) |
|---|---:|---:|
| 不可解但能到死局 | 65（平均出度 0.25、入度 0.34） | 348（平均出度 0.07、入度 0.08） |
| 不可解且孤立（永动陷阱） | 263（平均出度 2.45、入度 2.46） | 1,094（平均出度 1.70、入度 1.70） |
| 合计（不可解 = A−B） | 328 | 1,442 |
| 其中 cone\B 逃逸态 | 9（到死局 6 + 永动陷阱 3） | 6（到死局 2 + 永动陷阱 4） |

- **多数真死局根本没人疼**：38/52（73%）与 310/327（95%）的 sink 入度为 0——全图没有任何箭头指向它们（「够闷的角落」，打乱永远踩不到）。
- 「不可解但能到死局」这一组几乎是半冻结状态的集合（平均出度 0.25 / 0.07），其中大部分干脆就是 sink 本人（52 / 327 个），其余少数会流进死局。
- 换个说法：**不可解性的主源不是死局，而是永动小圈子**——263/328 = 80.2%（1094/1442 = 75.9%）的不可解局面属于后者。

## 7. 未决与边界（如实声明）

1. (4,4,2) 的孤立死区内部有 276 条跨圈子单行道，小圈子并非互不相连；本报告只刻画了凝聚图的出/入度汇总与坑底清单，**未**逐圈子画出走廊拓扑。
2. (4,4,3) 的 5 个大圈子（18~36 态）内部结构（弦的具体形态、哈密顿性等）只统计了规模与边数，**未**做精细结构分类。
3. 「分量内状态是否互为颜色置换像」在平移/D4 商下退化为恒否；若采用不保几何的抽象重标号口径，本数据无法回答（未决）。
4. 入口边只有 2+2 条，但「从可解态一步踏入陷阱」对打乱流程的实际风险率未量化（需要按 cone 上的转移概率另行计算）。
5. 本分析基于既有落盘数据，未重新运行 C++ 引擎；所有结论以 `membership.bin` / `edges.bin` / `boards.bin` 为准，且与 `summary.txt` 完全咬合。

## 附录 B. 术语速查

- **SCC（强连通分量）**：本报告叫「小圈子」——一组两两互相可达的状态，进去就出不来。
- **凝聚图**：把每个小圈子缩成一个点得到的图；「坑底」= 凝聚图里没有出边的点（汇分量），「过客」= 凝聚图里有出边的点。
- **弦**：小圈子内部超出「单环」所必需的额外边。
- **自环**：从状态指向自身的边（移动后规范形回到自身，只见于对称形状）。
