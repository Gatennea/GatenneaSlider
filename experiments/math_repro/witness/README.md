# 滿盤回路的證人檔（witness）

每個檔案記錄一組「從滿盤出發、走若干步、回到滿盤」的回路，按**滑塊帶編號**重放。
把這些回路當置換生成元，生成的群就是該尺寸的滿盤可達置換群。

## 檔案

| 檔案 | K | 尺寸 | 搜索深度 | 回路數 | 重算群階 |
|---|---:|---|---:|---:|---:|
| `witness_3x2.json` | 6 | 3×2 | 7 | 109 | 720 = 6! |
| `witness_2x4.json` | 8 | 2×4 | 5 | 20 | 40,320 = 8! |
| `witness_3x3.json` | 9 | 3×3 | 5 | 24 | 362,880 = 9! |
| `witness_2x5.json` | 10 | 2×5 | 5 | 24 | 3,628,800 = 10! |
| `witness_3x4.json` | 12 | 3×4 | 5 | 20 | 479,001,600 = 12! |
| `witness_2x7.json` | 14 | 2×7 | 5 | 32 | 87,178,291,200 = 14! |
| `witness_5x3.json` | 15 | 5×3 | 5 | 20 | 1,307,674,368,000 = 15! |

全部由 `witness_check.py` 獨立重放校驗通過（每步走法在當時形狀上重新枚舉並比對，終點形狀與標籤排列逐格比對）。

## 格式

```json
{
  "m": 3, "n": 3, "K": 9, "depth": 5,
  "start": [[r, c, tag], ...],
  "loops": [
    {"depth": 10,
     "steps": [{"seam": "H_0", "side": "上", "unit": [0,1], "comp": [[r,c], ...]}, ...],
     "perm": [[tag, r, c], ...]        // 按 tag 升序
    }
  ]
}
```

`perm[i] = [tag, r, c]` 表示回到滿盤時，編號 `tag` 的滑塊在格 `(r,c)`。

## 重放

```
python witness_check.py witness_3x3.json
```

輸出行首的「校驗通過 N 條，失敗 0 條」與「重算群階」兩項。

## 已知陷阱

- `perm` 必須按 **tag** 排序再當成 image-form 置換；按位置排序會得到錯誤的群階（曾算出 1）。
- 用 sympy 時必須寫 `Permutation(list(g))`，不能寫 `Permutation([list(g)])`——後者把外層 list 當循環記號，群階會被壓成 K!/2。
