# mi 标记「片级锚点」修复版 · 归档

本文件夹是**一次性归档**，用于回看 mi 谜题标记「重叠 bug 修复后」的样子。
它**不是**游戏代码，也**不参与运行**；真正的修复代码在 git 历史里（见下）。

## 它记录的是什么

- **旧 bug**：mi 一格被切成 4 片（上 N / 右 E / 下 S / 左 W）。早期把标记画在
  **格子正中心**，导致同一格 4 片的标记全叠在同一个点上，糊成一团。
- **修复**（commit `a868f3a`）：标记改为画在**每一片自己的内心**，四片分落格的
  上/右/下/左（实测两两相距约 0.414 格，完全分得开）。命中判定与绘制共用同一个
  坐标函数，保证「能点到的洞 = 画出的标记」。

## ⚠️ 一个重要澄清（2026-10-05）

修复提交 `a868f3a` **本来就是 `feat/ui-animation` 分支的祖先**，也就是说：

> 你在 feat 界面上看到的「还是很乱」的 mi 标记，**就是修复后的片级版本**，
> 不是修复前的旧版。你其实已经看过修复效果了。

（此前我误称「feat 不含修复、你看的是旧版」，是错的。）

看过之后你认为 mi 标记**仍然太乱**，最终决定：
**mi 干脆不标任何洞/缺口/凸起标记，只保留绿色目标框。**
该决定已落地在 feat 分支 commit `13e7184`，并已推送到远程。
