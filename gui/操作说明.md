## 核心玩法
每个蓝色方格是一个滑块，鼠标左键点一次选中缝隙（显示红线），再点一次选中的滑块（整组变绿），按虚拟键盘或 WASD 等键滑动。点击「编辑 → 打乱」或 Alt+S 打乱滑块组，将打乱的滑块还原为初始的实心形态则过关。

游戏提供三种操作模式（可在右下角「模式」开关循环切换）与一个隐藏功能入口（见「标注模式」）。

## 基本操作：滑动

1. 选中一个“缝隙”（滑块之间的间隔），你会看到一条红直线
2. 点击某个滑块，选中该滑块所在的区域，这部分会变成绿色
3. 使用 W / S / A / D 键移动选中的滑块组
   - 之前选择了纵向缝隙：上下移动（W / S）
   - 之前选择了横向缝隙：左右移动（A / D）
   - 注意：输入法必须切换到英文哦
4. 按空格键取消所有选中
5. 建议多多利用撤回/重做

## 游戏规则和目标

1. 选择一种谜题。谜题的名字由三部分组成：横竖尺寸(m,n)、等级/步长(step)，在窗口下方记为step~m*n。步长是指每次移动的距离。
2. 限制：
   - 整个滑块组在任何一个瞬间只能有一个联通分量
   - 通俗的说就是所有滑块必须像拼图一样连在一起，不能出现断开的地方
   - 滑块不能重叠
   - 如果发现某次操作无法移动，这不是bug
3. 打乱，将打乱的滑块还原为初始的形状则成功

注意：这个游戏非常难（除了1级），适合逻辑思维极强的人探索挑战

## 竞速与练习模式

1. 默认为练习模式：自由探索，不计时
2. 通过右下角开关或谜题菜单切换到竞速模式：打乱后按空格开始计时，复原自动停止并计入成绩，计时中再按空格记为DNF（未完成）
3. 竞速模式全程禁止求解器、宏指令和打开存档等，确保公平
4. 成绩按谜题分组保存，可在成绩记录面板查看

## 创造模式

1. 通过右下角开关切换到创造模式：造好题目后切回练习/竞速开始还原
2. 方形谜题：可用「随机生成」挖洞，或用「手动构造」逐格摆放（点空白放滑块、点已有滑块取下）
3. 三角形／米字格谜题：没有随机生成，只能用「手动构造」逐格摆放
4. 手动构造时画布会即时校验（滑块数、连通性、同余组计数、至少一个空位），不合法不能应用；「取消」放弃本次构造，回到进入前的局面
5. 带序号的谜题：取下的编号压入编号栈，放回时拿到的是最后取下的那个编号（后进先出）；编号栈空时不能摆放新滑块；「清空」把盘上编号按升序整批压回栈

## 视图操作

1. 左键拖拽空白处移动地图视角
2. Ctrl + 滚轮或触摸屏两指缩放地图

## 滑动条与开关面板
缩放滑动条：缩放地图大小。
速度滑动条：动画播放的快慢。
动画开关：在滑动（包括撤销、重做）时播放动画。
着色开关：分组着色，每个滑块实际上因为核心规则被分到了某一组，只有同组滑块可以交换位置。三种形态都可用；1 级着色会是全盘单色，故不开启。
连锁开关：连锁悬停提示，当鼠标悬停在某一个滑块/空白格，高亮所有同组的位置（包括能去的空位与洞）。只高亮当前地图范围内、整块落在滑块范围里的位置。三种形态都可用；三角形／米字格把朝向也算进同组，1 级同样可用，方形 1 级全盘同组会自动关闭。
逆序宏：执行宏指令时逆序。

## 悬浮面板
F1-虚拟键盘。F2-调试面板与辅助信息。F3-成绩记录。

## 文件操作

1. Ctrl+S 保存当前游戏状态（包括历史记录）的存档
2. Ctrl+O 打开存档
3. 文件菜单 → 另存为：导出到新文件
4. 首次保存会自动命名，格式为 步长-m-n-日期-时间.json，例如 2-6-6-20260827-112821.json（24小时制）
5. 游戏会记住上次关闭时的窗口大小、屏幕位置，以及各面板是否打开和所在位置

## 成绩记录

1. 默认开启（可用右下角开关关闭），按当前谜题分组显示成绩列表与统计
2. 摘要第二行显示：单次最好、平均最好（最佳的Ao5）、总平均
3. 列表每行的单次、Ao5、Ao12：最好的标绿，最差的标红（DNF按最差计），其他为默认色
4. 点击某行展开详情：左侧是打乱后的初始状态，右侧是用时、步数、TPS、生成时间
5. 点击详情左侧的初始状态会弹出菜单：复制到剪贴板 / 另存为存档 / 载入练习模式，方便复现每一次打乱
6. 行尾的×删除该成绩，需要二次确认

## 编辑操作

1. Ctrl+Z 撤销
2. Ctrl+X 重做
3. Alt+S 打乱滑块组
4. Ctrl+R 重置到初始状态（同时也会清空所有操作历史记录）
5. Ctrl+A 开始或中断自动求解运算

## 谜题选择

1. 菜单栏「谜题」切换预设尺寸
2. 选择「自定义...」自由设定尺寸和等级

## 宏定义
提供玩家自定义操作序列的功能（就像魔方公式），例如“向左移动3步，然后向上移动2步”等。玩家可以将这些操作序列保存为宏，方便后续执行。
1. 管理宏：重命名、删除已经存在的宏
2. Ctrl+M 开始/停止录制宏：先选好基准滑块，进行一系列滑动，最后点击再按一次完成录制。注意基准滑块就像坐标系原点，宏记录的位置是相对于基准滑块的位置。
3. 执行宏：已保存的宏会在这里列出，你之前选的基准方块会作为宏的执行起点。
4. 逆序播放：把宏的步骤倒过来执行，可通过宏菜单或右下角开关切换

## 设置
1. 快捷键：都可以自定义
2. 动画设置：注意右侧滑动条和这里的滑动条是同一个东西。
3. 求解器算法：当你选择某一个算法，启动自动求解时就用这个算法。

## 杂谈
- 关于求解器
因为开发者貓九自己都不会复原（虽然学过、破解过很多种魔方），所以目前主要目标是做更好的求解器。这是一个长期目标、巨大的工程，欢迎参与贡献。
最开始的求解器是IDA*，通俗的说是带有启发函数的暴力搜索，能找到最优解，但是还是很慢。
然后又做了两个快速求解算法，只是比第一个快一点，基于IDA*、贪心爬山，因为并不是穷举，很容易失败。
第四个求解器是查表求解器，我先计算了所有可能状态和它们的联系，建立一个大型表，求解速度达到1s以内。它的缺点更明显：建表时间很长（例如2~4\*4谜题，即使榨干CPU算力，87分钟才完成，35.7MB，比游戏本体还大，而2~5*5说不定要几天），每个谜题都需要独立建表。所以我知道这个算法也不能作为通用解法。
它们的共同特点是同一个状态，不管解多少次，速度都一样，不会越来越强。
接下来的目标是用神经网络、强化学习等方法训练专用AI，正好用之前的数据集。我没有训练AI的经验，难度未知。
我希望有一天AI求解器能应对任意等级10\*10以内的谜题，更希望可以借助求解器达到终极目标：找到人可以理解的通用解法。
另外说一下可能成功的人类解法：把滑块组拼成接近m*n的形状，这时它可能有突出、凹陷、孔洞，也许我们可以找找这些怎么处理。

- 其他
游戏有自动缓存，每次打开就是上次关闭时的样子。
自定义谜题的尺寸没有限制，如果很大，自动打乱会加载较久或者导致无响应。
如果不需要玩查表求解器，可以删除solver文件夹。
