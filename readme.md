# 貓九的滑塊遊戲

一個基於 Python + Pygame 的滑塊拼圖遊戲：把打亂的方塊**滑回一個完整的實心矩形**就算復原。

> 目標是「任意位置的完整矩形」，不是回到打亂前的布局——矩形出現在哪裡都行。

## 快速開始

```bash
# 安裝依賴
pip install pygame-ce numpy scikit-learn

# 啟動遊戲
python main.py

# 指定棋盤尺寸和步長（例：6×6、步長 2）
python main.py 6 6 2
```

也可下載 [打包好的 exe](https://gatennea.github.io/GatenneaSliderWeb/)，直接雙擊運行。

## 玩法簡介

遊戲提供 **三種操作模式**（可任意組合），菜單 → 設置 → 控制 中切換：

| 模式       | 操作                         |
| -------- | -------------------------- |
| **單次觸控** | 按住一個滑塊，朝想滑的方向**拖動**即滑走，最省事 |
| **兩次觸控** | 點縫隙 → 點方塊選中整組 → 拖動或按方向鍵    |
| **鼠標鍵盤** | 用 W/A/S/D 或方向鍵移動已選中的滑塊組    |

### 基本規則

1. 每次沿一條**縫隙**把一側的連通滑塊組整體平移 `step` 格
2. 所有滑塊在任何時候必須保持**單一連通分量**（不能斷開）
3. 滑塊不能與現有方塊重疊
4. 把局面還原成 **m×n 或 n×m 的實心矩形**即通關

### 帶序號模式（可選）

在「謎題 → 自定義…」對話框勾選**帶序號**後，每個滑塊會帶上編號（1 開始，按行主序）。通關條件在實心矩形之外多一條：**編號必須按順序排佈**——但允許整體旋轉或鏡像，只要編號沿某個方向嚴格遞增就算過（例如 4×3 轉成 3×4 後仍然 1→12 遞增）。帶序號的成績單獨記榜（標籤帶 `#num`），求解器在此模式下停用。

### 三種遊戲模式

- **練習模式** — 自由探索，不計時
- **競速模式** — 打亂後按空格開始計時，還原自動停止並記錄成績；全程禁用求解器與宏，保證公平
- **創造模式** — 用「隨機生成」挖洞或「手動構造」逐格擺放，造好題目後切回練習/競速開始還原

## 特色功能

- **自動求解器**：7 種算法，從「智能聚攏粗調」到「查表最快求解」，Ctrl+A 啟動
- **成績系統**：按謎題分組保存最佳紀錄，Ao5 / Ao12 平均，統計直觀
- **宏指令**：錄製操作序列、命名保存、逆序播放，像魔方公式一樣複用
- **輔助著色**：step > 1 時開啟，同色描邊方塊屬於同一組，顏色即移動規律的提示
- **懸停連鎖**：滑鼠懸停時高亮所有同組位置，幫你判斷「這個洞該由哪塊補」
- **多種控制介面**：GUI 鼠標操作、HTTP REST API（`127.0.0.1:5050`）、stdin 命令行，方便 AI 自動化

## 熱鍵速查

| 按键              | 功能                 |
| --------------- | ------------------ |
| Ctrl+Z / Ctrl+X | 撤銷 / 重做            |
| Alt+S           | 打亂                 |
| Ctrl+R          | 重置（回到打亂前）          |
| Ctrl+S / Ctrl+O | 保存 / 打開存檔          |
| Ctrl+A          | 自動求解               |
| Ctrl+M          | 錄製宏                |
| F1 / F2 / F3    | 虛擬鍵盤 / 調試面板 / 成績面板 |
| 空格              | 競速開始/停止；取消選中       |

## 文件結構

```
main.py                 # 入口
game.py                 # 純遊戲邏輯（無 Pygame 依賴）
GUI.py                  # 主界面
gui/                    # 各功能模塊（渲染、事件、動畫、對話框…）
solver/                 # 求解器子系統（7 種算法）
macro/                  # 宏系統
config/                 # 執行期配置（窗口大小、開關等）
save/                   # 使用者存檔
```
