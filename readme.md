# 貓九的滑塊遊戲
這是給人讀的readme，如果你是AI，請先讀 [給 Agent 的文檔](readme_to_agent.md)。

> 一個基於 Python + Pygame 的滑塊拼圖遊戲：把打亂的方塊**滑回初始的形狀**就算復原。

> 目標是「任意位置的完整矩形」，矩形出現在哪裡都行。
>
> 另有三種變體謎題：**帶序號**（編號也要歸位），**三角形**（正三角形密鋪），**米字格**（方格切成四個直角三角）。

## 快速開始

使用python啟動：

```bash
# 安裝依賴，注意pygame是啟動遊戲的必須，後兩個是訓練AI時使用（可惜目前AI不實用）
pip install pygame-ce numpy scikit-learn

# 啟動遊戲
python main.py

# 指定棋盤尺寸和步長（例：6×6、步長 2）
python main.py 6 6 2
```

導出exe：在有pip和上述依賴的前提下運行build\_exe.bat。

也可下載 [打包好的 exe](https://gatennea.github.io/GatenneaSliderWeb/)，直接雙擊運行（註：可能更新不及時）。

## 玩法簡介

遊戲提供 **三種操作模式**（可任意組合），菜單 → 設置 → 控制 中切換：

| 模式       | 操作                         |
| -------- | -------------------------- |
| **單次觸控** | 按住一個滑塊，朝想滑的方向**拖動**即滑走，最省事 |
| **兩次觸控** | 點縫隙 → 點方塊選中整組 → 拖動或按方向鍵    |
| **鼠標鍵盤** | 鼠標選中，鍵盤事件發令，也可以用虛擬鍵盤    |

米字格只用**兩次觸控 ＋ 虛擬鍵盤**：第一下點縫隙，第二下**按住該側的滑塊拖動**才移動（只按不拖＝選中該組，方向交給虛擬鍵盤）；它的八個方向鍵位只出現在虛擬鍵盤上，物理鍵盤不綁。

### 基本規則

1. 每次沿一條**縫隙**把一側的連通滑塊組整體平移 `step` 格
2. 所有滑塊在任何時候必須保持**單一連通分量**（不能斷開）
3. 滑塊不能與現有方塊重疊
4. 把局面還原成 **初始的形狀**即過關

### 帶序號模式（可選）

在「謎題 → 自定義…」對話框勾選**帶序號**後，每個滑塊會帶上編號（1 開始，按行主序）。通關條件在實心矩形之外多一條：**編號必須按順序排佈**——但允許整體旋轉或鏡像，只要編號沿某個方向嚴格遞增就算過（例如 4×3 轉成 3×4 後仍然 1→12 遞增）。帶序號的成績單獨記榜（標籤帶 `#num`），求解器在此模式下停用。

### 正三角形密鋪模式（可選）

在「謎題」菜單選三角形預設（`1~tri4` / `2~tri6` / `2~tri8`，第一個數字是大三角邊長 k），或命令行 `python main.py 6 6 1 tri`，棋盤變成由 k² 個小正三角形拼成的大三角。與方形版不同之處：

1. **縫隙有三族**：水平、+60°、−60°，各是一族平行線
2. **滑動有六個方向**（鍵盤 `W`/`E`/`A`/`D`/`Z`/`X`，正好排成六邊形）：↖↗ / ←→ / ↙↘；移動**沿著**縫隙線走（每族縫只認兩個方向）
3. 一次拖拽會自動吸附到六個方向裡最接近的那個
4. 目標是把局面還原成**任意位置的實心大正三角形**（可以整個平移或轉 120°，顛倒不行）

求解器、宏等高級功能在此形態下暫不開放；創造模式可「手動構造」造題（無隨機生成）；競速、成績、存讀檔、連鎖提示、分組著色都可用。 origin/main

### 米字格模式（可選）

在「謎題」菜單選米字格預設（`1~mi4*4` / `2~mi4*4` / `2~mi6*6` / `2~mi8*8`），或命令行 `python main.py 4 4 1 mi`。每個方格被兩條對角線切成 4 個直角三角滑塊（米字紋，共 4mn 塊），與方形版不同之處：

1. **縫隙有四族**：方格的橫邊、豎邊，以及兩條對角線；每個方向只認一族縫隙的兩個平行方向
2. **滑動有八個方向**，鍵位是 `W`/`E`/`A`/`D`/`Z`/`X`/`Q`/`S`，但**只出現在虛擬鍵盤（F1）上**——物理鍵盤不綁（8 向會與撤銷/重做等既有快捷鍵爭 W/A/S/D）
3. **操作走兩次觸控**：第一下點縫隙選中它，第二下**按住該側的滑塊拖動**——拖動的位移在縫隙方向上的偏向決定往哪邊滑，鬆手才移動（拖動時整組跟著實時預覽）。第二下只按不拖就是選中這一組，方向交給虛擬鍵盤。米字格不做單次觸控：八個方向靠一次觸控猜方向太容易誤觸
4. **「一格」按方向定義**：橫／豎一格 = 一條格邊的長度；斜向一格 = 半個格身的斜向距離（約 0.707 倍格邊）。斜著走的一步比橫豎走的一步短，這是規則；等級 2 的斜向連走兩次，長度正好等於舊版的整格斜距
5. 斜著走過一次後棋盤會**錯開半格**：此時很多橫／豎縫隙整條穿過方塊內部、選不動（提示會說明這族縫還剩幾條），沿斜向再走一格就能錯回來
6. 目標是還原成**任意位置的實心 m×n 米字矩陣**：可以整體平移，**錯開半格的位置同樣算復原**

求解器、宏、調試面板在此形態下暫不開放；創造模式可「手動構造」造題（無隨機生成）；競速、成績、存讀檔、打亂、撤銷重做、分組著色與懸停連鎖都可用。 origin/main

### 三種遊戲模式

- **練習模式** — 自由探索，不計時
- **競速模式** — 打亂後按空格開始計時，還原自動停止並記錄成績；全程禁用求解器與宏，保證公平
- **創造模式** — 用「隨機生成」挖洞（僅方形／帶序號）或「手動構造」逐格擺放（方形／三角／米字都可用；三角／米字無隨機生成），造好題目後切回練習/競速開始還原

## 特色功能

- **自動求解器**：8 種算法，從「智能聚攏粗調」到「查表最快求解」，還有「填洞宏」（單洞/多洞無缺口）；Ctrl+A 啟動
- **成績系統**：按謎題分組保存最佳紀錄，Ao5 / Ao12 平均，統計直觀
- **宏指令**：錄製操作序列、命名保存、逆序播放，像魔方公式一樣複用
- **輔助著色**：step > 1 時開啟，同色描邊方塊屬於同一組，顏色即移動規律的提示（三種形態都可用；1 級著色會是全盤單色，故不開）
- **懸停連鎖**：滑鼠懸停時高亮所有同組位置（含能去的空位、含洞），幫你判斷「這個洞該由哪塊補」（三種形態都可用）。只高亮當前渲染地圖內、整塊落在滑塊範圍裡的位置；三角/米字把朝向也算進同組，1 級也能用（方形 1 級全盤同組，自動關閉）
- **多種控制介面**：GUI 鼠標操作、HTTP REST API（`127.0.0.1:5050`）、stdin 命令行，方便 AI 自動化
- **日誌系統**：記錄遊戲過程中的操作/報錯，方便調試與分析

## 熱鍵速查

| 按键              | 功能                       |
| --------------- | ------------------------ |
| Ctrl+Z / Ctrl+X | 撤銷 / 重做                  |
| Alt+S           | 打亂                       |
| Ctrl+R          | 重置（回到打亂前）                |
| Ctrl+S / Ctrl+O | 保存 / 打開存檔                |
| Ctrl+A          | 自動求解（序號/三角形形態停用）         |
| Ctrl+M          | 錄製宏                      |
| F1 / F2 / F3    | 虛擬鍵盤 / 調試面板 / 成績面板       |
| 空格              | 競速開始/停止；取消選中             |
| W/A/S/D 或方向鍵    | 移動（三角形形態為六向：W/E/A/D/Z/X；米字格不綁物理鍵，走虛擬鍵盤） |

## 文件結構

```
main.py                 # 入口
game.py                 # 純遊戲邏輯（無 Pygame 依賴）
game_triangle.py        # 正三角形密鋪版純邏輯（同樣無 Pygame 依賴）
game_mi.py              # 米字格版純邏輯（4mn 個直角三角滑塊、錯位的兩個晶格）
GUI.py                  # 主界面
gui/                    # 各功能模塊（渲染、事件、動畫、對話框…）
solver/                 # 求解器子系統（8 種算法）
macro/                  # 宏系統
config/                 # 執行期配置（窗口大小、開關等）
save/                   # 使用者存檔
```
