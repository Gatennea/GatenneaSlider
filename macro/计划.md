## 宏定义功能 — 最终方案

### 核心概念：基于基准坐标的相对位置宏

宏录制时记录**相对于基准坐标**的操作步骤，执行时由玩家指定新的基准坐标，自动转换为绝对坐标。这样同一个宏可以在棋盘的不同位置复用。

---

### 一、数据格式

**单个步骤（step）：**
```json
{
  "gap_type": "h",           // 缝隙类型 h/v
  "gap_line_rel": 1,         // 缝隙行/列 相对于基准的偏移（h→基准行偏移, v→基准列偏移）
  "side": "above",           // 选中缝隙哪一侧（h: above/below, v: left/right）
  "direction": "a",          // 滑动方向 w/a/s/d
  "step": 2                  // 步长
}
```

**宏文件（`macro/xxx.json`）：**
```json
{
  "name": "将上方两行左移",
  "description": "在4×4棋盘上，将上方两行整体左移2格",
  "recorded_step": 2,
  "base_point": [2, 1],
  "steps": [
    {"gap_type": "h", "gap_line_rel": 1, "side": "above", "direction": "a", "step": 2},
    {"gap_type": "v", "gap_line_rel": 0, "side": "left", "direction": "s", "step": 2}
  ]
}
```

- `base_point`：录制时的基准坐标 `[row, col]`（仅供参考，不影响执行）
- `recorded_step`：录制时的步长（用于兼容性判断）

### 二、坐标转换规则

录制时：
```
gap_line_rel = gap_line_abs - base_row  (gap_type='h')
gap_line_rel = gap_line_abs - base_col  (gap_type='v')
```

执行时（玩家选择新基准 `(new_r, new_c)`）：
```
gap_line_abs = new_r + gap_line_rel  (gap_type='h')
gap_line_abs = new_c + gap_line_rel  (gap_type='v')
```

### 三、执行流程

```
1. 玩家选择"执行宏 → [宏名]"
2. 进入"选择基准"模式（状态栏提示"请点击基准方块"）
3. 玩家点击某个方块 → 取该方块坐标为 (new_r, new_c)
4. 逐步执行：
   a. 计算绝对 gap_line
   b. 检查缝隙有效性
   c. 检查 step 兼容性（recorded_step % current_step == 0 时兼容，按比例拆分为多次移动）
   d. opt() 选中方块组
   e. try_move() 验证
   f. 合法 → 播放动画 → commit_move → 保存快照
   g. 不合法 → 终止，提示"宏在第 N 步失败"
5. 所有步骤完成 → 提示"宏执行完毕"
```

### 四、Step 兼容性

- `recorded_step == current_step`：直接执行
- `recorded_step % current_step == 0`：将宏中的每步拆分为 `recorded_step / current_step` 次小步
- 否则：该宏不兼容当前谜题，提示并拒绝执行

### 五、UI 交互

**录制流程：**
1. 菜单「宏定义」→「录制宏」
2. 状态栏显示 `🔴 等待选择基准...`，玩家点击某个方块作为基准
3. 状态栏显示 `🔴 录制中（N步）...`，玩家正常操作
4. 菜单「宏定义」→「停止录制」（或按 Esc）
5. 弹窗输入名称 → 保存

**执行流程：**
1. 菜单「宏定义」→ 已保存的宏列表（如"将上方两行左移"）
2. 状态栏显示 `🎯 等待选择基准...`，玩家点击方块
3. 自动逐步执行

**管理对话框：**
- 宏列表（名称 + 步骤数 + 录制时的 puzzle 参数）
- 重命名、删除

宏定义功能已实现完成。以下是变更摘要：

## 新增文件

### `macro/__init__.py`

宏模块包初始化。

### `macro/macro.py`

核心数据模型，包含：

- __MacroStep__ — 单个宏步骤，记录缝隙类型/偏移/侧/方向/步长（相对于基准坐标）
- __Macro__ — 完整宏，包含名称、步长兼容性检测、JSON序列化
- __MacroManager__ — 宏文件管理器，负责加载/保存/删除/重命名 `macro/*.json` 文件
- __步骤拆分__：当录制步长≠执行步长时，自动拆分为多次小步（如录制step=4执行step=2 → 每步拆2次）

## 修改文件

### `GUI.py`

- 新增宏相关状态变量（recording/executing/dialog状态）

- 录制模式时 `_record_macro_step()` 在每次 `commit_move` 后记录步骤

## 功能流程

__录制__：菜单"宏定义"→"录制宏" → 执行操作 → 菜单"停止录制" → 输入名称保存

__执行__：菜单"宏定义"→ 点击宏名 → 点击棋盘指定基准点 → 逐带动画执行

__步长兼容__：录制step=4的宏在step=2环境下执行时，每步自动拆分为2次小步
