## 三、已修复的开发期 Bug 🔧

| Bug | 原因 | 修复方式 |
|-----|------|----------|
| 宏管理对话框关不上 | `_handle_macro_manager_click` 缺少 close button 点击检测 | 添加 `_macro_mgr_close_btn` 检测 + 外部点击关闭 |
| 宏管理对话框按钮不响应 | renderer 用 tuple 存储 rect，events 用 dict key 查找 | 统一为 dict 格式 `{'row', 'rename', 'delete', 'index'}` |
| 宏命名对话框按钮无反应 | `handle_macro_name_dialog_events` 只处理键盘，缺少鼠标按钮检测 | 添加 OK/Cancel 按钮的 collidepoint 检测 |
| 宏命名输入框点击无反应 | renderer 未存储 `_macro_name_input_rect` | 在 renderer 中添加 `self._macro_name_input_rect = input_rect` |
| 重命名宏传入整数索引而非名称 | `_start_macro_rename` 将索引存入 `macro_renaming_index`，`handle_macro_name_dialog_events` 调用 `rename_macro(idx, name)` 时类型错误 | 改为存储旧名称字符串；`handle_macro_name_dialog_events` 用 `isinstance(str)` 判断是否重命名模式 |

## 五、已知限制

1. **宏存储**：每个宏一个 JSON 文件，存放在 `macro/` 目录下
2. **步长兼容**：仅支持 `recorded_step % current_step == 0` 的情况
3. **宏执行失败**：某步失败后整个宏停止，已执行的步骤不会回滚
4. **基准选择**：执行宏时基准坐标取玩家点击的方块位置，不做合法性校验（可能转换出无效缝隙）
